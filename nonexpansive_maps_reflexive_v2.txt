NOTATION

R is the real numbers. N = {1,2,3,...}. X is a real vector space with a norm ||.||. A Banach space is a normed vector space that is complete: every Cauchy sequence converges. X* is the dual space: all continuous linear functionals f: X -> R, with norm ||f|| = sup{ |f(x)| : ||x|| <= 1 }. The weak topology on X is the topology in which a net x_i converges to x iff f(x_i) -> f(x) for every f in X*. The weak topology is weaker than the norm topology. A set is weakly closed if it is closed in the weak topology. The weak closure of a convex set equals its norm closure. A Banach space is reflexive if the canonical map J: X -> X** is onto. In a reflexive space, every norm-closed bounded convex set is weakly compact.

A map F: C -> C is nonexpansive if ||F(a)-F(b)|| <= ||a-b|| for all a,b in C. A fixed point is a point x with F(x)=x.

conv(A) is the convex hull: all finite convex combinations of points of A. closure(A) is the norm closure. diam(A) = sup{ ||a-b|| : a,b in A }. B_Y = { y in Y : ||y|| <= 1 }.

An ultrafilter on N is a collection U of subsets of N such that: N is in U; the empty set is not in U; if A is in U and A is a subset of B then B is in U; if A and B are in U then A intersect B is in U; for every A, exactly one of A or its complement is in U; and no finite set is in U. Such a free ultrafilter exists by Zorn's lemma. If (a_j) is a sequence in a compact Hausdorff space, then lim_{j->U} a_j is the unique point a such that for every neighborhood V of a, the set { j : a_j in V } is in U. This limit always exists. We use it to take limits without choosing subsequences.

Zorn's lemma: if every chain in a partially ordered set has an upper bound, then the set has a maximal element. We use it to get maximal filters and minimal invariant sets.

1. WHAT THE THEOREM SAYS

Theorem 1.1. Let X be a real reflexive Banach space. Let C be a nonempty norm-closed bounded convex subset of X. If F: C -> C is nonexpansive, then F has a fixed point.

The theorem is sharp. Reflexivity cannot be dropped: Alspach constructed a weakly compact convex subset of L1[0,1] with a fixed-point-free nonexpansive selfmap. The norm matters: Dominguez Benavides showed that every reflexive Banach space admits an equivalent norm with the fixed point property. The theorem here concerns the given norm.

Corollary 1.2 (Bruck). Under the same hypotheses, any pairwise commuting family S of nonexpansive selfmaps of C has a common fixed point, and the common fixed set is a nonexpansive retract of C.

We prove Theorem 1.1 in Sections 5-14 and deduce Corollary 1.2 in Section 15.

2. BACKGROUND IDEAS

A Banach space is a complete normed vector space. Think of a space of functions or sequences where you can add, scale, and measure length, and where Cauchy sequences converge. The reflexive spaces include Hilbert spaces and Lp spaces for 1 < p < infinity. They exclude L1 and L-infinity in general.

The weak topology is the topology of testing against all continuous linear functionals. A sequence converges weakly if every functional converges on it. Weak compactness is a powerful substitute for compactness in infinite dimensions. In a reflexive space, the closed unit ball is weakly compact.

A convex set is a set closed under taking line segments. A nonexpansive map does not increase distances. The fixed point property asks whether every such map on every closed bounded convex set has a fixed point.

3. WHY THE PROBLEM IS HARD

In finite dimensions, Brouwer's fixed point theorem says every continuous map from a closed ball to itself has a fixed point. In infinite dimensions, closed bounded sets are not compact, and continuous maps need not have fixed points. Nonexpansiveness is strong, but not strong enough to make the unit ball compact. Weak compactness is available in reflexive spaces, but nonexpansive maps are not weakly continuous in general. So we cannot simply apply a fixed point theorem for weakly continuous maps. The proof must extract a fixed point from approximate fixed points and the geometry of the space.

4. THE PLAN OF THE PROOF

Suppose the theorem fails. Then there is a counterexample. We reduce to a minimal invariant set K of diameter 1. Approximate fixed points in K have a special property: they are asymptotically diametral. That is, their distance to every point of K tends to 1. This is the Goebel-Karlovitz lemma.

We use this to build an anchor point x and a family of maps that can be chosen adaptively: at each step, the accuracy required can depend on all previous choices. The anchor lets us build a tree of maps. Each node of the tree carries a nonexpansive map and a point. The tree is designed so that replacing the leaves from right to left by a common approximate fixed point produces a detectable change at the root. Combining the detections along a branch gives a vector d in the unit ball of Y = closure(span(K-K)) such that all the functionals along the branch are at least 1/2 on d. But the same functionals tend to zero on all of Y along the branch, because the points z_i are dense. Contradiction.

The rest of the proof makes this precise.

5. STEP 1: REDUCE TO A MINIMAL SET

Lemma 5.1 (weak facts). Let X be a real normed space.
(a) Every v in X has a norming functional: f in X* with ||f|| <= 1 and f(v)=||v||.
(b) Every norm-closed convex set is weakly closed.
(c) The norm is weakly lower semicontinuous: if x_i -> x weakly, then ||x|| <= liminf ||x_i||.
(d) On a finite Cartesian product X^q, the weak topology is the product weak topology.
(e) The norm and weak closures of a convex set coincide.
(f) If X is reflexive and complete, every norm-closed bounded convex subset of X is weakly compact.
(g) Arbitrary products of compact Hausdorff spaces are compact.

The proof is in the appendix.

Lemma 5.2 (reduction). If Theorem 1.1 fails, there are a nonempty separable weakly compact convex set K and a nonexpansive map T: K -> K without a fixed point such that K has no proper nonempty norm-closed convex T-invariant subset. We may take diam K = 1. Moreover, the weak topology on K is metrizable. Let Y = closure(span(K-K)) and B_Y = { y in Y : ||y|| <= 1 }. Then B_Y is weakly compact and Y is separable.

Proof. Start with a fixed-point-free map F: C -> C as in the theorem and a point a in C. Set C_0 = {a} and C_{n+1} = closure(conv(C_n union F(C_n))). These sets are increasing and separable: continuous images of separable sets are separable, and rational convex combinations of a countable dense set are dense in its convex hull. Hence C' = closure(union C_n) is separable, bounded, closed, and convex. Norm continuity of F gives F(C') subset C', and Lemma 5.1(f) makes C' weakly compact.

Every decreasing chain of nonempty norm-closed convex invariant subsets of C' has a nonempty intersection, by weak compactness and the finite intersection property. The intersection is again closed, convex, and invariant. Zorn's lemma, with inclusion reversed, therefore supplies a minimal such set K. Put T = F restricted to K. Its diameter d is positive, since a singleton invariant set would give a fixed point. From now on express distances in units of d, writing ||.|| for the original norm divided by d. This scalar normalization preserves the topologies, nonexpansiveness, and fixed points; it makes diam K = 1.

Choose a norm-dense sequence (z_i) in K. Its pairwise differences have dense linear span in Y, so Y is separable. Choose a dense sequence (u_j) on the unit sphere of Y and norming functionals g_j in X* for these vectors. They separate points of Y: if ||v||=1 and ||v-u_j|| < 1/2, then g_j(v) > 1/2. Thus the map a -> (g_j(a))_{j>=1} continuously injects weakly compact K into R^N. The latter is metrizable, for example by sum_j 2^{-j} min{1, |s_j-t_j|}. The injection is a homeomorphism onto its image, since compact subsets of a Hausdorff space are closed. Hence the weak topology on K is metrizable. Finally B_Y is a norm-closed bounded convex subset of X, so is weakly compact by Lemma 5.1(f). Its inherited weak topology equals its intrinsic weak topology. QED.

6. STEP 2: APPROXIMATE FIXED POINTS ARE DIAMETRAL

A sequence (u_j) in K is an approximate fixed point sequence if ||T u_j - u_j|| -> 0.

Lemma 6.1 (Goebel-Karlovitz). Every approximate fixed point sequence (u_j) satisfies lim_{j->infinity} ||u_j - z|| = 1 for every z in K.

Proof. First K = closure(conv T(K)). Indeed, closure(conv T(K)) is nonempty and contained in K, and its image under T is contained in T(K) and hence in the hull. Minimality applies.

Consider on K the functions
s(z) = sup_{w in K} ||z-w||,
r(z) = limsup_j ||z-u_j||.
Both are convex and 1-Lipschitz. For a fixed center, the distance function is convex and continuous, so its supremum is unchanged on passing to a norm-closed convex hull. The hull identity and nonexpansiveness give
s(Tz) = sup_{w in K} ||Tz - Tw|| <= sup_{w in K} ||z-w|| = s(z),
r(Tz) = limsup ||Tz - u_j|| <= limsup (||Tz - Tu_j|| + ||Tu_j - u_j||) <= limsup ||z - u_j|| = r(z),
where the second inequality also uses ||Tu_j - u_j|| -> 0.

Every nonempty sublevel set of either function is norm closed, convex, and invariant. If the function had two different values, a sublevel strictly between them would contradict minimality. Both functions are therefore constant, and s=1 because its supremum is diam K. Write r=R <= 1.

Take the weak U-limit a in K of (u_j). For every z in K and eta > 0, all sufficiently large j satisfy ||z-u_j|| <= R+eta. The corresponding closed ball is weakly closed and the cofinite sets belong to U, so ||z-a|| <= R+eta. Letting eta decrease to zero and taking the supremum over z gives 1 = s(a) <= R, hence R=1.

This argument applies to every subsequence of (u_j), since each is again an approximate fixed point sequence. As all distances are at most 1, a failure of the asserted limit would give a subsequence bounded above by 1-eta for some eta > 0, contradicting its limsup of 1. QED.

Lemma 6.2 (compact detector). For every nonempty norm-compact set E subset K and every epsilon > 0, there exists delta > 0 such that each y in K with ||Ty-y|| <= delta admits a single f in X*, ||f|| <= 1, satisfying
f(y-z) >= 1 - epsilon for all z in E.

Proof. Choose an epsilon/2-net a_1,...,a_m in E and set a = (1/m) sum a_i in K. Lemma 6.1 implies that, for some delta > 0,
||Ty-y|| <= delta implies ||y-a|| >= 1 - epsilon/(2m).
Indeed, otherwise choosing a violating point with defect at most 1/j for each j would contradict that lemma. Choose a norming functional f for y-a. The numbers f(y-a_i) are all at most 1, whereas their sum is m f(y-a) >= m - epsilon/2. Each is therefore at least 1 - epsilon/2. For z in E, take a_i with ||z-a_i|| < epsilon/2 and use ||f|| <= 1 to obtain the claimed bound. QED.

7. STEP 3: RESOLVENTS AND THE FAMILY G

Lemma 7.1 (resolvents). For every n >= 1 and a in K, there is a unique point R_n(a) in K satisfying
R_n(a) = a/n + (1 - 1/n) T R_n(a).
The map R_n: K -> K is nonexpansive, and
||T R_n(a) - R_n(a)|| <= 1/n,
||R_n(a) - a|| <= (n-1) ||T a - a||.

Proof. For n=1, the defining equation gives R_1(a)=a. For n>1, the map u -> a/n + (1-1/n) T u takes the complete set K into itself and has Lipschitz constant q = 1-1/n < 1. Starting from any point of K, its iterates have successive displacements bounded by q^r times the first displacement. The geometric series shows that the iterates are Cauchy. Their limit solves the defining equation by norm continuity. Two solutions have distance at most q times their distance and therefore coincide.

For u=R_n(a) and v=R_n(b), comparison of their equations gives
||u-v|| <= (1/n)||a-b|| + (1-1/n)||u-v||,
which proves nonexpansiveness. The identity Tu-u = (Tu-a)/n and diam K=1 give the first estimate. For the second, the defining equation and nonexpansiveness of T give
||u-a|| <= (1-1/n)(||u-a|| + ||Ta-a||).
Rearranging proves the claim. QED.

Let G be the family generated by the identity map and the maps R_n using finitely many compositions and pointwise finite convex combinations. Every member of G is a nonexpansive selfmap of K. Moreover, for each G in G there is a finite constant c_G >= 0 such that
||G(a)-a|| <= c_G ||Ta-a|| for all a in K.
For the generators, take c_Id = 0 and c_{R_n} = n-1. Convex combinations preserve the estimate with the same convex combination of the constants. For compositions, nonexpansiveness gives
||G_1(G_2(a))-a|| <= ||G_1(G_2(a))-G_1(a)|| + ||G_1(a)-a|| <= ||G_2(a)-a|| + ||G_1(a)-a|| <= (c_{G_2}+c_{G_1})||Ta-a||.

For m >= 1, define the tail family
H_m = { R_n o G : n >= m, G in G }.
These families are nonempty, contained in G, and decreasing with m. Their outer resolvents give the uniform bound
||T h(a) - h(a)|| <= 1/m for h in H_m, a in K.

8. STEP 4: THE COMPACT SEMIGROUP AND THE ANCHOR

Give K^K, the set of all maps from K into itself, the topology of pointwise weak convergence. It is a compact Hausdorff space by the product compactness in Lemma 5.1(g).

Lemma 8.1 (finite simultaneous approximation). Let B subset K^K be a nonempty convex family of nonexpansive maps. Every map h in the pointwise weak closure of B is nonexpansive. For any integer q >= 1, points a_1,...,a_q in K, and delta > 0, there is a single g in B such that
max_{1<=i<=q} ||g(a_i)-h(a_i)|| < delta.

Proof. For each fixed pair a,b in K, the condition ||h(a)-h(b)|| <= ||a-b|| is closed in the pointwise weak topology: evaluation at a,b and subtraction are weakly continuous, and norm balls are weakly closed. Intersecting these conditions over all pairs proves the first assertion.

For the second, consider the convex subset
V = { (g(a_1),...,g(a_q)) : g in B } subset X^q.
The tuple (h(a_1),...,h(a_q)) belongs to its weak closure, by continuity of evaluation. The weak topology of the finite Banach product X^q is the product of its coordinate weak topologies. By separation, the weak and norm closures of a convex subset of X^q agree. Applying this fact with the maximum coordinate norm gives one element of V satisfying all the desired inequalities. QED.

Lemma 8.2 (idempotent in a compact semigroup). Let S be a nonempty compact Hausdorff semigroup. Suppose that, for each p in S, the right translation h -> hp is continuous. Then S contains an idempotent: an element p with p^2=p.

Proof. The intersection of a chain of nonempty compact subsemigroups of S is nonempty by compactness and is again a compact subsemigroup. Zorn's lemma therefore gives a minimal nonempty compact subsemigroup S' subset S. Fix p in S'. The set S'p is a nonempty compact subset of S' by continuity of right translation. It is a subsemigroup because (ap)(bp) = (apb)p in S'p for a,b in S'. Minimality gives S'p = S', so in particular there is h in S' with hp=p. The set E = { h in S' : hp=p } is thus nonempty. It is compact by continuity of right translation and is a subsemigroup, since hp=kp=p implies (hk)p = h(kp) = hp = p. Minimality gives E=S', and p in E proves p^2=p. QED.

Set
A_m = pointwise weak closure of conv H_m,
A = intersection_{m>=1} A_m.

Proposition 8.3 (anchor). The set A is a nonempty compact semigroup of nonexpansive selfmaps of K and contains an idempotent P. There is a point x in K with P(x)=x such that the nonempty weakly compact set
D_x = intersection_{m>=1} weak closure{ h(x) : h in H_m }
satisfies
x in norm closure(conv D_x).

Proof. The sets A_m are nonempty, compact, and decreasing. Every member is nonexpansive by Lemma 8.1.

First, conv H_m is closed under composition. Indeed, if
g = sum_{r=1}^s lambda_r (R_{n_r} o G_r) in conv H_m
and k in conv H_m, then k in G and
g o k = sum_{r=1}^s lambda_r (R_{n_r} o (G_r o k)) in conv H_m.
This identity distributes precomposition over the outer convex combination.

To pass to A_m, fix h,k in A_m, arguments a_1,...,a_q in K, and delta > 0. Lemma 8.1 gives k_delta, h_delta in conv H_m with
max_i ||k_delta(a_i)-k(a_i)|| < delta,
max_i ||h_delta(k(a_i))-h(k(a_i))|| < delta.
The second application uses the fixed arguments k(a_i). Nonexpansiveness of h_delta then gives
||h_delta(k_delta(a_i)) - h(k(a_i))|| <= ||h_delta(k_delta(a_i))-h_delta(k(a_i))|| + ||h_delta(k(a_i))-h(k(a_i))|| <= ||k_delta(a_i)-k(a_i)|| + ||h_delta(k(a_i))-h(k(a_i))|| < 2 delta.
The composition h_delta o k_delta belongs to conv H_m. Since the finite arguments and delta were arbitrary, these simultaneous norm approximations imply h o k in A_m. Thus A is a nonempty compact semigroup, by the nested intersection property.

For fixed k in A, the right translation h -> h o k is continuous in the pointwise weak topology: its value at an argument a is the evaluation of h at the fixed argument k(a). Lemma 8.2 supplies P in A with P o P = P. Choose any a in K and set x=P(a); then P(x)=x.

Write B_m = weak closure{ h(x) : h in H_m }. These are nonempty nested weakly compact subsets of K, so D_x = intersection_m B_m is nonempty and weakly compact. Since P is in A_m, Lemma 8.1 at the single argument x shows that
x = P(x) in norm closure(conv{ h(x) : h in H_m }) subset norm closure(conv B_m).
Consequently, for each f in X*,
max_{z in B_m} f(z) >= f(x).
The maximum exists because B_m is weakly compact. The sets B_m intersect { z : f(z) >= f(x) } are nonempty nested compact sets; their intersection gives a point of D_x at which f >= f(x). Hence
sup_{z in D_x} f(z) >= f(x) for all f in X*.
If x were not in norm closure(conv D_x), separation from the norm-closed convex hull of D_x would give a functional violating this inequality. This proves the proposition. QED.

9. STEP 5: CHOOSING MAPS ADAPTIVELY

Fix the point x supplied by Proposition 8.3. Its convex-hull property permits each new map to be selected at a scale that depends on all preceding choices.

Lemma 9.1 (adaptive finite selection). Let tau > 0. There is a successive selection procedure with the following property. Before the ith map is chosen, prescribe any finite integer m_i >= 1, allowing this prescription to depend on the entire previous history and on any auxiliary data already fixed at that stage. The procedure chooses G_i in H_{m_i} and terminates after finitely many steps, say M, with nonnegative coefficients beta_1,...,beta_M such that
sum_{i=1}^M beta_i = 1,
|| sum_{i=1}^M beta_i G_i(x) - x || < tau.
The coefficients are assigned on termination. Removing zero coefficients gives a nonempty list with positive coefficients, in the original order of selection.

Proof. Choose d_1,...,d_q in D_x and nonnegative coefficients lambda_1,...,lambda_q summing to 1 such that
|| sum_{r=1}^q lambda_r d_r - x || < tau/2.
Fix a metric rho inducing the weak topology on K. Cycle through the targets d_1,...,d_q: at step i, let r(i) be the member of {1,...,q} congruent to i modulo q. Once the threshold m_i has been prescribed, the membership
d_{r(i)} in weak closure{ h(x) : h in H_{m_i} }
allows a choice G_i in H_{m_i} with
rho(G_i(x), d_{r(i)}) < 1/i.
Any auxiliary choices associated with this map may now be made before the next threshold is prescribed. Stop as soon as the convex hull of the selected images comes within distance tau of x.

Suppose that the procedure never stops, and let
C_0 = norm closure(conv{ G_i(x) : i >= 1 }).
For each r, the subsequence assigned to target d_r converges weakly to d_r. The set C_0 is weakly closed by separation, so it contains every d_r and their convex combination sum_r lambda_r d_r. By the definition of C_0, a finite convex combination of the selected images is within tau/2 of this last point. It is therefore within tau of x. All its indices occur in some finite prefix of the selection, contradicting the stopping rule. The procedure thus terminates, and a convex combination at the stopping step supplies the inequality. Deleting its zero coefficients leaves the stated positive list. QED.

By the tail defect bound, the threshold at each selection may impose any positive upper bound on the defect of that individual image. The convex coefficients in Lemma 9.1 provide the return to x in norm.

Finally, fix once and for all the sequence
b_j = R_j(x), j >= 1.
Lemma 7.1 and the displacement estimate give
||T b_j - b_j|| <= 1/j,
||G(b_j) - b_j|| <= c_G / j for G in G.
Thus every fixed finite family of maps in G acts arbitrarily close to the identity at a common sufficiently late b_j.

10. STEP 6: A TREE OF MAPS

Fix the point x and the sequence b_j. We construct a single infinite tree. Each node carries a map in G, and each nonroot node also carries a functional. The maps will allow a subtree to approximate its prescribed label or to transmit a common point b_j. Each functional must be chosen before the weights in its own sibling group are assigned. A family of possible root outputs parameterized by a compact finite-dimensional set makes this order of choices possible.

The root is denoted by r, and L_k denotes the finite, nonempty level of depth k, with L_0 = {r}. Every node has a finite, nonempty ordered list of children. The order on L_{k+1} is obtained by placing these lists consecutively in the order of their parents in L_k. Write parent(v) for the parent of v, and p < v when p is a proper ancestor of v. The symbol < does not denote the order within a level.

Each node v is assigned a map G_v in G and the point y_v = G_v(x). At the root, G_r = identity on K and y_r = x. Each nonroot node has a weight alpha_v > 0, with
sum_{v child of u} alpha_v = 1 for every node u.
Given outputs at the children of u, the output at u is
H_u = G_u( sum_{v child of u} alpha_v H_v ).
Every output belongs to K. If outputs (H_v)_{v in L_k} are prescribed at a cutoff level, let Phi_k((H_v)_{v in L_k}) be the root output obtained by applying this rule strictly above that level. Thus Phi_0(H_r)=H_r; a map at the cutoff itself is not applied again.

Define the path weights by
W_r = 1, W_v = W_{parent(v)} alpha_v for v != r.
An induction gives sum_{v in L_k} W_v = 1. More generally, the sum of the weights at any later level below a given node is the weight of that node. Nonexpansiveness and the triangle inequality also give, by induction up the tree,
||Phi_k((H_v)) - Phi_k((H'_v))|| <= sum_{v in L_k} W_v ||H_v - H'_v||.
Indeed, at each parent the difference is at most the weighted sum of the child differences. Iterating multiplies the weights along each path. Consequently the root error is at most the largest cutoff error, and changing only the output at v in L_k changes the root by at most W_v times the change at v.

11. STEP 7: PREDICTIONS AND THE COMPACT DETECTOR

We first describe the information associated with a candidate node v of depth k >= 1 during construction. At this stage, all levels of depth less than k, including their maps and weights, have already been fixed. Candidates at depth k are selected one parent group at a time, from left to right, and within each group in their order of selection. Let I_v be the finite list of earlier depth-k candidates. We retain their points y_h and parent labels even if some of these candidates have already been discarded from the tree. The map G_v and point y_v have not yet been chosen.

The later switching experiment replaces leaf outputs from right to left. If v is retained, then just after its block has switched, the ideal cutoff state uses y_h at nodes strictly left of v and a common point b at v and to its right. The actual subtree outputs will approximate these prescribed values. We must describe the root outputs of this ideal state before the current level's weights and later children are known.

Put
Theta_v = { (theta_h)_{h in I_v} : theta_h >= 0, sum_{h in I_v, parent(h)=p} theta_h <= 1 for each p in L_{k-1} }.
This is a compact subset of a finite-dimensional space. If I_v is empty, it consists of the single empty tuple. For b in K and theta in Theta_v, set
a_{v,p}(b;theta) = b + sum_{h in I_v, parent(h)=p} theta_h (y_h - b), for p in L_{k-1},
Q_v(b;theta) = Phi_{k-1}( (G_p(a_{v,p}(b;theta)))_{p in L_{k-1}} ).
Each a_{v,p} is a convex combination of b and the earlier candidates belonging to p, so it lies in K. The residual coefficient of b represents all children whose outputs are to be replaced by that common point. Only maps and weights at depths less than k enter the evaluation of Q_v.

For fixed v, the map theta -> Q_v(b;theta) is norm Lipschitz, uniformly over b in K. In fact, since diam K = 1,
||a_{v,p}(b;theta) - a_{v,p}(b;eta)|| <= sum_{h in I_v, parent(h)=p} |theta_h - eta_h|.
Applying the nonexpansive maps G_p and the tree sensitivity gives
||Q_v(b;theta) - Q_v(b;eta)|| <= sum_{h in I_v} |theta_h - eta_h|.
For each theta, weak compactness of K gives the limit
Z_v(theta) = w-lim_{j->U} Q_v(b_j;theta) in K.
The difference of the two sequences at theta and eta converges weakly along U to Z_v(theta)-Z_v(eta). The norm ball of radius sum |theta_h-eta_h| is weakly closed, so the same bound holds for ||Z_v(theta)-Z_v(eta)||. Thus Z_v is continuous into the norm topology, and
E_v = { z_1,...,z_k } union Z_v(Theta_v)
is a nonempty norm-compact subset of K. It is completely determined before G_v is selected. The dense test points will force the branch functionals to tend to zero on the differences z_i-z_j, and hence on Y; the compact prediction image provides comparison limits for block detection. This argument takes weak limits of the already evaluated root outputs; it does not pass a weak limit through a nonlinear map.

12. STEP 8: BUILDING THE TREE

Proposition 12.1 (tree data). There is an infinite ordered tree with the maps, points, and positive weights described above. Each nonroot node v also has a budget e_v > 0, a functional f_v in X* with ||f_v|| <= 1, and the finite earlier-candidate list and predictions just defined. These data have the following properties:
(1) The budgets satisfy
sum_{v != r} e_v <= 1/128.
Define
tau_0 = 1/2, tau_k = 2^{-k-1} min{ e_u : u in L_i, 1 <= i <= k } for k >= 1.
Every node u in L_k satisfies
|| sum_{v child of u} alpha_v y_v - x || <= tau_k.
(2) For every nonroot node v,
sum_{p ancestor of v} ||G_p(y_v) - y_v|| <= e_v,
f_v(y_v - z) >= 1 - e_v for all z in E_v.
In particular, the second inequality holds at every z_i with i <= k when v in L_k.
The budgets, functionals, and prediction sets assigned to retained nodes remain fixed when the remaining weights at their level and all later levels are chosen.

Proof. Start with the root and tau_0 = 1/2. Number all candidate selections throughout the construction by l = 1,2,..., including candidates later discarded. At selection number l, assign the budget
e_v = 2^{-l-8}
before choosing the candidate's map. The sum of all such budgets is at most 1/256, which is more than sufficient for the budget inequality after discarding any candidates.

Suppose the finite levels through L_{k-1} have been constructed and tau_{k-1} has been fixed. Visit the parents in L_{k-1} from left to right. For a given parent, apply Lemma 9.1 with tolerance tau_{k-1}. Its successive map choices will be the candidates for this parent's children. We now specify the threshold to be imposed at every one of these choices.

Let v be the next candidate. Its budget has just been assigned. Using all earlier candidates at the present level, form I_v, Theta_v, Q_v, and E_v. The ancestor maps are fixed, so the number
C_v = sum_{p ancestor of v} c_{G_p}
is finite; take c_{G_r}=0. By Lemma 6.2, there is delta_v > 0 such that any y in K with ||Ty-y|| < delta_v admits a functional f in X*, ||f|| <= 1, satisfying f(y-z) >= 1-e_v for every z in E_v. Choose the integer threshold m so large that
1/m < delta_v, C_v/m <= e_v.
This choice uses only data already available, and is made before selecting G_v.

Require the next map in the adaptive selection to belong to H_m. Every such choice has ||Ty_v-y_v|| <= 1/m by the tail defect bound. The displacement estimate then gives
sum_{p ancestor of v} ||G_p(y_v)-y_v|| <= C_v ||Ty_v-y_v|| <= e_v.
After selecting G_v, choose the functional f_v given by the compact detector. Both requirements in (2) now hold. In particular, they hold for every map choice allowed by this step's threshold, so they are compatible with the weak-neighborhood choices used in Lemma 9.1.

That lemma terminates after finitely many candidates for the parent under consideration. Only then choose the convex coefficients whose average of the points y_v lies within tau_{k-1} of x. Discard the candidates with zero coefficient and retain the others, in their original order, as this parent's children; their positive coefficients are the weights alpha_v. The retained list is nonempty, and its weights sum to one. Keep the labels of discarded candidates in the finite lists used to form subsequent predictions. Thus no already defined prediction or functional changes when zero coefficients are discarded.

There are only finitely many parents, so this completes a finite, nonempty level L_k. Every parent in L_{k-1} now satisfies the child-average inequality. Define tau_k by the tolerance schedule; its defining minimum is over a nonempty finite set of positive numbers. Proceed to the next level. This constructs the entire tree and proves the stated properties. QED.

Once level L_k is complete, each retained v in L_k has a particular parameter theta^v in Theta_v: for h in I_v, set theta^v_h = alpha_h if h was retained, and set theta^v_h = 0 otherwise. The parent-group sums are at most one, as required. Write h <_k v for the left-to-right order on the retained level. For b in K, prescribe the ideal cutoff outputs
H~_h^{v,b} = y_h if h <_k v, and b if h = v or v <_k h.
For every parent p in L_{k-1}, their weighted average is exactly
sum_{h child of p} alpha_h H~_h^{v,b} = b + sum_{h in I_v, parent(h)=p} theta^v_h (y_h - b).
Consequently
Phi_k((H~_h^{v,b})_{h in L_k}) = Q_v(b;theta^v).
In a parent group earlier than that of v, all retained children contribute their y_h and their weights sum to one. In the group containing v, the residual coefficient of b collects v and all later children. In every later parent group, all ideal outputs are b, so their average is b regardless of how many children were eventually selected or what their weights are. This explains why the prediction required no information about those future children. The actual parameters theta^v are used only after the weights are fixed; the compact sets E_v were chosen to cover all their possible values.

13. STEP 9: SWITCHING LEAVES

Fix the tree supplied by Proposition 12.1. Write v <= s when v=s or v is an ancestor of s. For N >= 1, set
T_N = union_{k=0}^N L_k,
B_N(v) = { s in L_N : v <= s } for v in T_N.
The set B_N(v) is a consecutive block in the ordering of L_N, and
sum_{s in B_N(v)} W_s = W_v.
We first show that some path in each finite truncation has all its functionals large on one vector.

Proposition 13.1 (finite witness). For every N >= 1, there are a leaf s in L_N and a vector d in B_Y such that
f_v(d) >= 1/2 for all nonroot v <= s.

Proof. Fix N. All the maps, weights, functionals, and budgets in T_N are already fixed. Put
M_k = min{ e_v : v in L_1 union ... union L_k } for 1 <= k <= N.

Choosing a common terminal point. For each v in T_N \ {r}, use the parameter theta^v in Theta_v from Section 12: it assigns the actual weight alpha_h to each earlier retained candidate h in I_v, and zero to each earlier discarded candidate. The point
q_v = Z_v(theta^v) = w-lim_{j->U} Q_v(b_j;theta^v)
belongs to E_v. By the tree conditions, f_v(y_v-q_v) >= 1-e_v. The definition of this weak ultrafilter limit therefore gives
{ j in N : f_v(y_v - Q_v(b_j;theta^v)) >= 1-2e_v } in U.
There are only finitely many such conditions. Moreover, the displacement estimate and the approximate fixed point property of (b_j) give
sum_{u in T_N} ||G_u(b_j)-b_j|| -> 0.
Intersecting the finitely many ultrafilter members above with a suitable cofinite set, choose one j and write b=b_j so that
f_v(y_v - Q_v(b;theta^v)) >= 1-2e_v for all v in T_N \ {r},
D_N := sum_{u in T_N} ||G_u(b)-b|| <= M_N.

The switching experiment. Initially assign the output H_s = y_s to each leaf s in L_N. Switch these outputs one at a time to H_s = b, proceeding from right to left. At each stage calculate every other output by the tree rule. All outputs belong to K. For v in T_N \ {r}, let U_v and V_v be the root outputs immediately before and immediately after the whole block B_N(v) is switched.

We need two estimates for subtrees whose leaves are all in the same state. If none of the leaves below h in L_k have switched, then
||H_h - y_h|| <= epsilon_{k,N} := sum_{d=k}^{N-1} tau_d.
Here and below an empty sum is zero. At a leaf this is an equality. For an internal node, nonexpansiveness and the child-average inequality give the induction step
||H_h - y_h|| <= || sum_{child u} alpha_u H_u - x || <= sum_{child u} alpha_u ||H_u - y_u|| + || sum_{child u} alpha_u y_u - x || <= epsilon_{k+1,N} + tau_k.
The tolerance schedule yields, for k >= 1 and every v in L_k,
epsilon_{k,N} <= M_k sum_{d=k}^infinity 2^{-d-1} = 2^{-k} M_k <= e_v.
Thus the error is at most e_v for every unchanged node at depth k, regardless of which v in L_k is used in the comparison.

If all the leaves below h have switched, put delta_u = ||G_u(b)-b||. At each internal node of that subtree,
||H_u - b|| <= sum_{child w} alpha_w ||H_w - b|| + delta_u.
The error at each leaf is zero. Iteration gives
||H_h - b|| <= sum_{u in T_N \ L_N, h <= u} (W_u/W_h) delta_u <= D_N <= M_N.
The coefficients W_u/W_h are products of weights below h and are at most one.

Detection of an entire block. Fix v in L_k, where 1 <= k <= N, and consider the stage immediately before its block switches. Its output is within e_v of y_v by the untouched-error estimate. Let p_0=r, p_1,...,p_k=v be the path to v, and put A_i = ||H_{p_i}-y_v|| at this stage. Since every off-path child output and y_v lie in the diameter-one set K, nonexpansiveness gives
A_i <= alpha_{p_{i+1}} A_{i+1} + (1-alpha_{p_{i+1}}) + ||G_{p_i}(y_v)-y_v|| for 0 <= i < k.
The off-path contributions telescope:
sum_{i=0}^{k-1} W_{p_i}(1-alpha_{p_{i+1}}) = sum_{i=0}^{k-1} (W_{p_i}-W_{p_{i+1}}) = 1-W_v.
Unwinding the recurrence and using the tree conditions, we obtain
||U_v - y_v|| <= W_v e_v + (1-W_v) + sum_{i=0}^{k-1} W_{p_i} ||G_{p_i}(y_v)-y_v|| <= 1-W_v+2e_v.

Immediately after the block has switched, precisely the level-k nodes strictly to the left of v have unchanged leaf blocks. By the untouched-error estimate, their outputs are within e_v of their labels y_h. The outputs at all the other level-k nodes are within M_N <= e_v of b by the transmitted-error estimate. The ideal level-k assignment consisting of these y_h on the left and b elsewhere has root output Q_v(b;theta^v) by the prediction-cutoff identity. The sensitivity estimate and sum_{h in L_k} W_h = 1 therefore imply
||V_v - Q_v(b;theta^v)|| <= e_v.
Together, the terminal detection, the before-block estimate, and the after-block estimate give
f_v(U_v - V_v) >= f_v(y_v - Q_v(b;theta^v)) - ||U_v-y_v|| - ||V_v-Q_v(b;theta^v)|| >= (1-2e_v) - (1-W_v+2e_v) - e_v = W_v - 5e_v.

A common witness along one path. For a single leaf s, only its output changes during its switch. By the sensitivity estimate,
||U_s - V_s|| <= W_s ||y_s - b|| <= W_s.
Since W_s > 0 and both root outputs belong to K, the vector
d_s = (U_s - V_s)/W_s
belongs to B_Y. The successive root differences over a consecutive block telescope, so
sum_{s in B_N(v)} W_s d_s = U_v - V_v.
Applying f_v to this identity and using the block detection yields
sum_{s in B_N(v)} W_s (1 - f_v(d_s)) = W_v - f_v(U_v - V_v) <= 5e_v.
Each summand is nonnegative, because ||f_v|| <= 1 and ||d_s|| <= 1. Summing over the nonroot nodes and interchanging the two finite sums gives
sum_{s in L_N} W_s sum_{r != v <= s} (1 - f_v(d_s)) <= 5 sum_{v in T_N \ {r}} e_v <= 5/128.
If a leaf s has f_v(d_s) <= 1/2 for any nonroot node v on its path, its inner sum in the total deficit is at least 1/2. Consequently, the total weight of all such leaves is at most 5/64. Since the leaf weights sum to one, some leaf has f_v(d_s) > 1/2 for every nonroot node v on its path. This proves the proposition. QED.

14. STEP 10: AN INFINITE BRANCH GIVES A CONTRADICTION

Proof of Theorem 1.1. Suppose a counterexample exists. The reduction and constructions in Sections 5-12 give the fixed infinite tree to which Proposition 13.1 applies.

Call a node v feasible if some d in B_Y satisfies
f_u(d) >= 1/2 for all nonroot u <= v.
The root is feasible, and every ancestor of a feasible node is feasible. Proposition 13.1 gives a feasible node at every depth. These nodes therefore form a finitely branching tree with arbitrarily great depth. Starting from the root, choose a child having feasible descendants at arbitrarily great depths, and repeat. Such a child always exists because each node has finitely many children. This produces a branch r, v_1, v_2, ... with v_k in L_k, all of whose nodes are feasible.

For each k >= 1, the set
C_k = { d in B_Y : f_{v_i}(d) >= 1/2 for 1 <= i <= k }
is nonempty and weakly closed in B_Y, and C_{k+1} subset C_k. The normalized differences used in Proposition 13.1 are controlled in the whole unit ball B_Y. Reflexivity supplies weak compactness of this ball, as established in Section 5. It follows that there is one vector
d in intersection_{k=1}^infinity C_k,
f_{v_k}(d) >= 1/2 for k >= 1.

On the other hand, the functionals on every branch converge pointwise to zero on Y. Indeed, for fixed i,j and k >= max{i,j}, the tree conditions and diam K = 1 give
1-e_{v_k} <= f_{v_k}(y_{v_k}-z_i) <= 1,
1-e_{v_k} <= f_{v_k}(y_{v_k}-z_j) <= 1.
Subtracting these inequalities yields
|f_{v_k}(z_i-z_j)| <= e_{v_k} -> 0,
where the convergence follows from the summability of the budgets. The linear span of the differences z_i-z_j is dense in Y = closure(span(K-K)). Hence the bound ||f_{v_k}|| <= 1 extends this convergence to every d' in Y: for any vector a in that span,
|f_{v_k}(d')| <= ||d'-a|| + |f_{v_k}(a)|,
and one first lets k tend to infinity and then lets a approach d'. In particular f_{v_k}(d) -> 0, contradicting f_{v_k}(d) >= 1/2. The assumed counterexample cannot exist. QED.

15. THE COMMUTING-FAMILY COROLLARY

Corollary 1.2 follows from Bruck's theorem. We state it for reference.

Theorem 15.1 (Bruck 1974). Let C be a nonempty weakly compact convex subset of a Banach space. Suppose C has the fixed point property for nonexpansive selfmaps and the conditional fixed point property: for every nonexpansive f: C -> C and every nonempty closed convex f-invariant D subset C, f has a fixed point in D. Then every pairwise commuting family of nonexpansive selfmaps of C has a common fixed point, and the common fixed set is a nonexpansive retract of C.

Proof of Corollary 1.2. For the empty family, take R = identity. Otherwise, Theorem 1.1 applies to every nonempty closed bounded convex subset D of C, since a relatively norm-closed subset of the norm-closed set C is norm closed in X. Thus C has Bruck's hereditary fixed point property and, by taking D=C, the fixed point property. If f: C -> C is nonexpansive and such a subset D is f-invariant, the same theorem applied to f restricted to D gives a fixed point in D. Hence C also has Bruck's conditional fixed point property. The ordinary fixed point and conditional fixed point properties just proved, together with weak compactness of C by reflexivity, satisfy the corresponding hypotheses of Theorem 15.1. That theorem gives the claimed nonempty nonexpansive retract. QED.

16. APPENDIX: THE FOUNDATIONAL FACTS

Proof of Lemma 5.1. We begin with the Hahn-Banach extension argument underlying the first two assertions. Suppose that a linear functional l on a subspace M is dominated by a continuous sublinear function p on X. To extend it to M+R b, where b is not in M, choose its value at b in the interval
sup_{a in M} (l(a)-p(a-b)) <= l(b) <= inf_{c in M} (p(c+b)-l(c)).
This interval is nonempty because l(a)+l(c) <= p(a+c) <= p(a-b)+p(c+b). Its endpoints are finite, as is seen by setting a=0 or c=0 in this inequality. The displayed bounds give domination on a+b and a-b; positive homogeneity then gives domination on a+tb for every real t. Unions of chains of dominated extensions remain dominated extensions, so Zorn's lemma gives an extension to X. It is continuous because domination of both v and -v bounds its absolute value near zero. Applying this construction with p = norm and l(tv)=t||v|| gives a norming functional (use the zero functional when v=0). In particular,
||v|| = sup{ f(v) : f in X*, ||f|| <= 1 }.

For separation, let q lie outside a nonempty norm-closed convex set D. Choose rho > 0 such that the open convex set U = D + { v : ||v|| < rho } still excludes q, and fix u in U. The gauge
p(v) = inf{ t > 0 : v in t(U-u) }
is finite, nonnegative, positively homogeneous, and subadditive. For the last property, if v in s(U-u) and w in t(U-u), convexity gives v+w in (s+t)(U-u), and one takes infima. Since U-u is open, convex, and contains zero, { v : p(v) < 1 } = U-u: one inclusion follows from convexity, and the other by extending a little past a given point along its ray using openness. A ball about zero contained in U-u gives p(v) <= c||v|| for some c; subadditivity then makes p continuous. On the line through q-u, the functional taking the value p(q-u) at q-u is dominated by p; for negative multiples this follows from -p(q-u) <= p(u-q). Its extension f therefore satisfies
f(z-u) < 1 <= f(q-u) for z in U.
In particular f is not zero, and taking the supremum over the ball of radius rho added to any d in D gives f(d)+rho||f|| <= f(q). Thus f separates q from D with a positive gap. This proves weak closedness of D. Applied to closed balls it proves weak lower semicontinuity of the norm. Separation also shows that the weak closure of a convex set equals its norm closure. On X^r, equipped with the maximum norm, every continuous linear functional has the form sum_{i=1}^r f_i(x_i), with f_i in X*, by restriction to the coordinate subspaces. This proves the assertion about the finite-product topology and allows the same separation argument there.

Here are the compactness details. A proper filter is a family of subsets closed under finite intersections and supersets, containing the whole space but not the empty set. By Zorn's lemma it extends to a maximal proper filter, called an ultrafilter. For every subset an ultrafilter contains either that subset or its complement: if the subset cannot be added while preserving the filter property, an existing filter member misses it. An ultrafilter converges to a point when it contains every neighborhood of that point. In a compact space it converges: the closures of its members have the finite intersection property, and any point in their intersection is a limit by the preceding either-or property. Limits are unique in a Hausdorff space. Conversely, if every ultrafilter converges, extend any family of closed sets with the finite intersection property to an ultrafilter; its limit belongs to all those sets. This is the closed-set criterion for compactness. An ultrafilter on a product of compact spaces has a limit in each coordinate, and the tuple of these limits is its limit, since a basic product neighborhood restricts only finitely many coordinates. This proves product compactness.

Now let D subset X be bounded, norm closed, and convex, with X reflexive. Given an ultrafilter V on D, each bounded real evaluation has a limit in a compact interval, and
L(f) = lim_{V} f(d) for f in X*
defines a linear functional with |L(f)| <= M||f||, where M = sup_{d in D} ||d||. Linearity follows by intersecting the filter members on which each of two evaluations is close to its limit. Reflexivity supplies a in X with L(f)=f(a) for every f. Thus V converges weakly to a, and weak closedness gives a in D. The ultrafilter criterion proves weak compactness. QED.
