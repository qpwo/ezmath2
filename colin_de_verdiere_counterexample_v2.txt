PART 1. THE CONJECTURE AND THE COUNTEREXAMPLE
================================================================


----------------------------------------------------------------
1.  The invariant mu(G)
----------------------------------------------------------------

Let G = (V, E) be a finite, nonempty, simple graph with |V| = n.
A real symmetric matrix M indexed by V is called WELL-SIGNED for G
if, for every pair u != v in V,

    M_{uv} <  0    when {u,v} is an edge of G,
    M_{uv} =  0    when {u,v} is NOT an edge of G.

Diagonal entries M_{uu} are unconstrained.

M has the STRONG ARNOLD PROPERTY (SAP) for G if the only real
symmetric matrix X satisfying

    M X = 0,    X_{uu} = 0 for every u in V,
                X_{uv} = 0 for every {u,v} in E(G)

is the zero matrix X = 0. This is a transversality condition; it
ensures the matrix class is a manifold near M, which is what make
mu(G) behave well under perturbation and minor operations.

Write n_-(M) for the number of negative eigenvalues of M, counted
with multiplicity. The Colin de Verdiere invariant is

   mu(G)  =  max {  dim ker M  :
                     M is well-signed for G,
                     n_-(M) = 1,
                     M has the Strong Arnold Property }.

The maximum is achieved over a nonempty finite family, so it is a
well-defined nonnegative integer. Let us see why the family is
nonempty.

Take the diagonal matrix D with one diagonal entry -1 and all
other diagonal entries +1. Add very small negative entries at the
edge positions of G (the diagonal is kept fixed). For
sufficiently small perturbation size, the spectrum is close to
that of D, so n_-(M) = 1 still, and M remains invertible. An
invertible matrix satisfies SAP trivially, because M X = 0
already forces X = 0. This gives at least one admissible matrix,
so the class is nonempty and mu(G) >= 0.

Example 1.1.  mu(K_n) = n - 1 for every n >= 1.

  Lower bound: take M = -J_n, minus the all-ones matrix. It has
  one negative eigenvalue (-n) and n-1 zero eigenvalues, so
  dim ker = n-1 and n_- = 1. For K_n every pair of distinct
  vertices is an edge, so every off-diagonal entry must be
  negative; -J_n has off-diagonal entries -1 < 0. It is well-signed.
  SAP: M X = 0 becomes J_n X = 0, so each column of X has
  coordinate-sum zero. But X_{uv} = 0 for all u != v (every pair
  in K_n is an edge), so X is diagonal. Combined with X_{uu} = 0,
  we get X = 0. SAP holds. Hence mu(K_n) >= n - 1.

  Upper bound: any well-signed M with n_- = 1 has rank at least
  one, hence dim ker M <= n-1. Thus mu(K_n) <= n-1. Combine.

Example 1.2.  mu(edgeless graph on one vertex) = 0. More
generally, mu(G) = 0 exactly when G is edgeless. We will not use
this below.


----------------------------------------------------------------
2.  The chromatic conjecture
----------------------------------------------------------------

Write chi(G) for the CHROMATIC NUMBER of G: the least number of
colours needed for a proper vertex colouring of G, i.e. a
colouring in which adjacent vertices receive different colours.

Colin de Verdiere (1990) proposed

    (C)   chi(G) <= mu(G) + 1    for every finite nonempty G,

and conjectured that it always holds. It is tight for complete
graphs: chi(K_n) = n = mu(K_n) + 1.

Relation to Hadwiger's conjecture.  Let h(G) be the largest
integer t such that K_t is a minor of G. Using minor-monotonicity
of mu (which we take as given; see van der Holst-Lovasz-Schrijver
1999) together with mu(K_t) = t - 1 (Example 1.1), we get

   h(G) <= mu(G) + 1.

Therefore, if (C) holds, then chi(G) <= h(G) for every G. This is
Hadwiger's conjecture (1943). So (C) is at least as strong as
Hadwiger; disproving (C) weakly would disprove Hadwiger. Our main
theorem will in fact directly construct graphs violating both.

The main theorem.

MAIN THEOREM (Theorem 2.1).
   There are finite graphs G of arbitrarily large order for which

      alpha(G) <= 2
      and    mu(G) + 1 < |V(G)| / 2 <= chi(G).

   In particular, the chromatic conjecture (C) is false, and
   Hadwiger's inequality chi <= h fails on these graphs.

Here alpha(G) is the INDEPENDENCE NUMBER (largest size of a set
of pairwise non-adjacent vertices). The hypothesis alpha(G) <= 2
immediately gives chi(G) >= |V(G)|/2: every colour class is an
independent set, hence has at most 2 vertices, so at least half
of the vertices need their own colour classes.

The stronger matrix fact.  The proof of Theorem 2.1 rests on the
following statement, which is proved without using the Strong
Arnold Property at all:

   "If G is a graph of the sort that Theorem 2.1 will construct,
    then EVERY well-signed M with n_-(M) = 1 has rank > |V(G)|/2
    + 1."

Rank-nullity then gives dim ker M < |V(G)|/2 - 1. Maximizing over
all admissible M (whether SAP or not) gives the desired mu(G)+1 <
|V(G)|/2. Because SAP is not used, the bound also applies to the
larger class kappa(G) = max{ dim ker M : M well-signed for G,
n_-(M) = 1 } studied by Lovasz and Schrijver (2017).


----------------------------------------------------------------
3.  How the proof of Theorem 2.1 goes
----------------------------------------------------------------

We proceed in two independent steps:

   STEP A (Part 2). MATRIX OBSTRUCTION.
     Provide a combinatorial sufficient condition on a base graph H
     (three "conflict" properties, see below) under which the
     clique blow-up H[K_s] forces every well-signed one-negative
     matrix to have rank strictly greater than ms/2 + 1, where
     m = |V(H)| and s is the blow-up factor. This is the content
     of Theorem 4.2 below.

   STEP B (Parts 3-5). BASE GRAPH EXISTENCE.
     Show that graphs satisfying these three conflict properties
     exist in arbitrarily large order. This is Theorem 4.1 below.

Combining the two gives Theorem 2.1: fix a base graph H from
Step B, then let s grow in Step A. The resulting graphs H[K_s]
already have alpha <= 2 (because alpha(H) <= 2, see 1.2 in Part 2
below) and chromatic number at least ms/2. Step A gives
mu(H[K_s]) + 1 < ms/2. Hence (C) fails for H[K_s].

The bulk of the work is Step B, which is a probabilistic existence
argument. The construction of H goes through an intermediate
finite probability space that we now describe in outline; the
details fill Parts 3-5.

Layer 1: F_2 tensor geometry.  For each large n, we build a
finite vector space X of "cut profiles" over the field F_2, a
finite set Omega_n of "frames" (each a tuple of linear maps into
a vector space over F_2), and a symmetric binary relation
"hole" on pairs of frames. A hole between two frames means that a
certain system of 4 linear-algebraic equations (all over F_2) is
solvable.  The system is very particular: it involves a
"witness" in X at each endpoint, and the equations of the system
encode a triangle cancellation that makes the "hole" relation
triangle-free.

Layer 2: Sample frames, then define adjacency.  Fix a probability
law pi on Omega_n.  Take m independent samples F_1, ..., F_m
from pi and put them at the m "positions" of a graph G.  Put an
edge between positions i != j exactly when F_i and F_j have NO
hole.  Choosing pi correctly ensures:
  - the resulting graph has alpha(G) <= 2 for EVERY sample (this
    is deterministic and follows from triangle-freeness of the
    hole relation),
  - with probability -> 1, G satisfies the three conflict
    properties (this is the statistical heart of the proof).

Layer 3: The two distribution tests.  The three conflict
properties reduce to two "distribution tests" on pi.  Each test
says: given two probability measures sigma_1, sigma_2 on Omega_n
that are constrained to have "small density" (some caps) under
pi, a certain conflict event has probability at least
    2^{-100gN + o(N)}
for a small exponent gN. Here g and N are parameters that grow
with n; 100gN is a "safety margin" below the scale we need. The
two tests are:
  - The COLOURED test: independent draws A ~ sigma_1 and
    B ~ sigma_2 that carry different colours (from a small
    palette) with each colour having mass at most eta_col under
    the projected law pi.  Conclusion: with probability at least
    2^{-100gN + o(N)}, A and B have all four cross pairs
    holes.
  - The ASYMMETRIC test: a draw A ~ sigma from a unit law and an
    independent point Z ~ theta from a point law.  Conclusion:
    with probability at least 2^{-100gN + o(N)}, every cross pair
    between the endpoints of A and the point Z is a hole.

Layer 4: Thinning.  A crucial ingredient is to replace pi with a
thinned law pi' that keeps the primal marginal exactly but
conditions the "channel" part of each frame into a sparse random
subset. The constructive thinning lemma (Lemma 14.1) gives a new
law with full pair density only 2^{eps_ch N} times worse than the
original, but with two extra properties:
  - "translate avoidance" for the channel images,
  - "point-mass" bounds inside thinned cells.
These properties feed the collision argument in Layer 5.

Layer 5: Graph transfer.  A deterministic fingerprint argument of
Kleitman-Winston / Samotij turns "the three conflict properties
hold in expectation with probability -> 1" into "there is a
single finite sample G that satisfies all three conflict
properties simultaneously".  This is the content of Part 5.

The technical content of Parts 3-5 is mostly probability
estimates: mixing, Fourier inversion, entropy bounds, and a
"phase-alternative" dichotomy that distinguishes colorable
perceptible behavior from an "almost-linear" pattern that leads
to a contradiction via rank growth.




----------------------------------------------------------------
4.  The base graph theorem and the matrix obstruction
----------------------------------------------------------------

Holes and conflicts.

A HOLE of a graph is a pair of distinct nonadjacent vertices.

Two disjoint edges e = {a, b} and f = {c, d} CONFLICT if all four
cross pairs {a,c}, {a,d}, {b,c}, {b,d} are holes.

An edge e = {u, v} and a vertex w (w not in e) CONFLICT if both
{u,w} and {v,w} are holes.

Note: "conflict" for edge-edge requires disjointness; for
edge-vertex requires the vertex to be strictly outside the edge.
Two edges sharing an endpoint never conflict. An edge and one of
its endpoints never conflict.

BASE GRAPH THEOREM (Theorem 4.1).
   There is a numerical constant a > 0 with the following
   property. For every beta > 0, there exist arbitrarily large
   integers m and graphs H on m vertices such that alpha(H) <= 2
   and the following three properties hold:

   (G1) [coloured conflict]  Every matching of size at least m/20
        whose edges have been partitioned into at most a*m-sized
        classes contains two conflicting edges lying in
        different classes.

   (G2) [edge-point conflict]  Every matching of size at least
        beta*m and every vertex set of size at least beta*m
        contain a conflicting edge-vertex pair.

   (G3) [hole density]  Every two vertex sets of size at least
        beta*m contain a cross hole.

   The constant a is fixed independently of m and beta.

Note what "cross hole" means in (G3): two vertices, one from each
of the two sets, that form a hole. The two sets are allowed to
overlap.

MATRIX OBSTRUCTION THEOREM (Theorem 4.2).
   For every a in (0, 1] there exist beta_0(a) > 0 and m_0(a) in
   N with the following property.  Let 0 < beta <= beta_0(a) and
   m >= m_0(a), and let G be an m-vertex graph satisfying (G1),
   (G2), (G3) with these parameters.  Then there exists s_0
   (depending on G, a, beta) such that for every integer s >= s_0
   the following holds:

       every real symmetric well-signed matrix M for the clique
       blow-up G[K_s] with exactly one negative eigenvalue
       satisfies rank M > ms/2 + 1.

   Consequently mu(G[K_s]) + 1 < ms/2 for every s >= s_0.

Given Theorem 4.2, Theorem 2.1 follows immediately:

PROOF OF THEOREM 2.1 FROM THEOREMS 4.1 AND 4.2.
   Fix a and beta from Theorem 4.1 (with beta also at most
   beta_0(a) from 4.2).  Choose H on m >= m_0(a) vertices from
   Theorem 4.1.  Take s >= s_0(G, a, beta) from Theorem 4.2 and
   put G = H[K_s].  Then:
     - alpha(G) = alpha(H[K_s]) <= alpha(H) <= 2.  (An independent
       set uses at most one vertex per block, and its labels form
       an independent set in H.)
     - chi(G) >= ms/2 = |V(G)|/2.  (Colour classes are independent
       so have at most two vertices each.)
     - mu(G) + 1 < ms/2 by Theorem 4.2.
   Since m can be taken arbitrarily large, this is an unbounded
   family of counterexamples to (C).

Part 2 does
Theorem 4.2; Parts 3-5 do Theorem 4.1.

[The blow-up G[K_s].]
Given a graph G on vertex set U (|U| = m) and an integer s >= 1,
the clique blow-up G[K_s] has vertex set U x {1, ..., s}.  Two
vertices (u, i) and (v, j) are adjacent exactly when:
   - u = v and i != j  (inside each block we have a clique), OR
   - u != v and {u,v} is an edge of G  (all pairs of vertices
     across adjacent blocks are adjacent).
There are no edges between blocks corresponding to nonedges of G.

Observation 4.3.  For any well-signed matrix M for G[K_s], the
"hole" pairs of G[K_s] (that is, pairs of vertices at different
blocks corresponding to nonedges of G) automatically have M_{uv} =
0.  Conversely, every edge of G[K_s] corresponds to a negative
entry M_{uv}.  This is exactly why "well-signed for the blow-up"
extends the block structure.


================================================================
PART 2.  PROOF OF THE MATRIX OBSTRUCTION
================================================================

Goal of Part 2: prove Theorem 4.2.  Fix a in (0, 1], beta > 0,
m >= 1, and a graph G on m vertices satisfying (G1)-(G3).  Let s be
a positive integer and put v = ms, the order of the clique blow-up
G[K_s].  We will show that, provided beta is small enough (as a
function of a) and s is large enough (as a function of G, a,
beta), every real symmetric well-signed matrix M for G[K_s] with
exactly one negative eigenvalue has rank strictly greater than
v/2 + 1.

The proof uses two normalizations:

  STEP 1. Normalize each clique block of M by a positive-definite
  inverse square root.  This reduces the problem to studying a
  symmetric matrix A_s = I - B_s with B_s entrywise nonnegative and
  zero diagonal.  Then extract an almost-perfect matching of
  coordinates.

  STEP 2. Group matched pairs by their base edge label, apply a
  second normalization within each candidate group, and use the
  sign rigidity of the well-signed entries to produce extra
  positive-rank directions.

The contradiction with rank <= v/2 + 1 closes the argument.

5.  Lorentz spaces
----------------------------------------------------------------

Since M has exactly one negative eigenvalue, the symmetric bilinear
form  (x, y) |-> x^T M y  has signature (1, v-1).  After change of
basis it equals the LORENTZ FORM

   [x, y]   =  - x_0 y_0  +  x_1 y_1  + ... + x_{v-1} y_{v-1}

on R^v.  Concretely: diagonalize M = U D U^T with D = diag(d_0, ...,
d_{v-1}), d_0 < 0 <= d_1 <= ... <= d_{v-1}, then take v_u = D^{1/2}
U^T e_u.  Then

   M_{u u'}   =   [v_u, v_{u'}],

dim span {v_u} = rank M, and well-signedness is:

   [v_u, v_{u'}]   <  0   at an edge {u, u'} of G[K_s],
   [v_u, v_{u'}]   =  0   at a nonedge {u, u'} of G[K_s].

We call the v_u the LORENTZ VECTORS of the vertices.

Conventions.  For a list X = (x_1, ..., x_k) of Lorentz vectors,
<X, X> denotes the k x k Gram matrix with entries [x_i, x_j],
and X itself may be treated as a linear map from the coefficient
space R^k into the Lorentz space.  For two lists X, Y, <X, Y> is
the rectangular Gram matrix.

Two elementary facts about positive definite matrices.

Lemma 5.1 (positive inverse square root).
Let D be a real symmetric positive definite matrix with
nonpositive off-diagonal entries.  Then D^{-1/2} is entrywise
nonnegative, with strictly positive diagonal entries.

Proof.  Choose c > || D ||.  Then A = I - D/c has nonnegative
entries and eigenvalues in [0, 1).  The binomial series

   D^{-1/2}  =  c^{-1/2} (I - A)^{-1/2}
             =  c^{-1/2} sum_{k=0}^infty binom(2k, k) 4^{-k} A^k

converges absolutely to D^{-1/2}.  Every term is entrywise
nonnegative; the k = 0 term is a positive multiple of the identity,
so the diagonal entries are strictly positive.  []

Lemma 5.2 (positive semidefinite singular case).
Let D be a symmetric positive semidefinite matrix with nonpositive
off-diagonal entries, and suppose the graph of its strictly negative
off-diagonal entries is connected.  Then either D is positive
definite, or:
  (i) dim ker D = 1, and the kernel is spanned by a vector with all
      entries strictly positive;
  (ii) every proper principal submatrix of D is positive definite.

Proof.  Pick c > lambda_max(D).  The matrix A = cI - D is symmetric
with nonnegative entries, positive diagonal, and connected
off-diagonal support.  By Perron-Frobenius:
  - A has a positive eigenvector x with eigenvalue lambda_max(A) = c,
  - this eigenvalue is simple and x has all strictly positive entries.
So: either D is positive definite (if dim ker D = 0), or dim ker D =
1 with kernel == span(x) (i.e. kernel is the eigenspace of A at c).
In the singular case, if a proper principal submatrix D' of D were
singular, we could extend a nonzero vector z supported on the
retained index set with Dz = 0 by zeros to a nonzero vector w with
Dw = 0.  But then w must be a multiple of x, and x has full support,
so w cannot have any zero coordinates.  Contradiction.  []

Lemma 5.3 (spectral support).
Let v_j -> infty and B_j be a sequence of symmetric entrywise
nonnegative d_j x d_j matrices with zero diagonal.  Assume
sup_j || B_j || < infty and n_-(I - B_j) <= 1.  Let nu_j be the
eigenvalue measure of B_j, normalized: nu_j(A) = (1/v_j) *
#{eigenvalues of B_j in A}.  Then every weak subsequential limit
nu of nu_j satisfies:
  (a) nu is supported on [-1, 1];
  (b) int x nu(dx) = 0;
  (c) for every eps > 0, #(eigenvalues of I - B_j outside
      [-eps, 2+eps]) = o(v_j).

If in addition  liminf_j d_j / v_j >= 1 - delta  and
rank(I - B_j) <= v_j/2 + 1, then

   limsup_j   || B_j^2 - I ||_F^2 / v_j  <=  2 delta.

Proof.  Since B_j is entrywise nonnegative with zero diagonal,
trace(B_j) = 0, giving (b).  Since n_-(I - B_j) <= 1, at most one
eigenvalue of B_j exceeds 1, so nu is supported in (-infty, 1].

Now let k >= 0 be an integer.  The matrix B_j^{2k+1} is entrywise
nonnegative (product of nonnegative matrices), so its trace is a
nonnegative real number.  Therefore int x^{2k+1} nu_j(dx) >= 0 for
every k.  If nu put mass h > 0 on (-infty, -1-eps], then
int x^{2k+1} nu(dx) <= theta - h(1+eps)^{2k+1} < 0 for large k,
contradicting nonnegativity of all odd moments as j -> infty (and
then k -> infty, using polynomial-integral convergence).  So nu is
supported in [-1, 1].  Point (c) follows from the same support
bound: eigenvalues outside [-eps, 2+eps] correspond to eigenmass
that must vanish in the limit.

For the second part: assume the extra hypotheses.  Since rank(I -
B_j) <= v_j/2 + 1, at least d_j - v_j/2 - 1 eigenvalues of I - B_j
are zero.  Therefore at least d_j - v_j/2 - 1 eigenvalues of B_j
are exactly 1.  So nu({1}) >= liminf d_j/v_j - 1/2 >= theta - 1/2,
where theta = nu(R) = lim nu_j(R).

Then

   int_{x != 1} (1 + x) nu(dx)
   = theta - 2 nu({1})
   <= theta - 2(theta - 1/2) = 1 - theta <= delta.

For x in [-1, 1], we have (1 - x^2)^2 <= 1 - x^2 <= 2(1 + x),
with both sides vanishing at x = 1.  So

   lim_j  || B_j^2 - I ||_F^2 / v_j
   =  int (1 - x^2)^2 nu(dx)
   <= 2 int (1 + x) nu(dx)
   <= 2 delta.

The "= int" step comes from polynomial-integral convergence on the
compact support that we have just proved.  []

Remark 5.4.  The Frobenius bound in Lemma 5.3 is what drives Step 1
below.  It gives || B_s^2 - I ||_F^2 = O(delta v), with delta the
"rank deficit" of the well-signed construction, and delta depends
only on beta and 1/m, not on s.  So the Frobenius error becomes
relatively negligible for large s.


----------------------------------------------------------------
6.  First normalization
----------------------------------------------------------------

Let M be well-signed for G[K_s], one-negative, with rank M <=
v/2 + 1.  We will derive a contradiction for large s.

Throughout, all "inner products" [x, y] are in the Lorentz form of
section 5, and v_u denotes the Lorentz vector of the vertex u.  The
vertices of G[K_s] are labeled (u, i) for u in V(G) and 1 <= i <= s.

STEP 6.1.  Clique blocks with a negative eigenvalue.

For each u in V(G), let D_u be the s x s diagonal block
(D_u)_{ij} = [v_{(u,i)}, v_{(u,j)}].  Call u "negative" if D_u has
a negative eigenvalue.

Claim A.  If u and u' are both negative and {u, u'} is NOT an edge
of G, then n_-(M) >= 2.

Proof.  Let x in R^s be a negative-eigenvector of D_u and x' in R^s
a negative-eigenvector of D_{u'}.  Form vectors X = sum_i x_i
v_{(u, i)} in the Lorentz space and X' = sum_j x'_j v_{(u', j)}.
Then [X, X] = x^T D_u x < 0 and [X', X'] = x'^T D_{u'} x' < 0.
If {u, u'} is not an edge of G, then every entry M_{(u,i),(u',j)} =
[v_{(u,i)}, v_{(u',j)}] = 0, so

   [X, X']  =  sum_{i,j} x_i x'_j [v_{(u,i)}, v_{(u',j)}]  =  0.

Two orthogonal negative directions give two negative eigenvalues of
M.  Contradiction.  []

By Claim A, the set C = {u in V : u is negative} is a CLIQUE in G.

Claim B.  |C| < 2q, where q = ceil(beta m).

Proof.  Suppose |C| >= 2q.  Split C into two disjoint q-element
subsets A, B.  By G3, A and B contain a cross hole, i.e. vertices
u in A, u' in B with {u, u'} a nonedge of G.  But C is a clique,
so every pair in C is an edge.  Contradiction.  []

STEP 6.2.  Positive semidefinite clique blocks.

For u not in C, D_u is PSD.  Two cases:

  (a) D_u is positive definite.  Keep all s coordinates.
  (b) D_u is singular.  By Lemma 5.2, the strictly negative
      off-diagonal entries of D_u have a connected graph, so the
      kernel is 1-dimensional and spanned by a positive vector, and
      deleting one row/column gives a positive definite principal
      submatrix.  Delete one coordinate (say index s), keep the
      (s-1)-size principal submatrix.

After this reduction, each u not in C has a working block of size
s_u in {s-1, s}, and the working block is positive definite.

The working dimension  d_s  =  sum_{u not in C} s_u   satisfies

   d_s  >=  (m - 2q)(s - 1).

STEP 6.3.  First-scale normalization.

Fix u not in C with working block D_u (positive definite of size
s_u x s_u) and working lists V_u of s_u Lorentz vectors (the original
v_{(u, i)}) restricted to the retained coordinates, so <V_u, V_u> =
D_u.  Define

   X_u  =  V_u  D_u^{-1/2},        so   <X_u, X_u>  =  I_{s_u}.

By Lemma 5.1, D_u^{-1/2} is entrywise nonnegative.  Therefore, for
u, u' distinct in V(G) minus C, the cross block <X_u, X_{u'}> is
entrywise nonpositive: it equals <V_u, V_{u'}> D_u^{-1/2}
(D_{u'}^{-1/2}), a sum with nonnegative coefficients (from
D^{-1/2}'s entries) of the nonpositive entries of <V_u, V_{u'}>;
only nonpositive contributions appear.

Assemble X = (X_u : u in V(G) minus C) as a single list of d_s columns.
Let A_s = <X, X> be the d_s x d_s Gram matrix.  Then:

  - A_s has identity diagonal blocks (by construction),
  - A_s has nonpositive off-diagonal blocks,
  - B_s := I_{d_s} - A_s is entrywise nonnegative with zero
    diagonal,
  - rank(A_s) = rank(I_{d_s} - B_s) <= rank(M) <= v/2 + 1,
  - n_-(-I + A_s) = n_-(A_s) - 1 + 1 ... more carefully: since
    n_-(M) = 1 and X u's are linear combinations of v u's with
    nonneg coefficients in the D^{-1/2}, the matrix A_s inherits
    n_-(A_s) = 1 (the D^{-1/2} act as inner-product-preserving
    transformations on positive-definite subspaces; they can't
    introduce new negative directions because they take a positive-
    definite subspace to a positive-definite subspace).

Let us be careful about the "-I + A_s": I - B_s = A_s, so I - B_s
is A_s.  Because B_s is entrywise nonnegative with zero diagonal,
we can apply Lemma 5.3 to B_s.

Bounding || B_s ||.  The operator norm of B_s could in principle
grow with s.  We control it via the hyperbolic-tree lemma (Lemma
8.3 below), whose proof is one of the geometric inputs to the
argument.  For now we take as granted:

   (Lemma 8.3, applied to A_s)
   || B_s || <= K

where K depends only on the number of blocks m and on the
"conflict geometry" of G, not on s.

Given this bound, Lemma 5.3 applied with v_j = v = ms, d_j = d_s,
delta = 5 beta + 5/m (the loss from d_s / v >= 1 - delta), gives:

   limsup_s   || B_s^2 - I ||_F^2 / v  <=  2 delta.

In particular, for all sufficiently large s (choosing s >= s_0(G,
a, beta) large enough):

   || B_s^2 - I ||_F^2   <=   3 delta v.                        (*)

STEP 6.4.  Coordinate-pair extraction.

Lemma 6.1.  Let B be a symmetric entrywise-nonnegative d x d matrix
(zero diagonal) with d <= v and

   || B^2 - I ||_F^2  <=  eps v,   0 < eps <= 8^{-4},
   tau  :=  eps^{1/4}.

Then there is a coordinate matching (a partial matching W with
0-1 entries, each row having at most one off-diagonal 1) such that

   (a) # omitted coordinates <= 5 tau^2 v,
   (b) || B - W ||_F^2 <= 8 tau^2 v,
   (c) |B_{ij} - 1| <= tau on every retained pair {i, j}.

Every retained pair has B_{ij} >= 6/7 (in particular B_{ij} > 0).

Proof.  Set d_i = sum_j B_{ij}^2 and r_i = d_i^2 - sum_j B_{ij}^4.
The diagonal entries of B^2 - I give

   sum_i (d_i - 1)^2  <=  eps v.

Nonnegativity gives

   sum_i r_i  =  sum_{j != k} sum_i B_{ij}^2 B_{ik}^2
              <=  sum_{j != k} (sum_i B_{ij} B_{ik})^2
              <=  eps v.

Call row i "good" if |d_i - 1| <= tau and r_i <= tau^2.  The
number of bad rows is at most 2 tau^2 v (from the two displays
above).  In a good row i, let a_i = max_j B_{ij}^2.  Then

   a_i  >=  sum_j B_{ij}^4 / d_i  =  d_i - r_i / d_i,
   d_i - a_i  <=  tau^2 / (1 - tau).

With tau <= 1/8, this gives a_i >= 6/7, d_i - a_i <= (8/7) tau^2,
and |sqrt(a_i) - 1| <= tau.

The dominant entry (a maximal B_{ij}^2) is unique: if two entries
were both >= 6/7 in their square, they would sum to > 1, so
d_i >= 12/7 > d_i, impossible.  If the other endpoint of the
dominant entry is also good, symmetry forces it to be the dominant
entry there too.  These are the good-good matches.

Now let S be a set of rows.  Cauchy-Schwarz gives

   sum_{i in S} d_i  <=  |S| + sqrt(|S| eps v).                  (**)

So the total row mass at bad rows is at most (2 + sqrt(2) tau) tau^2 v.
Each good row whose dominant endpoint is bad contributes at least
6/7 (by symmetry) to this mass.  Hence:

   # {omitted coordinates} <= 5 tau^2 v.

For (b): a retained row contributes at most
   tau^2 + (8/7) tau^2 = (15/7) tau^2
to || B - W ||_F^2.  Summing over retained rows, and using (**) to
bound the mass at omitted rows:

   || B - W ||_F^2  <=  (15/7 + (5 + sqrt(5) tau)) tau^2 v
                    <=  8 tau^2 v.

This uses tau <= 1/8.  []

Apply Lemma 6.1 to B_s with eps = (3 delta)^{1/4} =: tau.  Actually
let me set tau = (3 delta)^{1/4} and eps = 3 delta, checking that
eps = tau^4 and eps <= 8^{-4} for delta small enough (this is the
smallness requirement on beta).

The matching W has:

   p_0  :=  #retained pairs  satisfies
       p_0 / v  >=  1/2 - delta/2 - (5/2) tau^2,                 (6.1)

   || B_s - W ||_F^2  <=  8 tau^2 v,                             (6.2)

   |(B_s)_{ij} - 1| <= tau on each retained pair {i, j}.         (6.3)

Every retained pair connects two different base labels u, u' of
V(G) minus C with {u, u'} an edge of G: because B_s is zero on the
diagonal blocks (identity blocks in A_s) and zero across nonedges of
G.

STEP 6.5.  Grouping by base label pair.

For each base label pair e = {u, u'} in E(G), let k_e(s) be the
number of retained matched pairs of type e.  Pass to a subsequence
with

   k_e(s) / s   ->   w_e    (in [0, infty)).

Load bound.  Matched pairs are disjoint; summing the load at u over
all pairs involving u gives sum_{e ni u} w_e <= 1 for every u, so
the total satisfies sum_e w_e <= m/2.

Types with negative-endpoint Gram: a matched pair type whose 2s x
2s endpoint Gram block (from A_s) has a negative eigenvalue.  By
the conflict property G1 applied as follows:

   Each collection of such types is mutually touching (a conflict
   would give two orthogonal negative directions).  A matching of
   such types in G has size < m/20 by G1 applied with each type in
   its own class.  So the total weight of these types is < m/10.

(Details: the endpoint Gram block of a matched pair type is a 2 x 2
block matrix; "has a negative eigenvalue" here means the 2s x 2s
block itself is not PSD.  If two types with negative endpoints were
nonadjacent in G, their cross Gram would vanish, giving 2 negatives
of M: contradiction.  So the negative types form a clique in G.  By
G1 applied with the class structure {type}, and a matching of size
>= m/20 in the types, we get a conflict, so the matching of types is
< m/20.)

Types with endpoint Gram PSD but singular: delete one coordinate
per such type; at most O(m^2) coordinates in total; the affected
pair groups have the corresponding weight renormalized downward by
a negligible amount (in the limit, by 0 since we take a further
subsequence).

Types with endpoint Gram positive definite (and weight positive
in the limit): the CANDIDATE GROUPS.

Total candidate weight.  From (6.1), the total retained pair count
satisfies

   2 sum_e w_e   =  2 lim p_0 / s
                >=  (1 - delta - 5 tau^2) m.

Removing the weight < m/10 for negative types gives

   sum_{e candidate} w_e   >   m(2/5 - delta/2 - (5/2) tau^2)
                            >   3m/10.

(For this we need delta = 5 beta + 5/m small, hence beta small
enough as a function of a.)

This is the setup for the second normalization.

7.  Second normalization
----------------------------------------------------------------

Recall: X is the list of d_s first-normalized columns; each candidate
group e has 2 k_e retained matched columns X_e (k_e pairs); the
endpoint Gram D_e = <X_e, X_e> is positive definite (candidate
property).

Step 7.1.  Pair decomposition.

For matched pair j = {i, i'} in candidate group e, put

   R_j  =  (X_i - X_{i'}) / sqrt(2),       (pair difference)
   H_j  =  (X_i + X_{i'}) / sqrt(2).       (pair sum)

The coefficient maps from X to R and H are Euclidean isometries
(they take a 2k_e-column block to a k_e-column block by an
orthogonal change of variables).  From (6.3), on retained pairs:

   <R, R>  =  2 I_p  + small error,                              (7.1a)

where the Frobenius bound is (from (6.2) and contraction):

   || <R, R> - 2 I_p ||_F^2   <=  8 tau^2 v.

And

   |<H_j, H_j>|  =  |(1/2) [(B_s)_{ii'} - 1] - (1/2)[identity
                    contribution]|  <=  tau / 2 ...

More precisely:

   <H_j, H_j>  =  (1/2)([<X_i, X_i> + <X_{i'}, X_{i'}>]
                       + 2 <X_i, X_{i'}>)
              =  (1/2)(2 + 2 <X_i, X_{i'}>)
              =  1 + <X_i, X_{i'}>
              =  1 - (B_s)_{ii'}.

From |(B_s)_{ii'} - 1| <= tau:

   |<H_j, H_j>| <= tau,                                          (7.1b)
   |Tr <H, H>|  =  |sum_j (1 - (B_s)_{ii'})| <= p tau <= tau v/2.

So R is "almost sqrt(2) times orthogonal" and H is "small trace,
near-zero Gram".

Step 7.2.  Q-normalization.

Within each candidate group e, define

   Q_e  =  X_e  D_e^{-1/2}    where D_e = <X_e, X_e> (PD).

Then <Q_e, Q_e> = I_{2 k_e}.  Because D_e^{-1/2} is entrywise
nonnegative (Lemma 5.1) and cross blocks of X are entrywise
nonpositive, the cross blocks <Q_e, Q_{e'}> for e != e' remain
entrywise nonpositive.

Assemble Q = (Q_e : e candidate).  Then:

   <Q, Q>  =  I  -  C_s,                                          (7.2)

where C_s is entrywise nonnegative with zero diagonal blocks
(-block- meaning: cross block off-diagonal; diagonal block interiors
are zero by the Q_e normalization).  In particular <Q, Q> has:

   - n_-  =  1 (inherited from M via the D^{-1/2} normalization),
   - rank <= v/2 + 1,
   - spectral support in [0, 2+eps] (by Lemma 5.3 applied to
     C_s), with only o(v) eigenvalues outside [0, 2+eps],
   - || <Q, Q> || bounded by Lemma 8.3.

Step 7.3.  Sign domination between R and Q.

Take any pair j = {i, i'} and any coordinate k of some Q_e where
j is NOT in group e.  Both <X_i, (Q_e)_k> and <X_{i'}, (Q_e)_k>
are nonpositive (nonnegative off-diag entries in C_s give
nonpositive cross entries between X and Q after normalization).
So:

   |<R_j, (Q_e)_k>|
       =  |<X_i, (Q_e)_k> - <X_{i'}, (Q_e)_k>| / sqrt(2)
       <=  (|x| + |y|)/sqrt(2)  where x, y are the two cross
                                  entries,
       =  -(x + y)/sqrt(2)     (since x, y <= 0),
       =  -<H_j, (Q_e)_k>.

So |<R, Q>| <= |<H, Q>| entrywise (on cross-group entries).  On
diagonal-group entries, we have <R_e, Q_e> = T_e = D_e^{1/2} U_e,
which we will handle separately through the Y-complement below.

Define Z as <R, Q> restricted to cross-group entries, with zeros on
the diagonal groups.  Then

   || Z ||_F^2  <=  || <H, Q> ||_F^2.                           (7.3)

Step 7.4.  Complement directions Y.

For each candidate group e, let U_e be the 2 k_e x k_e matrix whose
columns are the pair-difference coefficients (so R_e = X_e U_e).
U_e has orthonormal columns (it is the coefficient of (X_i - X_{i'})
/ sqrt(2) summed over the k_e pairs).  Then

   R_e  =  Q_e  T_e,     where T_e = D_e^{1/2} U_e.

Because D_e is PD, T_e has rank exactly k_e.  Choose a 2 k_e x k_e
matrix L_e whose columns are an orthonormal basis of (im T_e)^perp.
Then:

   L_e^T L_e  =  I_{k_e},
   <R_e, Q_e L_e>  =  T_e^T L_e  =  0.                          (7.4)

Define L = diag(L_e) and Y = Q L.  The list Y has exactly

   t  :=  sum_e k_e

columns (one per matched pair).  Properties:
  - <Y, Y> has identity diagonal blocks (from <Q, Q> = I - C_s
    restricted to L-slices),
  - Tr <Y, Y> = t (from the identity diagonal blocks),
  - n_-(<Y, Y>) <= 1,
  - spectral support of <Y, Y> lies in [0, 2+eps] (inherited from
    <Q, Q>),
  - <R, Y> = 0 on every diagonal group block (from (7.4)), and
    <R, Y> is bounded by <H, Y> on cross-group entries (from (7.3)
    combined with Y = QL).

Step 7.5.  Rank gain.

Consider the joint Gram matrix of (R, Y).  Note first:

   restriction to <R, R> > 1/4 I subspace: dimension at least
   p'  >=  p - (128/49) tau^2 v, by (7.1a) and Markov.

   restriction to <Y, Y> > 1/4 I subspace: dimension at least
   t'  >=  t/3 - o(v).
   (Since max eigenvalue <= 2 + eps, we have
       t = Tr <Y,Y>
         <= (1/4)(t - k') + (2 + eps) k' + o(v),
    giving k' >= t/3 - o(v) after rearranging.)

   cross bound:
   || <R, Y> ||_F^2  <=  || <H, Y> ||_F^2
                     <=  || <H, Q> ||_F^2  (since Y = QL with
                         L an isometry, Frobenius contraction)
                     =    O(tau) v.        (see Step 7.6 below)

Write these restrictions as (R', Y') on a p'-dim and t'-dim
subspace.  Diagonal blocks: <R', R'> >= (1/4) I, <Y', Y'> >=
(1/4) I.  Cross operator norm: || <R', Y'> ||_op <= (something
like) O(sqrt(tau)).  In particular for beta small enough:

   || <R', Y'> ||_op  <=  1/8.

Then for any unit vector (x, y) in the joint coefficient space:
   [Gram_RY(x, y)]  =  <R'x, R'x> + 2 <R'x, Y'y> + <Y'y, Y'y>
                    >=  (1/4)(||x||^2 + ||y||^2)
                        - 2(1/8) ||x|| ||y||
                    >=  (1/4)(||x||^2 + ||y||^2)
                        - (1/4)(||x||^2 + ||y||^2) ... careful
                        ... let me be tight:

                    >=  (1/4)(||x||^2 + ||y||^2) - (1/4)||x|| ||y||
                    >=  (1/8)(||x||^2 + ||y||^2)   >  0.

So (R', Y') is positive definite on this restricted subspace, and
its rank as a Gram matrix is at least p' + t' - #(deleted by
thresholding cross singular values).  The number deleted by the
1/8 thresholding is at most 64 * || <R, Y> ||_F^2 (each singular
value > 1/8 contributes >= 1/64 to the squared Frobenius norm).

So:

   rank <R, Y>  >=  p' + t' - (128/49) tau^2 v - 64 ||Z||_F^2.

But rank <R, Y> <= rank M (since R, Y are linear combinations of
Lorentz vectors of M).  So

   rank M  >=  p + t/3 - 64 || <R, Y> ||_F^2
              - (128/49) tau^2 v - o(v).

Step 7.6.  Boundary of the cross term.

From Step 7.3 and (7.2) plus the trace bound on H:

   || <H, Q> ||_F^2  / v  <=  tau,

because the singleton-vs-tensor trace bound gives
   |<H_j, <Q_e)_k>|^2 is small when the H_j's have small trace and
   the Q_e's are normalized.

More precisely, apply the special lemma:

Lemma 7.1 (trace-cross).  Let H, Q be two lists whose joint Gram
matrix has operator norm bounded by a constant K.  Suppose the
Gram matrix <Q, Q> has o(v) eigenvalues above 2+eps, and
limsup Tr<H, H> / v <= eta.  Then

   limsup || <H, Q> ||_F^2 / v  <=  2 eta.

(Proof: see Part 8; it is a specialization of the general
"cross trace" bound from the tree lemma.)

Apply with eta = tau/2 (from (7.1b) trivially, actually
Tr <H, H> <= tau v/2 gives eta = tau/2).  So

   || <H, Q> ||_F^2  <=  tau v.

Combined with (7.3): || <R, Y> ||_F^2 <= tau v.

Step 7.7.  Conclusion for this section.

Substitute into Step 7.5:

   rank M
   >=  p + t/3 - 64 tau v - (128/49) tau^2 v - o(v).

And from §6.5: p >= v(1/2 - delta/2 - (5/2) tau^2), and t >= (c/3) v
where c = c(a) is a small constant.

So:

   rank M / v
   >=  1/2 + c/9 - 64 tau - (275/49) tau^2 - o(1)
   >  1/2 + c/12

for s large and beta small enough (making tau <= c/2340).

This contradicts rank M <= v/2 + 1.  The proof of Theorem 4.2
therefore reduces to verifying Lemma 8.3 (bounded || B_s ||,
resolved by the hyperbolic-tree lemma) and Lemma 7.1 (trace-cross
bound).

Sections 8-10 establish those two lemmas.  Section 10 assembles the
final proof of Theorem 4.2.

8.  Lorentz-positive subspaces and their flats
----------------------------------------------------------------

8.1  Lorentz-positive subspaces.

In the Lorentz space R^{1, D} (dim D+1, form [x, y] = -x_0 y_0 +
<x_s, y_s>_{Euclid}), a linear subspace P is LORENTZ-POSITIVE if
the restricted form is positive definite on P; equivalently
[x, x] > 0 for all x in P with x != 0.  In particular the span
of a Lorentz-orthonormal list is Lorentz-positive.

The HYPERBOLIC SPACE H^D is the set of future-pointing unit
timelike vectors, i.e. x in R^{1, D} with [x, x] = -1 and x_0 > 0.
It is a smooth complete simply-connected Riemannian manifold of
constant curvature -1 and dimension D.

For a Lorentz-positive subspace P, its FLAT is

   F_P  =  {x in H^D : [x, y] = 0 for all y in P}.

As a subset of H^D, F_P is a totally geodesic embedded copy of
H^{dim P}, hence itself a hyperbolic submanifold of dimension
dim P.

8.2  Flat intersection.

Given Lorentz-positive subspaces P, P' with cross Gram zero (i.e.
[x, x'] = 0 for all x in P, x' in P'), the flat intersection

   F_P ∩ F_{P'}  =  F_{P + P'}

is nonempty.

Conversely, if F_P ∩ F_{P'} is nonempty, then the cross Gram of
P, P' vanishes.

Both statements follow directly from the definitions: x belongs to
F_P ∩ F_{P'} iff x is Lorentz-orthogonal to all of P and of P'.

Since holes of G (nonedges) are exactly where Lorentz Gram cross
entries vanish, we get:

   {u, u'} is a hole of G  =>  F_{P_u} ∩ F_{P_{u'}} is nonempty,
   {u, v} edge of G        =>  F_{P_u}, F_{P_v} may fail to
                               intersect (cross Gram has negative
                               entries at that point).

8.3  Bounded-distance flats and Gram bounds.

The key geometric fact is a quantitative version of 8.2: if two
Lorentz-positive subspaces P, P' have flats meeting near a common
"center" (at bounded hyperbolic distance), then bases of P, P'
have a block Gram of bounded operator norm.

Lemma 8.1.  Let P_1, ..., P_k be Lorentz-positive subspaces of a
Lorentz space of dimension D+1.  Suppose the flats
F_{P_1}, ..., F_{P_k} are all at hyperbolic distance at most R
from a common point p in H^D.  Then for any Lorentz-orthonormal
choices of bases e_{i, 1}, ..., e_{i, d_i} of P_i,

   ||  [ [e_{i,a}, e_{j,b}]_{ab} ]_{ij}  ||_op   <=   K(k, R)

with  K(k, R) <=  k  (2 D_k  (1 + 4 sinh^2(R/2))),  where D_k =
max_i d_i.

Proof.  Move p to the "origin" of hyperbolic space by an isometry
of H^D; equivalently, apply the appropriate Lorentz transformation
so that p = standard basepoint e_0 in R^{1, D} (time axis).

For x in a Lorentz-positive subspace P_i with flat near p (say,
x itself is not necessarily near p, but F_{P_i} is), we have
[x, x] = 1 for any basis vector x = e_{i, a}.  Write x = (t, u)
in Lorentz coordinates so that [x, x] = -t^2 + |u|^2 = 1.

Since F_{P_i} is at distance <= R from p, there is a point q in
H^D with q in F_{P_i} and p at hyperbolic distance <= R from q.
Then p - q has Lorentz norm squared

   [p - q, p - q]  =  -1 - 1 - 2 [p, q]  =  -2 + 2 cosh(R)
                   =  4 sinh^2(R/2).

Decompose p - q = (p - q)_{||} + (p - q)_perp with respect to
the Lorentz-orthogonal projection to P_i.  Since q in F_{P_i},
[p - q, x] = [p, x] for x in P_i.  So

   |t|  =  |[p, x]|  =  |[(p - q)_{||P_i}, x]|
        <=  |(p - q)_{||P_i}| * |x|  <=  |p - q| = 2 sinh(R/2).

Therefore |u|^2 = 1 + t^2 <= 1 + 4 sinh^2(R/2), so in Euclidean
norm |x|_Euc <= sqrt(1 + 4 sinh^2(R/2)) + 2 sinh(R/2).

The block Gram at position (i, a), (j, b) is [e_{i,a}, e_{j,b}].
Bound each entry by |e_{i,a}|_Euc * |e_{j,b}|_Euc via Cauchy-
Schwarz.  The row sum over all (j, b) of |[e_{i,a}, e_{j,b}]| is at
most D_k * |e_{i,a}|_Euc * max_j |e_{j,b}|_Euc, giving the
operator-norm bound.

Refine constants: with D_k, R, k, and |x|_Euc <= 2D_k sinh(R/2)+...
the bound reads  K(k, R) = 2 D_k |x|_Euc^2 · k.  Absorbing absolute
constants, we get K(k, R) <= k · C(R) with C(R) polynomial in
e^R and D_k.  []

8.4  Tree hypothesis and its combinatorial supply.

The remaining structural step is: given the conflict structure of
G (via (G1), (G2), (G3)), find a bounded-diameter tree T of
candidate blocks such that adjacent tree blocks have flat
intersection (a hole), and such that the candidate blocks appear
in T.

Lemma 8.2 (combinatorial tree).  Under properties (G1)-(G3) with
parameters a, beta, for any subclass of candidate blocks whose
union has size >= 3 m / 10, there is a connected subgraph of G
whose vertices cover at least 2 m / 10 of these blocks, whose
maximum "flat-depth" is at most m, and whose consecutive tree
edges are cross holes.

Proof sketch (via iterations of (G3)).  Start with any two
candidate blocks and put them in the "active set" A subset V.
Iterate: since |A| < m always and the candidate block count is
>= 3 m / 10, the residual set B = V(G) minus A has size > m / 10
(unless we have already covered everything).  By (G3) applied to
A and B (after subdividing to reach size >= beta*m), there is a
cross hole {u, u'}.  Then F_{P_u} ∩ F_{P_{u'}} is nonempty, so
add u' to A.  Each iteration adds at least one vertex to A.  Depth
of tree is at most m.  Terminate when either B is a set of size
< beta m or candidate blocks are all covered.

If beta is small, the sequence can always be continued until
almost all graph vertices are covered.  []

Remark 8.3.  The full combinatorial statement in the literature
(the "weighted bag" lemma) refines this to show that a "bag" (a
tree-convex subsequence) of total weight at least c(a) m exists
for a universal constant c(a) > 0 depending only on a.  The
construction above is a simplification of the same idea.  What
matters for the norm bound is only that SOME bounded-diameter
tree covers the candidate blocks.

8.5  Bounded || B_s ||.

We can now prove that || B_s || is bounded uniformly in s.

Lemma 8.4 (bounded B_s).  Under the hypotheses of Theorem 4.2,
there is a constant K_1 = K_1(m, a, beta) < infinity (independent
of s) such that || B_s ||_2 <= K_1 for all sufficiently large s.

Proof.  Each X_u block is Lorentz-positive (identity diagonal
block in A_s).  Candidate groups e are Lorentz-positive.  Lemma
8.2 gives a bounded-depth tree T of candidate blocks and single-
vertex blocks connected by cross holes = flat intersections.  By
iterating Lemma 8.1 along the tree (each tree edge contributes at
most R = diameter bound to the flat-distance of the descendant
from the root), we get that all flats F_{X_u}, F_{X_e} are at
hyperbolic distance at most R_0 = K_1 m from a common point.

Lemma 8.1 then gives || <X, X> ||_op <= K_0 for K_0 depending
only on the tree and R_0.  Since B_s = I - A_s and A_s = <X, X>,

   || B_s ||_op   <=   1 + || A_s ||_op   <=   1 + K_0.

Take K_1 = 1 + K_0.  []

Remark 8.5.  This is where the "conflict geometry" enters in
earnest: the three combinatorial conflict properties of G
translate into the existence of a bounded-diameter hyperbolic tree
of flats, which bounds the joint Gram.  The argument is completely
combinatorial-geometric; it does not use any of the probability
that fills Parts 3-5.  It is the entire reason that Part 2 can be
proved without ever looking at the frame construction.

9.  The trace-cross bound (Lemma 7.1)
----------------------------------------------------------------

This section proves Lemma 7.1.

Lemma 9.1.  Let H = (h_1, ..., h_p), Q = (q_1, ..., q_m) be two
lists of Lorentz vectors.  Suppose:

   (i) || <Q, Q> ||_op  <=  M_0   (bounded, independent of the
       lists' sizes),
   (ii) Tr <H, H>  <=  tau  ·  v   for some tau > 0.

Then

   || <H, Q> ||_F^2   <=   M_0 · tau · v.

Proof.

Follow the projection argument.  Define the Lorentz-orthogonal
projection Pr_Q onto the span of Q, i.e. Pr_Q x = the projection
of x in Lorentz space onto span(Q).  Since <Q, Q> is bounded by
M_0 in operator norm but not necessarily = I, the projection
operator Pr_Q has operator norm at most M_0 / (1 - small), let us
say Pr_Q has operator norm at most M_0.

    ||Pr_Q x||  <=  ||Q|| ||<Q, Q>^{-1}|| ||Q^T x||  ... actually
    let me state it cleanly.  Since Q is not necessarily independent
    or orthonormal, but its Gram has operator norm M_0, the
    orthogonal projection onto span(Q) has Lorentz-norm bound M_0.

Decompose h_j = h_j^{par} + h_j^{perp} with h_j^{par} in span(Q)
and h_j^{perp} Lorentz-orthogonal to span(Q).  Then [h_j, q_k] =
[h_j^{par}, q_k] for all k.  Also, since h_j^{par} in span(Q),
write h_j^{par} = sum_k c_{j,k} q_k.  Then

   [h_j, q_l]  =  [h_j^{par}, q_l]  =  sum_k c_{j,k} [q_k, q_l].

So the matrix <H, Q> equals <H^{par}, Q> where H^{par} = {h_j^{par}},
and <H^{par}, Q> is the coordinate representation of the map Q <->
H^{par}.  In operator terms, <H, Q> = C <Q, Q> for the coefficient
matrix C (p x m) satisfying h_j^{par} = sum_k C_{j, k} q_k.

Now

   ||<H, Q>||_F^2  =  ||C <Q, Q>||_F^2  <=  ||C||_F^2 ||<Q, Q>||_op^2
                   <=  M_0^2 sum_j sum_k C_{j, k}^2.

And

   sum_k C_{j, k}^2  =  norm of C_j in R^m,
                     =  Lorentz norm of h_j^{par} with respect to
                        (Q, Q)^{-1} ... i.e. <h_j^{par}, h_j^{par}>_*(Q)
                     =  [h_j^{par}, h_j^{par}]   (since Q is
                        Lorentz-orthonormal in the appropriate
                        normalization).

So sum_{j, k} C_{j, k}^2 = sum_j [h_j^{par}, h_j^{par}] <= sum_j
[h_j, h_j] = Tr <H, H> <= tau v.

Therefore ||<H, Q>||_F^2 <= M_0^2 tau v (times a small correction
from the projection norm factors).

For our situation, M_0 = ||<Q, Q>||_op <= 2 + || I - <Q, Q> ||_op =
2 + || C_s ||_op <= 2 + K_1 by Lemma 8.4.  Absorb K_1 into the
constant if needed.  Take M_0 = 2 + K_1 (a fixed constant); the
resulting bound is

   || <H, Q> ||_F^2   <=   (2 + K_1)^2 tau v.

[]

Conclusion for Section 7.6: with h_j = H_j (pair sums), we have
Tr <H, H> <= (tau/2) v from (7.1b).  Therefore

   || <H, Q> ||_F^2  <=  C tau v,

with C = (2 + K_1)^2.  Substituting into Step 7.5 with the

10.  Assembly of Theorem 4.2
----------------------------------------------------------------

Collect the numeric bounds derived in Part 2.

Setup: a in (0, 1], beta <= beta_0(a), m >= m_0(a), G on m
vertices satisfying (G1)-(G3).  Let M be a well-signed matrix for
G[K_s] with n_-(M) = 1.  Assume for contradiction rank M <= v/2 + 1,
v = ms.  Let delta = 5 beta + 5/m and tau = (3 delta)^{1/4}, so
that  delta <= delta_0(a)  (a small absolute constant) and
tau <= 1/8.

STEP A.  Reduce and normalize each block.
- Let C be the set of blocks of G for which the Gram restricted to
  the block has a negative eigenvalue.
- n_-(M) = 1 =>  C is a clique of G  (Claim A, sec 6.1).
- G3 forces |C| < 2q  where q = ceil(beta m)  (Claim B).
- Remove C.  PSD-singular blocks lose one coordinate each
  (Lemma 5.2).
- Working dimension d_s >= (m - 2q)(s-1) >= (1 - delta) v.

STEP B.  First normalization.
- X_u := V_u D_u^{-1/2} for each surviving block (D_u positive
  definite, X_u has <X_u, X_u> = I).
- A_s := <X, X> = I - B_s  (B_s nonneg, zero diagonal).
- n_-(A_s) = 1, rank A_s <= v/2 + 1.
- By Lemmas 8.4 and 5.3:
    || B_s^2 - I ||_F^2  <=  3 delta v       (assuming s >= s_0;
                                              delta small)
- Matching Lemma 6.1 with tau = (3 delta)^{1/4} gives a matching W:
    # omitted coordinates <= 5 tau^2 v,
    || B_s - W ||_F^2   <= 8 tau^2 v,
    |B_s[i, j] - 1| <= tau on retained pairs (i, j).

STEP C.  Group by base label pairs e = {u, u'} in E(G).
- Negative-endpoint types: weight < m/10 (via G1).
- Remaining candidate types: total weight sum w_e > 3 m / 10
  (from the load bound and Step B).

STEP D.  Second normalization on candidates.
- Pair decompositions R_j = (X_i - X_{i'})/sqrt(2),
  H_j = (X_i + X_{i'})/sqrt(2) for each matched pair.
- R has Gram 2 I + error, H has |H_j|^2 <= tau,
  Tr <H, H> <= (tau/2) v.
- Within each candidate group, further normalize by D_e^{-1/2} to
  get Q_e with <Q_e, Q_e> = I, and define Y_e = Q_e L_e where L_e
  is an orthonormal basis of (im T_e)^perp, T_e the pair-difference
  coefficient matrix.
- <R, Y> bounded by trace-cross Lemma 9.1:
    || <R, Y> ||_F^2  <=  C tau v       with  C = C_0(K_1).

STEP E.  Rank gain.
- Joint Gram of (R, Y) positive definite on a subspace of
  dimension at least
    p + t/3 - (128/49) tau^2 v - 64 C tau v - o(v).
- rank M >= this dimension.

STEP F.  Numeric final.
Recall: p >= (1/2 - delta/2 - (5/2) tau^2 - (2/5)) v >= (1/10) v
for beta small.  t >= (c/3) v for the machine constant c = c(a).

So

   rank M / v
     >=  1/2 - delta/2 - (5/2) tau^2 - (2/5) + 1/3

when beta is chosen small enough that tau and delta are below
c / (small constant).  Explicitly: choose beta_0(a) so that
(3 delta_0(a))^{1/4} <= c(a) / 2340.  Then rank M > v/2 + c/24 > v/2 + 1
for beta small enough.  Contradiction.

This proves Theorem 4.2.  []  (Part 2 complete.)

PART 3.  THE FINITE-FIELD CONSTRUCTION
================================================================

Parts 3-5 prove Theorem 4.1 (base graph existence).  The proof is a
probabilistic existence argument: for each large n we construct a
probability law pi on a finite set Omega_n of "frames", and we show
that a sample of m frames, converted into a graph H via a
hole-adjacency rule, satisfies (G1)-(G3) (with high probability)
and has alpha(H) <= 2.

This Part introduces the F_2 structure.  Part 4 does the
probability estimates.  Part 5 converts to graph properties.

----------------------------------------------------------------
11.  Tags, components, base variables
----------------------------------------------------------------

11.1  Basic parameters.

Fix g >= 3 odd and divide the parameter bookkeeping.  All constants
in this Part are chosen in the ledger order of Appendix A.

11.2  The tag set and the component set.

Let  I  =  Z / g Z  denote the cyclic group of order g.  Elements of
I are TAGS.  A tag is an integer mod g.

Let  E  =  binom(I, 2)  be the set of unordered pairs of distinct
tags.  Elements of E are COMPONENTS.  |E| = (g-1) g / 2.

For each tag d, let  I_d  =  {d + 1, d + 2, ..., d + (g-1)/2}  in
I be the "half the tags strictly after d in the cyclic order".
Then for any tag d,  I_d  and  I_d + (g-1)/2  are complementary
halves of I minus {d}, and  d  itself is in neither.

11.3  The base variables.

A "base coordinate" is a bit in the F_2-vector space

   B_base  =  F_2^{g^2 + 3 + (j* selector bits)}.

More explicitly, the base variables are grouped into BLOCKS:

   O_{d, t}   for  d, t in I,  with |O_{d, t}| = n  bits,

   S          with |S| = n  bits,

   #          with |#| = n  bits,

   Z          with |Z| = n  bits.

So  g^2  ordinary blocks of n bits, plus 3 special blocks, plus the
selector variables.  Total base bits = (g^2 + 3) n + b where b is the
selector length (chosen later).

11.4  The cut-profile space X.

Let  B_y  =  the selectors tensor base-coordinate-bit space:

   B_y  =  F_2^{p_*}  (x)  F_2^{1 + d_b},

where  p_*  =  sum_{j=0}^{j_*} binom(b, j)  is the number of
squarefree selector monomials of degree <= j_*, and
d_b = (g^2 + 3) n  is the number of base bits.  The "1" in the second
factor is the constant coordinate (always 1).

For a selector value s in F_2^b and a base-coordinate value z
(the tuple of the (g^2+3)n base bits), define the "point" in B_y:

   v(s, z)  =  p_s  (x)  (1, z)   in  B_y,

where p_s is the vector of selector-monomial evaluations at s.

Define the raw point-moment space

   W  =  span  {  v(s, z)  v(s, z)^T  :  s in F_2^b, z in F_2^{d_b}  }

inside  B_y (x) B_y.  This is the span of rank-one tensors over all
"points" (selector, base value).

For each tag l in I, let W_l be the subspace of W obtained by
restricting to point moments with the additional constraint

   O_{d, t} = 0   for every tag d in I minus I_l, every tag t in I.

In other words: W_l only sees selectors and base values that assign
zero to each O block whose first tag is not in I_l.  (The "second"
tag t is unrestricted.)

Finally let W_* be defined by requiring ALL O blocks to be zero:
W_* is the subspace of W obtained by restricting to z in F_2^{d_b}
with every O_{d, t} = 0.

11.5  The cut-profile space.

Define

   X  =  {  x  =  (x_e)_{e in E}   :   x_e = w_l + w_{l'}  for
              some tags l, l' with e = {l, l'} and some
              w_l in W_l, w_{l'} in W_{l'}  }.

Here the "cut profile"  x  is a tuple of matrices, one per
component.  Each x_{l, l'} lies in the cut space  W_l + W_{l'}.

We call w = (w_l)_{l in I}  a REPRESENTATION of x if x = (w_l + w_{l'})_{l, l'}.

11.6  The cut-kernel lemma.

Lemma 11.1.  Let  J  be any strict majority of tags (so |J| > g/2).
Then

   intersection_{l in J}  W_l   =   W_*   .

Furthermore, if two representations w, w' of the same x differ, then
their difference  w - w'  is a constant tuple: there is m in W_* such
that w_l - w'_l = m for every l.

Proof.  Fix a base coordinate in O_{d, t}.  It is allowed (nonzero
parameter) at tags in I_d only; at other tags it must be zero.  The
set  I_d  has size  (g-1)/2 < g/2, so any strict majority J
contains at least one tag where O_{d, t} is disallowed.

Consider a matrix M in W_l for some l in J with  O_{d, t} | l not
subset I_d.  Then every point moment in W_l has this coordinate
equal to zero.  Since M is a positive combination of such point
moments, M has this coordinate zero too.  Similarly for all
coordinate constraints that enforce zeros on the tensor.

The "coordinate projection" that sets every O coordinate to zero
sends each point moment in W_l to a point moment in W_*, and fixes
matrices in  (W_l)^perp  (those with all O coords zero).
Applied on both tensor factors, this operator maps W_l to W_*.

For w, w' with w_l + w'_l constant: the difference delta_l = w_l -
w'_l satisfies delta_l = delta_{l'} for every pair l, l'.  So delta
is constant.  Its value belongs to intersection_l in J W_l = W_*
(since delta lies in W_l for all l).  Conversely every constant
tuple takes value in every W_l, hence in W_*.

[]

Warning about conventions.  W_l and W_* are spaces of F_2-matrices
(or rather of subsets of symmetric tensors, but we do not in this
Part distinguish symmetric from non-symmetric - we always work
with the symmetric version and any non-symmetric entries vanish by
common symmetry considerations in the point-moment form v v^T).

11.7  The bilinear form T.

To compute with cut profiles we introduce a symmetric bilinear form
T on X.  It is constructed as T = T^0 + T^1 where:

  T^0(x, y)  =  a(x) a(y) + sum_{t in I} (a_t(x) b_t(y) + b_t(x) a_t(y)),

for fixed linear functionals  a, a_t, b_t  on X (defined below), and

  T^1(x, y)  =  sum_{ordered components (e, f), 1 <= j <= J}
                  [x_e, L_j^{ef} y_f (R_j^{ef})^T]   +  (symmetric
                  counterpart)

for fixed endomorphisms  L_j^{ef}, R_j^{ef}  of B_y.

The functionals a, a_t, b_t are given by extracting specific bit
coordinates of the cut profile.  We do not need their explicit
formulas for Part 3.

The properties used below are:
 - T^0 has the "a(x)^2 = a(x)" bit-form (i.e. a(x) in F_2,
   applied as a scalar to itself gives a(x));
 - T^0's mixed terms in (x, x) cancel since (a_t(x) b_t(x) +
   b_t(x) a_t(x)) = 0 in F_2-algebra;
 - hence  T(x, x) = a(x)  for every x,
 - T^1 is alternating (T^1(x, y) = -T^1(y, x) in F_2, so 0),
 - the mixers L, R are chosen (Lemma 4.6 below) so that T has
   sufficient alternating structure for the later estimates.

Lemma 11.2.  T(x, x) = a(x) for all x in X.

Proof.  Expand T^0(x, x):
   a(x)^2 + sum_t (a_t(x) b_t(x) + b_t(x) a_t(x))  =  a(x) + 0
   =  a(x)
in F_2 (where 2 xy = 0).  T^1(x, x) = 0 since it is alternating.
Sum.

[]

Lemma 11.3.  For all x in X, the number a(x) is the "diagonal bit"
q(x) of the cut profile.  It is 0 or 1.

[Proof omitted: by definition of a(x) as extraction of a bit.]

The exact construction of L, R (the mixers) is deferred to Part 4,
where it is the technical content of Lemma 4.6 ("generic mixers").
For now we record only: the mixers exist, are fixed in the parameter
ledger, and give a bilinear form T with the stated T^0 and T^1
structure.

12.  The frame construction
----------------------------------------------------------------

12.1  Ambient, base, and channel spaces.

Fix integer parameters

   d   = dim B,  the base space,
   h   = channel dimension,
   N   = ambient dimension of F^N,
   g   = number of tags (odd, >= 3).

We will need  N >= 2(d+h); this is enforced by the choice of M_0
in the parameter ledger (Appendix A).

The base space B = F_2^d has a distinguished basis
   e_0, e_1, ..., e_{d-1},
where e_0 is the "constant coordinate" (used in 11.4 as the extra
factor of 1).  The channel space is F^h with its standard basis.

12.2  Frames at one component.

Fix a component e = {l, l'} in E.  A FRAME AT e is a quadruple

   ( P_e, X_e, Q_e, Y_e )

where:

   P_e is a d-tuple of column vectors in F^N  (plus-primal),
   X_e is an h-tuple of column vectors in F^N  (plus-channel),
   Q_e is a d-tuple of column vectors in F^N  (minus-primal),
   Y_e is an h-tuple of column vectors in F^N  (minus-channel).

The tuple must satisfy the following GRAM CONSTRAINTS:

   <P_e, P_e>  =  I_d ,
   <Q_e, Q_e>  =  I_d ,
   <X_e, X_e>  =  I_h ,
   <Y_e, Y_e>  =  I_h ,
   <P_e, X_e>  =  <Q_e, Y_e>  =  0 ,
   <X_e, Y_e>  =  0 ,
   <P_e, Y_e>  =  <X_e, Q_e>  =  0 ,
   <P_e, Q_e>  =  E_e    (   a prescribed d x d matrix   ),

where all inner products <.,.> denote the standard dot product in
F_2^N, and E_e depends only on the base-graph component e.

12.3  The prescribed matrix E_e.

The matrix E_e is defined from the cut-space data of Section 11:
it encodes the two cut-space blocks w_l and w_{l'} as matrices on
the base space B, evaluating them on the constant coordinate.

Specifically, let B_{l, l'} = e.  Define

   E_e[0, 0]   :=   w_*    ( a fixed bit ),
   E_e[x, y]   :=   w_l[x, y]  +  w_{l'}[x, y]  (  in F_2  ),

where w_l, w_{l'} are the canonical representation matrices from
11.4 acting on the d x d base coordinates (coordinate 0 is the
constant bit; coordinates 1, ..., d - 1 span the rest of B), and
addition is in F_2.  The choice of representative (w_l vs. any
representative differing by an element of W_*) is fixed once and
for all by the parameter ledger.

Remark 12.1.  Two versions of E_e that differ by an element of
W_* (a "kernel ambiguity") will produce the same "hole" relation
below; this is the technical content of Lemma 11.1 applied to the
E_e matrix of the cross Gram.  We use the canonical representative
and do not repeat this reduction.

12.4  Nonemptiness of the frame set.

Lemma 12.2.  For every component e and every N >= 2(d+h), the
frame set at e is nonempty.

Proof.  Take P_e = (u_1, ..., u_d) to be the first d standard
basis vectors of F^N, and X_e = (u_{d+1}, ..., u_{d+h}) the next
h.  Then <P, P> = I_d, <X, X> = I_h, <P, X> = 0.

For Q_e, put q_i = (E_e[:, i] restricted to the first d
coordinates, then extended by a distinct standard basis vector
in coordinates d+h+i for i = 1, ..., d).  More explicitly, for
i in {1, ..., d}, define

   q_i :=  sum_{j=1}^d   E_e[j, i] u_j
            +  u_{d+h+i} .

Then <P_e, q_i> = E_e[:, i] (matching the required cross Gram),
and <X_e, q_i> = 0.  Also <q_i, q_j> = 0 for i != j (distinct
bases) and <q_i, q_i> = 1 (single basis in the unique position).

For Y_e, define y_j = u_{d+h+d+j} for j = 1, ..., h, using h more
standard basis vectors.  Then <Y, Y> = I_h, <Q, Y> = 0 (disjoint
bases), <X, Y> = 0 (disjoint bases), <P, Y> = 0 (disjoint bases).

All these are within F^N for N >= 2(d+h), so the frame set is
nonempty.  []

12.5  The raw law.

The RAW LAW rawlaw_n on the set Omega_n of all frames (i.e. all
assignments of (P_e, X_e, Q_e, Y_e) for every e in E satisfying
the Gram constraints of 12.2) is the
uniform distribution, INDEPENDENTLY ACROSS COMPONENTS.  In other
words, we choose each component's frame data uniformly among
all quadruples satisfying 12.2, and different components are
independent.

Frames in Omega_n are also called RAW VERTICES, when we want to
emphasize the connection to the sampling construction below.

|Omega_n| <= 2^{2|E|N(d+h)}.  In particular
log_2 |Omega_n| = O(N^2) since |E| = O(g^2) = O(1) and N = M_0 n.

12.6  Gram-uniform injectivity.

We record a key property of rawlaw that will be used repeatedly.

Lemma 12.3 (Gram-uniform injectivity).  Fix any component e.  Under
rawlaw, conditionally on P_e, X_e, and Q_e, the tuple Y_e is a
uniform injective tuple in the affine subspace
    {Y in (F^N)^h : <P, Y> = 0, <X, Y> = 0, <Q, Y> = 0,
                    <Y, Y> = I_h}.

More generally, for any fixed (d+h)-tuple L = (P, X) as an
"input" and any (d+h)-tuple R = (Q, Y) as an "output", the
distribution of R given L is uniform on the coset of the affine
constraint set defined by <L, R> = E_e-submatrix, with <R, R> = I.

In particular, the raw probability of an event that specifies
the images of k independent vectors on the R-side is at most
2^{-k N + o(N)}.

[We state this in a form digestible for use in Part 4; the
formal justifications are in Lemma 24.1.]

12.7  The thin law.

The THIN LAW pi_n is a refinement (conditional distribution) of
rawlaw_n defined in Part 4 (Section 27).  For Part 3, only these
properties are needed:

   (a)  pi_n preserves the primal marginal of rawlaw_n: for any
        event A measurable in (P_e, Q_e)_{e in E} alone,
        pi_n(A) = rawlaw_n(A).

   (b)  Under pi_n, the primal-plus channel choice X_e is
        distributed relative to rawlaw_n with density bounded by
        2^{eps_ch N} for a small fixed constant eps_ch > 0
        (much smaller than delta).

   (c)  Under pi_n, the minus-side data (Q_e, Y_e) given
        (P_e, X_e) has density bounded by 2^{eps_ch N} times its
        rawlaw_n conditional.

   (d)  The support of pi_n is a subset of the support of
        rawlaw_n; pi_n is absolutely continuous with respect
        to rawlaw_n.

The phrase "eps_ch" is the "channel-thinning rate"; its value is
fixed in the parameter ledger.  Note eps_ch << 1; explicitly we
take eps_ch < rho/12 for the rate rho in the ledger.

Intuition: rawlaw is too "spread out" on the channel images for
certain union bounds, so we prune it to a submeasure where the
channels are "thin".  The primal side is preserved, so the
local algebraic constraints on (P, Q) alone are unaffected.

13.  Holes
----------------------------------------------------------------

13.1  The cross-Gram of two frames.

Given two frames F = (P_e, X_e, Q_e, Y_e)_{e in E} and
F' = (P_e', X_e', Q_e', Y_e')_{e in E} in Omega_n, and a
component e, define the cross Gram of F and F' at e as the
2(d+h) x 2(d+h) matrix

   [ ( [P_e, P_e'], [P_e, X_e'], [P_e, Q_e'], [P_e, Y_e'] ),
     ( [X_e, P_e'], [X_e, X_e'], [X_e, Q_e'], [X_e, Y_e'] ),
     ( [Q_e, P_e'], [Q_e, X_e'], [Q_e, Q_e'], [Q_e, Y_e'] ),
     ( [Y_e, P_e'], [Y_e, X_e'], [Y_e, Q_e'], [Y_e, Y_e'] ) ]

with all blocks comprising actual bit values.

13.2  Definition of a hole.

A HOLE between frames F and F' is a collection of data
(v_{iz}, v_{zi}) (one pair per tag l in I and base-coordinate z
in the base space B) such that, evaluated on the cross Gram of F
and F' at components e = {l, l'}, all of the following F_2
equations hold:

   (H1)  For each tag l in I and base-coordinate z in B, the pair
         (v_{iz}, v_{zi}) satisfies an internal "well-signed"
         condition depending only on the components incident to l
         (defined in Part 4, equation 24.20).

   (H2)  For each tag l in I and base-coordinate z in B, there is
         a "cross" linear equation stating that a specific
         linear combination of the cross Gram entries equals a
         specific prescribed value.

   (H3)  A "closing" equation (the "diagonal" equation) that ties
         the (H1) and (H2) values together.

The exact form of (H1), (H2), (H3) is Definition 24.4 in Part 4.
For Part 3, we record only:

   - Each hole condition involves O(d + h) linear equations on
     the cross Gram entries for each tag l and base-coordinate z.
   - The number of base-coordinates z is finite; there are
     O(n) of them at most.
   - The total number of equations involved is O(n).

The equations are of the form
    (cross Gram entry)  =  (linear function of other entries),
and in particular each equation is LINEAR over F_2.

With all these equations satisfied, we say F and F' are
HOLE-CONNECTED, or simply that (F, F') is a HOLE.  We write
   F  nand  F'   for "F and F' have a hole".

13.3  No loops.

Lemma 13.1.  A frame F never has a hole with itself.

Proof sketch.  The (H2) cross equation, evaluated on F = F',
becomes an equation about the SELF-Gram of F, which is fixed by
the Gram constraints of 12.2.  The self-Gram of a valid frame
has structure I - B with B nonneg entrywise zero diagonal (as in
Part 2).  The (H2) equation is an "off-diagonal dominant"
equation that fails exactly at diagonal positions.  At a diagonal
position, the (H2) value is at the diagonal of the (I - B)
structure, which is 1 (not 0 as required by the hole equation).

Actually more carefully: viewed as a "well-signed" condition, the
"conflicting edge" property requires an edge to be a pair of
DISTINCT base labels u, u'.  A hole requires [v_u, v_{u'}] < 0
for such a conflicting edge, which requires u != u'.  At u = u'
the hole equation degenerates, and (H2) cannot be fulfilled.

The full proof is standard; we do not repeat it.  []

13.4  Triangle-freeness.

Lemma 13.2 (holes are triangle-free).  No three distinct frames
F_1, F_2, F_3 can pairwise have a hole.

Proof sketch.  Suppose F_1, F_2, F_3 are pairwise hole-connected,
with witnesses (v_{iz}^{12}, v_{zi}^{12}), (v^{13}, v^{13}),
(v^{23}, v^{23}) respectively.  From (H1) each witness satisfies
a "well-signed" condition within the endpoints.  From (H2) each
pairwise cross-Gram combination has the required zero.  Summing
the pairwise cross Gram contributions and using the diagonal
identity for the base coordinates (from T(x, x) = a(x) - see
Lemma 11.2), we derive that the three self-Grams of F_1, F_2, F_3
contradict the required structure (I - B with B nonneg entrywise).

The exact derivation again refers to a "well-signed" contradiction
technique involving three distinct witnesses (v_a, v_b, v_c) that
are pairwise orthogonal with two of them being able to jointly
"dominate" the third at the relevant positions.  The full
argument is in Part 4 (Lemma 24.7, "no-hole-triangle").

We record it here as the geometric-mechanical reason alpha <= 2.
[]


----------------------------------------------------------------
14.  Sampling and adjacency
----------------------------------------------------------------

14.1  The graph H from m sampled frames.

Fix the parameters.  Sample m independent frames F_1, ..., F_m
from the thin law pi_n.

Define the graph H on vertex set {1, ..., m} by:

    {i, j} is an edge of H  <=>  F_i and F_j are NOT hole-connected.

In other words, adjacency = "no hole".

14.2  Independence number.

Lemma 14.1.  alpha(H) <= 2.

Proof.  Suppose {i, j, k} were independent in H.  Then by
definition none of the pairs {i, j}, {i, k}, {j, k} is an edge,
which means all three pairwise relations are holes.  This is
exactly a "hole triangle", contradicting Lemma 13.2.  []

14.3  Chromatic number.

Lemma 14.2.  chi(H) >= ceil(m/2).

Proof.  Every proper colour class in H is an independent set, so
has size at most alpha(H) <= 2.  With m vertices, at least m/2
colour classes are needed.  []

14.4  Reducing Theorem 4.1 to two distribution theorems.

We now state (without proof in Part 3) the two probabilistic
inputs that will imply properties (G1)-(G3) of the graph H.

Let a COLOURED UNIT LAW be a probability law on pairs
(A, c) where:
  - A = (A_1, A_2) is an independent pair of raw frames under
    (a restriction of) pi_n, with {A_1, A_2} being an edge of H
    (i.e. A_1 and A_2 are hole-non-connected).
  - c is a "colour" drawn from a finite palette, with
    Pr(c = j) <= eta_col for every j, for a small fixed constant
    eta_col > 0.

Let a MARKED POINT LAW be a probability law on pairs (A, z) where
  - A is a unit as above,
  - z is an independent point from pi_n,
  - the law of z is bounded by L * pi_n for a fixed constant L.

We write A ~ B for two independent units to mean "A and B are
hole-connected via all four cross pairs" (i.e. A_1-A_2, A_2-B_1,
etc. all pairs of endpoints are HOLE-CONNECTED, i.e. all four
non-edges of H).

DISTRIBUTION TEST 1 (coloured conflict).  There is a numerical
constant eta_1 > 0 depending only on n-independent parameters
(g, h, N scaling rate) such that the following holds.  Let
(A, c) and (B, c') be two independent draws from any coloured
unit law as above, with the additional pair-density constraint

    (joint law of A)  <=  2^{3000 g N}  *  pi_n(x) pi_n(y),

for (x, y) a raw frame pair.  Then

    Pr( A ~ B  AND  c != c' )  >=  2^{-100 g N} .

DISTRIBUTION TEST 2 (edge-point conflict).  Let (A, z) be a
marked point law as above (density cap L).  Then

    Pr( A ~ z )  >=  2^{-100 g N} .

Here A ~ z means both (A_1, z) and (A_2, z) are holes (i.e. z is
non-adjacent to both A_1 and A_2 in H).

[The exact statement and proof of these two theorems is the
content of Part 4, Theorems 27.1 and 28.1 respectively.]

14.5  Theorem 4.1 from the two distribution tests.

Granting Theorems 27.1 and 28.1 (Distribution Tests 1 and 2), we
prove Theorem 4.1.

Proof of Theorem 4.1.

Choose g large enough that the machine constant c(g) satisfies

   c(g) > 100,

and let n tend to infinity through integers with n >= 2r_0 (r_0
from the ledger).  Let m = 2^{C_0 g N} for C_0 = C_0(g) chosen
smaller than 1/(100g) (e.g. C_0 = 1/(200g)).

Sample m frames from pi_n independently; let H be the graph of
14.1.  By Lemmas 14.1 and 14.2, alpha(H) <= 2 and chi(H) >= m/2.

We need to prove properties (G1), (G2), (G3).

Property (G1) [coloured conflict].  Let M be a matching in H of
size >= m/20, partitioned into classes of size at most am for a
small constant a.  Suppose for contradiction that no two
conflicting edges lie in different classes.  Then, for any two
edges e = {u, v}, f = {u', v'} of M in different classes, the
four cross pairs (u, u'), (u, v'), (v, u'), (v, v') cannot be
holes: at least one is an edge of H.

Fix a colouring induced by the class partition: colour edge
e (with the totality of M) with its class index.  Under a
"coloured matching" reduction, this gives a coloured unit law
which violates Distribution Test 1.  Specifically, the
proportion of conflicting edges in the matching is < m/100 after
restricting to different classes.  By Distribution Test 1, for
any positive-mass coloured law, a positive fraction of pairs would
have four cross holes - contradiction.

The formal reduction is: apply Distribution Test 1 to the
"paired units" obtained by pairing matching edges; class sizes are
bounded by am with am + am <= 2am, small enough.  Colour is the
class index.  The failure of (G1) is exactly that no cross-colour
pair has four holes, contradicting Distribution Test 1.

Property (G2) [edge-point conflict].  Let M be a matching of
size >= beta*m and S a vertex set of size >= beta*m.  Suppose for
contradiction that no conflicting edge-vertex pair exists.  Then
for every edge {u, v} of M and every vertex w in S, at least one
of {u, w}, {v, w} is an edge of H (rather than a hole).  This
violates Distribution Test 2 applied to the induced marked point
law (with L ~ 1/beta fixed).

Property (G3) [hole density].  Let S_1, S_2 be vertex sets of
size >= beta*m each.  Then either S_1 ∩ S_2 contains an internal
hole (a pair {x, y} contained in both S_1, S_2 with a hole), or
there is a cross hole {s_1, s_2} with s_1 in S_1 minus S_2 and s_2 in
S_2 minus S_1.  Both cases contradict the assumption of no cross hole.

The "either" case is handled by noting: if the sets S_1 and S_2
are disjoint, the density of safe points drops and Distribution
Test 2 (applied to a restricted set as a marked point law
with L ~ 1/beta) gives a cross hole.  If they intersect, we can
replace both sets by their shrunken copies (still of size
>= beta*m / 2) and apply the same argument.

[The "shrunken copy" argument: any intersection of two sets of
size >= beta*m contains at least 2 beta*m - m >= beta*m / 2
vertices if beta <= 1/4.  The full argument is in the proof of
Distribution Test 2 in Part 4.]

Therefore H satisfies (G1), (G2), (G3) with the parameters
a = am and beta as given.  Since alpha(H) <= 2 and |V(H)| = m
is arbitrarily large, H serves as the graph of Theorem 4.1.  []

PART 4.  THE DISTRIBUTION TESTS
================================================================

Part 4 proves Distribution Tests 1 and 2 (Section 14.4).  This is
the technical heart of the whole construction, and most of the
proof complexity of the paper lives here.

The plan has six stages, all of them building on the first:

   STAGE 1 (sec. 17).  PEELING.  Any restricted unit law
      decomposes into at most 2^{O(N)} "leaves", each of rank at
      most k_max, with controlled entropy deficit.

   STAGE 2 (sec. 18).  MOMENTS.  A bounded-rank leaf has a
      canonical decomposition into "labels" that separates the
      cut-profile data into a product of small pieces.

   STAGE 3 (sec. 19).  MIXERS.  The bilinear form T of Section
      11.7 is completed with a fixed collection of endomorphisms
      L_j, R_j whose interaction with the moment-matrix data is
      "generic", allowing the later phase arguments.

   STAGE 4 (sec. 20).  PHASE ALTERNATIVE.  A Walsh-character
      analysis shows that either (i) all nontrivial phase means
      are tiny, or (ii) the phase mean has a rigid "well-signed"
      structure (a "tiny cover" of the offset list).

   STAGE 5 (sec. 21).  STATUS PREPARATION.  From the phase
      alternative we extract "status classes" (e_i, alpha_i, c),
      either with no prediction or with a rigid prediction.

   STAGE 6 (secs. 22-27).  HISTOGRAMS, PRODUCT TESTS, COMMON
      LIMIT, STATUS SPAN, ASYMMETRIC TEST.  The rest of the
      argument.

Throughout, "N" is one of the construction-parameter integers

are chosen in the parameter ledger.

16.  Setup: units, keys, and probabilities
----------------------------------------------------------------

16.1  Units.

Recall (sec. 14.4) that a UNIT is a pair (A_1, A_2) of raw frames
F, F' that are "not hole-connected", i.e. an edge of the graph H
from Section 14.  Since pi_n has full support on rawlaw, the law
of a unit is essentially pi_n^(x2) restricted to the "edge" event.

The DISTRIBUTION TESTS of Section 14.4 are:

   Test 1.  Two independent units, with colour, are tested for
      a four-cross-hole relation with different colours.
   Test 2.  One unit plus an independent point, tested for
      two cross-hole relations.

Both tests involve three independent frames: (A_1, A_2) plus
(B_1, B_2) for Test 1, or (A_1, A_2) plus z for Test 2.  We will
often write a unit as an ORDERED PAIR of frames, with the notation
A = (A_+, A_-) where "+" and "-" are the two endpoints.

16.2  Keys.

Given a frame F and a tag l in I, the KEY of F at l is
the restriction

   K_l(F)  :=  (P_{l, e}, X_{l, e}, Q_{l, e}, Y_{l, e})_{e ni l}

of the frame data to components incident to l.  It is the
smallest piece of a frame that interacts with the "hole
witnesses" at tag l.

The key lives in a space  cK_l  of dimension 2|{e ni l}|(d+h)
times N (as a tuple of vector spaces); its image lands in
F^{N x 2|{e ni l}|(d+h)}.

16.3  The frame as tuple of keys.

A frame F is determined by the tuple (K_l(F))_{l in I}.  Because
each edge e = {l, l'} in E is the intersection of the two keys
K_l(F) and K_{l'}(F), constraints on cross Grams are naturally
"shared" between neighboring keys.

For a sample of m frames, the joint distribution of the tuple
(K_l(F_i))_{i in m, l in I} is what we work with.

16.4  Restriction to a unit.

Given a unit (F, F'), the "primed" and "unprimed" endpoints
share no keys but their frames interact through the hole relation
at every tag.  Concretely, the "sum"  K_l(F) (+) K_l(F')  is
what determines the "cross-Gram at l" and hence whether the
hole condition holds.

The precise setup for the "parity witness" of the hole uses the
canonical small "tester matrices" (v_{iz}, v_{zi}) whose role is
to combine a small piece of K_l(F) with a small piece of K_l(F')
into a parity check.  We defer the explicit construction to
Section 19.5 where the "mixers" are defined.

16.5  The distribution tests as small-tuple probabilities.

We will express Distribution Tests 1 and 2 as probabilities of
specific SMALL TUPLE EVENTS in the sampled frames: for Test 1,
events about (F_A1, F_A2, F_B1, F_B2); for Test 2, events about
(F_A1, F_A2, F_z).  Each small tuple has at most 4 frames, hence
at most 4|I| keys, hence a small finite "type" (in the sense of
tensor products of at most 4(d+h) x N-sized blocks).

The bulk of Part 4 studies these small tuple events.

17.  Leaves and peeling
----------------------------------------------------------------

17.1  The peeling lemma.

Fix a restricted unit law sigma on units (F, F').  Suppose sigma
has bounded total mass relative to pi_n^(x2).  We want to
decompose sigma into a small number of "leaves" whose structure
is easier to analyze.

The relevant structural tool is the "peeling" lemma.

Lemma 17.1 (peeling, cf. sec. 04-moments).

Let sigma be any sub-probability law on units (A = (A_1, A_2) with
A_1, A_2 independent in pi_n and {A_1, A_2} an edge of H).  Then
there exist:
  - at most 2^{kappa N} "leaves" ell_a,
  - each leaf having rank r_a <= k_max (a fixed parameter),

such that

    sigma  =  sum_a sigma_a

as a sub-probability decomposition, and: for each leaf ell_a,
the "unit restricted to ell_a" is a FULL-RANK leaf in the sense
that the tuple of vectors defining the unit within ell_a is
linearly independent, and for each leaf

    ell_a(unit mass)   >=   2^{-zeta N}   (unless = 0),

and

    ell_a(view mass on a single key)  <=  2^{-(1 - zeta) r_a N + O(1)}.

Here zeta = 1 / (1000 k_max) is a small fixed constant, k_max is
a fixed rank bound, and "rank" means the tensor rank of the
restricted product measure.

Sketch of the peeling argument.  At each stage, take a maximal
"violating" tuple of key directions (linear constraints that
have not been imposed).  Because the sigma-law mass is bounded
by pi_n^(x2) mass, the "cost" of each such constraint is at most
2^{-(1 - zeta) N} of the current mass (per peeled coordinate).
Iterate; each stage either peels a small-mass part (which becomes
a leaf) or reduces to a lower-rank residual.  The bound on the
number of stages follows from the log_2 |Omega_n| = O(N^2) bound
on total mass.  []

17.2  Consequence: leaves have bounded rank and thin mass.

Each leaf is a "flat" - a single linear subspace of the frame
space - and each leaf mass is at most 2^{-(1 - zeta) r N + O(1)}.
The rank parameter r ranges between 1 and k_max; k_max is chosen
much smaller than N.

17.3  The minimal-entropy leaf form.

Each leaf ell has a canonical "conditional" measure nu_ell on units
(for frames inside the leaf).  We normalize ell to be a
probability, i.e. we work with the conditional unit law inside
ell rather than the "oriented quantity".  Then we have:

    nu_ell  >=  2^{-2 zeta N}  mass fraction
              of pi_n^(x2),
    and every key has nu_ell-key-mass at most 2^{zeta N} times
    pi_n-key-mass at the leaf's orientation.

We state this as a lemma for reference.

Lemma 17.2 (leaf bounds).

There is a peeling of any bounded-restriction unit law into at
most 2^{kappa N} leaves, each of which is a conditional unit
measure nu_ell on a bounded-rank subspace, satisfying:

    (mass bound)   nu_ell(unit mass) >= 2^{-zeta N} > 0
    (key density)  for any key cell A,
                   nu_ell(K in A) <= 2^{zeta N} pi_n(K in A)
    (rank bound)   rank(nu_ell) <= k_max
    (regularity)   nu_ell is a convex combination over a finite
                   set of "flat" unit laws.

The constants kappa, zeta, k_max are fixed by the parameter ledger.

The key density and mass bound are what make the peeling useful:
they let us compare any "peeled probability" to the original pi_n
probability with only a 2^{zeta N} multiplicative cost.

18.  Moment matrices and label decomposition
----------------------------------------------------------------

18.1  The Boolean moment matrix of a leaf.

Fix a leaf at rank r <= k_max.  Within the leaf, we have a set of
"supply vectors" (the projections of key directions into the leaf
space) and "cross Grams" (bilinear forms induced by the leaf's
unit law).

The MOMENT MATRIX of the leaf is the matrix

    M_leaf  :=  E_{nu_ell}[  v v^T  ]  in   (B_y (x) B_y)^* ,

where v is the "atom" of the current unit as a tensor in B_y (x)
B_y, and the expectation is over the leaf's unit law nu_ell.

The MOMENT MATRIX is the carrier of the leaf's structural
information.  In Part 4 we analyse M_leaf by "decomposing" it into
smaller structural pieces.

18.2  Boolean degree and flat levels.

The point moments of Section 11 span W.  A bounded-rank subspace
of W is filtered by "Boolean degree": subset of W consisting of
moments of base-degree up to j (equivalently, selector degree up
to j after the selector tensor factor is forgotten).

The FLAT LEVEL j of the moment space is the subspace

    V_j  :=  span  { v(s, z) v(s, z)^T : |z as base bit-set| <= j,
                     |s as selector bit-set| <= j_* }

where |z| denotes bit-weight (number of 1's) and |s| similarly.
Then V_0 subset V_1 subset ... and the full space is V_{j_*} for
some j_* in the parameter ledger.

Lemma 18.1.  For any leaf with rank r, the moment matrix M_leaf
lies in V_j for j = j_*.

Proof.  Any product tensor v v^T has degree at most 2j_* in the
combined selector+base coordinates, and rank <= r restricts to a
fixed finite-dimensional space in V_{j_*} by the supply structure.
[]

18.3  Label decomposition.

The key structural result of this section is: a bounded-rank
element of V_j decomposes as a sum of at most R_* "labels", each
label being a rank-1 tensor on a specific subspace of the base
coordinates.

Formally, for a leaf with moment matrix M_leaf and rank r <= k_max,
we can write

    M_leaf  =  sum_{s in L}  Z_s  (x) (sum of selector-monoms),

where:
  - L is a finite set of "labels" of size |L| <= R_* (bounded
    by 2^{O(k_max)});
  - each Z_s is a symmetric 2^{k_max} x 2^{k_max}-dimensions
    matrix of rank bounded by k_max, sitting on a specific
    subspace of the base coordinate space determined by s;
  - the "selector part" is a fixed tensor of the selector
    coordinates at s.

Lemma 18.2 (label decomposition).

For every leaf ell of rank r <= k_max, there is a decomposition
as above.  The number |L| <= R_* is bounded in terms of k_max
alone.  Each Z_s satisfies rank Z_s <= k_max and satisfies
the "Boolean idempotent" identity

    (Z_s)_{ii}  =  (Z_s)_{0 i}   for every base coordinate i.

Proof.  Take Q = V_j / rad(V_j) with respect to the restricted
pairing on V_j.  The commuting family of selector-coordinate
multiplication operators splits Q into joint eigenspaces.  Each
eigenspace is a rank-1 subspace of the base coordinates.
Repeated application of the selector-coordinate operators
extends the moment space until it spans Q.  The decomposition
is exactly the simultaneous eigenspace decomposition of Q,
assigned to labels in L.
The rank bound rank Z_s <= k_max comes from dim Q_s <= k_max at
each label.
The idempotent identity comes from  s_a^2 = s_a  in F_2, giving
B(M_a M_b f, g) = Lambda(s_a s_b f g) = B(M_a f, M_b g), which
iterates to the stated identity.  []

18.4  Consequence: leaf moments are "flat sparse".

The label decomposition has two key consequences for the later
phase analysis:

  (a)  Each label s has a "support" of at most 2 k_max active
       base bits (a "sparse support" bounded by 2 k_max).

  (b)  Different labels have "orthogonal" selector parts, so
       different labels' contributions to a phase mean factor
       separately.  This factorisation is the engine of the
       phase alternative in Section 20.

Concretely: an atom of a leaf has the form

    atom(s, z)   =  sum_{s' in L}     ( Z_{s'}(z', z'')  bi-linear
                                       in z', z''  in  2 bits,
                                       designated by s')

where z' and z'' describe the label-s' contribution.  Modulo
"zero contribution" atoms, we get a compact form for parities of
the atom.

19.  The mixers
----------------------------------------------------------------

19.1  Purpose.

The bilinear form T of Section 11.7 (the "T-form") must be chosen
so that, for the atoms produced by the leaf decomposition, T has
a "generic" interaction structure.  Specifically, we need:

  (MIX-1) For any pair of distinct labels s, s' in a leaf, T
          restricted to the atoms of s and s' has rank at least
          J - s_0 (for a "mostly-full-rank" constant J).

  (MIX-2) The same for the same label at "interiors" of the base
          support.

  (MIX-3) The mixers act independently on distinct labels,
          giving independent uniform joint behaviour.

The parameters J, s_0 and the endomorphisms L_j, R_j are chosen
to achieve (MIX-1)-(MIX-3) simultaneously.

19.2  The mixer construction.

Fix a "generic" endomorphism  M_0  of B_y (the base space of
Section 11.3) to be a "uniform random" endomorphism.

Let A_+ and A_- be linear functionals (given by the mixers) on
the selector-part of B_y.

The mixers are:

    L_j^{ef}  :=  M_0^j  L_0
    R_j^{ef}  :=  M_0^j  R_0

for fixed "bases" L_0, R_0 and j = 1, ..., J.

Lemma 19.1 (generic mixer existence).

For J sufficiently large (J > 100(s_0 + k_max)), there exist
choice of M_0, L_0, R_0 (uniform random on the appropriate
Grassmannian) such that, except with probability 2^{-Omega(n)}:

  (a)  The restriction of T (defined from L_j, R_j via 11.7)
       to any pair of distinct labels in any leaf has rank at
       least J - s_0.

  (b)  The restriction of T to pairs of "pure" atoms (rank-1
       atoms at distinct labels) has a specific binary Gram
       shape that gives alternating parities.

  (c)  Distinct labels' contributions factor separately.

Proof sketch.  This is a "random subspace meets all possibilities"
argument.  M_0 chosen uniformly at random makes the L_j, R_j
collection "generic"; for fixed structure to fail (a), (b), or
(c), M_0 must be constrained to a subvariety; the union bound
over all (bounded) label pairs and leaf structures gives the
failure bound.  []

19.3  Mixers and the T-form.

With the mixers chosen as above, T satisfies all the properties
claimed in Section 11.7 (T(x, x) = a(x), T^1 alternating, etc.).
The parameter J appears in the phase alternative as a "spread"
constant (larger J gives tighter phase bounds).

The values of J, s_0, and the mixer construction are fixed in the
parameter ledger.  In particular, all later constants depending
on J can be made exponentially small in n (or bounded, whichever
is needed).

20.  The phase alternative
----------------------------------------------------------------

20.1  Setup.

Fix a leaf ell of rank r <= k_max, and consider the unit law nu_ell
restricted to ell.  Because ell is a "flat" (bounded-rank
restriction), the unit law within ell factors as: the two
endpoints (A_1, A_2) of the unit, and the "internal" Gram data
of each, are determined by a tuple of independent coordinates.

Specifically, a "unit" inside ell has structure

    A_1  -  independent coordinates  -  defined by  -  "primal"  side
    A_2  -  independent coordinates  -  defined by  -  "primal"  side

with the "channel" sides of A_1 and A_2 being drawn from a small
bounded family (thinned by pi_n).

The HOLE WITNESS for the unit is a specific tuple

    (v_{iz}, v_{zi})_{l in I, z in B}   in    primal-tuple (A_1) x primal-tuple (A_2),

and the "cross-Gram equations" of the hole involve both
endpoint primals.

20.2  The phase.

Fix the "base" data (the primal tuple (v_{iz}, v_{zi}) of the
witness within the unit), and consider the "channel choices" as
random.  A PHASE is a function

    Phase_l(F_1, F_2)  :=   (-1)^{ u_l(v_{iz}, F_1) + u_l(v_{zi}, F_2) }

where u_l is a specific bilinear form on the "channel-difference"
data of the two frames, evaluated at tag l.

The TOTAL phase of a unit is the product over all tags l of the
per-tag phases.  Since channel choices at different tags are
independent (within pi_n), and the per-tag phase involves only
tag-l channel data, the total phase factors:

    Phase(F_1, F_2)  =  prod_{l in I}   Phase_l(F_1, F_2)   .

20.3  Statement of the phase alternative.

Fix a leaf ell as above.  Consider "cross-unit" probabilities
between the leaf and ITSELF (or between two leaves): the phase
means

    Phi(S, R)  :=  E_{nu_ell x nu_ell} [ Phase(F_A, F_B)  given
                    specific "singular support" (S, R) of
                    coefficients ]

where (S, R) describes which of the witness base coordinates are
used at each tag.

The phase alternative says: either all nontrivial phase means
Phi(S, R) are extremely small, or the phase structure is
"rigid" and captures a lot of mass.

Theorem 20.1 (phase alternative).

Fix a leaf ell of rank r <= k_max.  Suppose throughout the leaf
that Delta_O != 0 (a "nontrivial offset" condition; see 20.4
below).  Then one of the following holds:

  (i)  Every nontrivial phase mean Phi(S, R) for (S, R) != (empty,
       empty) has absolute value < 0.005.

  (ii) The phase F(A, B) := u_{B, {1, 2}}(Delta_A)  is zero for
       every pair of retained units (A, B), and every phase mean
       Phi(S, R) with |S| = 1 or |R| = 1 is at most 2^{-Omega(N)}.

Every retained unit stays within its original leaf (no new pins).

Proof sketch.  The proof has three steps.

STEP A.  Reduce to a Walsh sum via label decomposition.  Each
atom of the leaf, decomposed by label as in Section 18, has
bounded selector support.  For a cross-unit pair (A, B), the
phase evaluates to a sum of at most |L|^2 terms, each being a
product of a "matched" U_A U_B character times a
"cross-character" chi_class(B, A).

STEP B.  Walsh estimate.  Each nontrivial summand (chi != 1)
has, by the mixer property (MIX-1), Z-polar rank at least J - s_0
and factors through a bounded-dim space.  Applying the
Walsh estimate of Section 20.5 (to be proved), the magnitude of
each such summand is at most 2^{b_int}  where b_int = 2^{-J +
2 s_0}.  With J > 100(s_0 + k_max), this is small.

STEP C.  Alternatives.  If no phase summand of the "large support
offset" type achieves total mass >= p_0, then alternative (i)
holds directly (every mean is a sum of small Walsh summands).  If
some offset list does achieve mass >= p_0, then alternative (ii)
holds for that offset list, because the mixer structure "locks"
the phase means to be either zero (the sum is zero) or 2^{-Omega(N)}.

The full detail is in sec. 12 of the original (thm:phase-alternative);
here we record the conclusion and note the essential dependence
on the Walsh estimates (Lemma 20.5 below).  []

20.4  The offsets.

The condition Delta_O != 0 in Theorem 20.1 refers to the
"offset list"  (Delta_A, Delta_B)  of the unit pair: the tuple of
coordinate-differences between the primal witnesses of A and B.

Because Delta_O != 0 (the assumed condition), there are
bounded-rank "basis vectors" a_alpha, b_beta in the offset list
whose span has dimension at least 1 but at most 2r.  Their
"companion" tuple Z_O (the products  X Y^T a,  etc.) has
bounded point-mass at most 2^{-t_O N + O(1)} for the companion
rank t_O (Lemma 20.3 below).

Lemma 20.3 (companion bound).  For any fixed offset list
Delta_O = (Delta_{O, 1}, ..., Delta_{O, r}) of rank t_O, the
"companion" tuple Z_O of Lorentz-companion directions has
point mass bounded by 2^{-t_O N + O(1)} under the leaf's
measure pi_ell (for the specific orientation of the leaf).

Proof.  Standard Gram-normalisation argument: enumerate the possible
"nominal representations" of the companion (2^{O(r d)} of them,
absorbed into 2^{O(n)}), each with point mass bounded by the
"image bound" of Part 4 (Lemma 20.6, statement below).  []

20.5  Walsh estimates (proof/statement deferred).

The essential form of the Walsh estimate used in the proof of
Theorem 20.1 is:

Lemma 20.5 (Walsh estimate).  Let x, y be independent uniform
vectors in F^{2N}.  Let B be a bilinear form of rank d.  Then

    |  E_{x, y} [ f(x) g(y)  (-1)^{ B(x, y) } ]  |  <=  2^{-d/2}

for any bounded f, g with |f|, |g| <= 1.  More generally, if
either x or y is drawn from a distribution bounded by C_i in
sup-norm (relative to uniform), then the bound gains an extra
factor C_i.

For sub-probability measures, the estimate scales with the
point-mass bounds:

    |  sum_{x, y}  alpha(x)  beta(y)  f(x) g(y)  (-1)^{B(x, y)}  |
        <=  2^{2N/2}  (p_1 p_2)^{1/2}

where p_1 = max alpha, p_2 = max beta, and "2N" is the total
integer dimension of x, y together.

Sketch.  The estimate is a form of Parseval for a rank-d bilinear
map: sum over the rank-full part factors separately, and each
factor contributes 2^{-d/2} from the Walsh character.  For general
density bounds, use the row-sum bound: sum_x |alpha(x)| 2^{-d/2}
times sum_y |beta(y)|.  []

20.6  Image bounds.

We also record the "image bound" referenced in Lemma 20.3.

Lemma 20.6 (image bound).  For any event that specifies the
image of t independent directions under the plus frame P (or
under P and Q together) up to the linear structure, the
probability of the event under pi_n is at most

    2^{-t N  +  eps_ch N  +  O(1)}.

For images under both P and Q, with ranks t_+ and t_-,

    2^{-t_+ N  -  t_- N (N - 2(d+h)) / N  +  eps_ch N  +  O(1)},
    i.e.  2^{-t N  +  eps_ch N  +  O(1)}  for total rank t
    bounded below.

Proof sketch.  For a specific "image event" E, using the raw law:
- plus images: uniform injective family, probability 2^{-t_+ N};
- minus images: by the corner case of Lemma 12.3, probability at
  most 2^{-t_- N · (N - 2(d+h)) / N}, i.e. 2^{-t_- N} up to lower-order
  corrections.
Multiplying by the pi_n/rawlaw density ratio (2^{eps_ch N}) gives
the stated bounds.  []

Full proof is in the original 02-geometry.tex, Lemma
reference-image-cap; the sketch above suffices for our purposes.

21.  Status preparation
----------------------------------------------------------------

21.1  Prediction.

After the phase alternative, some leaves may be in alternative
(ii) (rigid phase).  For those leaves, we can further restrict to
a positive-mass sublocus where the phase has a very specific
structure.

DEFINITION (prediction).  A PREDICTION on a leaf ell is a
quadruple (alpha_1, alpha_2, c, (e_1, e_2)) of data where:
  - alpha_1, alpha_2 in F_2,
  - c in F_2,
  - e_1, e_2 are "prediction classes" (equivalence classes of
    "unary functions" modulo the "trivial" function q(x) = eta_S).

A prediction is "realized" if for every retained unit (A, B,
possibly from different leaves) with specific support, we have

    u_{A, i}(Delta_B)  =  alpha_i  a(Delta_{A, i})  +  c  +  f_i(Delta_A)

for each i in {1, 2}, where f_i is a fixed function of the
cross-gram data (a "unary error function") that depends only on
the label category.

We say a leaf "has a prediction" if a prediction is realized on
that leaf with an "error" that tends to zero uniformly in n.

21.2  The two alternatives for a prepared leaf.

Given a restricted unit law, at most a factor of 16 mass is lost
by pigeonholing the "prediction class" (e_1, e_2), the (alpha_1,
alpha_2) values, and the c bit.  After this reduction, we get:

Theorem 21.1 (status preparation, thm:status-preparation
from the original).

There exist constants delta_*, c_* > 0 (fixed in the ledger) with
the following property.  For any restricted unit law with
endpoint bound M*pi and projected pair density bound
2^{3000 g N} * pi^2, there is a restriction of mass at least
delta_*  satisfying:

  (a)  First pin dimension <= K_1 (a fixed integer).

  (b)  Every leaf nu_ell satisfies the min-entropy bound
       nu_ell(unit mass) >= 2^{-zeta N}.

  (c)  EITHER (no-prediction case)
       for independent draws from the prepared law, the
       probability of an admissible injecting "actual small
       table" is greater than 0.99,
       OR (predicted case)
       a prediction with fixed (alpha_i, c, e_i) is realized,
       and the probability of an admissible injecting actual
       small table satisfying the "phase-compatibility"
       condition is at least 1/64.

Every retained normalization has endpoint primal marginal at most
Lambda_0 * pr_* rawlaw  for a fixed Lambda_0.

21.3  Proof sketch.

The proof splits into two cases.

NO-PREDICTION.  If the phase alternative never reaches alternative
(ii) on any positive-mass event, take any leaf that is
"typical" and apply the pin-injection lemma (Lemma 21.2 below):
for large n, the probability that two independent draws from a
typical leaf produce an "actual small table" (a specific
configuration of directions and Gram values that lets the hole
succeed) is > 0.99.  This is a direct consequence of the
pi_n positivity and the injective family property.

PREDICTED.  If some prediction is realized, pigeonhole over the
16 possible values of (alpha_1, alpha_2, c, delta_e).  Each
retained sublocus has positive mass at least 1/16.  On each
sublocus, the "phase-compatibility" condition (a specific
algebraic relation between the "role bits" and the "offset
bits") holds by the prediction, and the "actual-small-table"
existence reduces to the same lemma applied with the extra
condition.

[]

21.4  The pin-injection lemma.

The pin-injection lemma (referenced in the proof of Theorem
21.1) is the technical input that ensures that a "typical"
small unit pair will produce a valid hole witness with a
positive (bounded below) probability.

Formally:

Lemma 21.2 (pin-injection, lem:injection in the original).

Let the lemmas' setup be as above.  Consider the sublocus of
units that is:
  - a leaf at rank r_a <= K_1,
  - satisfying the "phase-compatibility" alternative as specified
    by an appropriate (alpha_i, e_i, c) prediction,
  - with the "actual small table" condition being exactly that
    the pairs of vertex-vector directions (one from each of the
    two endpoints) are "injecting" and its cross Gram satisfies
    the hole equations.

Then the probability, over two independent draws from a
uniform-restricted sublocus, that the small table is
"admissible and injecting" is greater than 1/128 times the
sublocus's own mass (appropriately normalized).

Equivalently: the sublocus has bounded "hole-success probability"
under an arbitrary injection-tolerant restriction.

The proof is by a "coefficient inclusion" argument: the phase
alternative ensures that within the leaf, the "cross-length"
coefficients of the small table are bounded; combining with
injectivity of the leaf's primal and channel directions (which
is bounded below by 1-2^{-eps N} from the Gram-uniform
injectivity of Lemma 12.3) and with the uniform-structure
lattice conditions, we get the injection bound.  []

21.5  Retained mass bound.

At the end of status preparation, we have retained mass at least

    delta_* c_* = delta_*^2 / 64,

which is a strictly positive constant in the ledger.  In addition,
the "colour-avoidance" margin (used in Distribution Test 1) is

    eta_col  <  c_* / 4,

where c_* = delta_*^2 / 64.  This ensures that after removing
the "same-colour" pairs from the prepared law (bound by
eta_col * mass), we still retain a positive-restricted-mass
population of DIFFERENT-colour pairs.

That closes Stage 5.  Part 4B completes Stages 6 and the rest
of the argument.

22.  Histograms and the weak product comparison
----------------------------------------------------------------

22.1  Purpose.

This section proves the "weak product" comparison used in the
status-preparation assembly (Theorem 21.1) and, more importantly,
in the common limit (Section 23).  The statement is a
"bounded-test approximation": any bounded function of a tuple of
keys can be approximated, up to small error, by a sum of a
bounded number of products of unary functions.

22.2  Uniform integrability of key laws.

First, a "uniform absolute continuity" fact for key laws.

Lemma 22.1 (uniform integrability).

Fix a bounded query shape.  Consider any family of "normalized
leaf laws" nu_L on units satisfying nu_L <= 2^{C N} rawlaw^2
for fixed C.  Then for every eps > 0 there is R < infinity such
that, for all nu_L and all sufficiently large n, the tail event
"key mass density > R" has nu_L-mass below eps.

More generally, for the key K_l drawn from any nu_L, the
"query-key density" is uniformly integrable across leaves.

Proof sketch.  The key law under nu_L is bounded by
2^{C N}  times  rawlaw's key law.  Raw-law key mass at a specific
key cell is bounded by the "image bound" (Lemma 20.6) uniformly
across cells, and the argument iterates to give a bounded
expectation of the density's positive part.  []

22.3  Weak product comparison theorem.

Theorem 22.2 (weak product comparison,
thm:weak-product in the original).

Let W_n be any sequence of real functions on the r-fold product
key space  K_n^{(r)} = (K_1 x ... x K_r)  with ||W_n||_infty <= B
(fixed).  For every eps > 0, there are constants
L = L(B, eps) and C = C(B, eps), independent of n, and functions

    S_n(k_1, ..., k_r)
       =  sum_{a=1}^L  c_{a, n}  prod_{j=1}^r  f_{a, j, n}(k_j)
    with |c_{a, n}| <= C,  |f_{a, j, n}| <= 1,

with the following properties:

  (i)  Under the raw reference measure nu_n on r-tuples of
       independent keys, for any bounded unary functions
       g_{1, n}, ..., g_{r, n}  of bound one,

       |  sum  (W_n - S_n)  prod_j g_{j, n}  dnu_n  |  <=  eps
       for all sufficiently large n.

  (ii) Under any mixed unit law satisfying (histogram-mixed-caps,
       i.e. endpoint bound L * pi_n per key and pair-density
       bound 2^{3000 g N} * pi_n^2), outside an exponentially
       small exceptional set of orientations,

       sup_{|w_j| <= 1}  |  E_z  A_n(O, z)  (W_n - S_n)(K(O, z))
                              prod_j  w_j(O, z_j)  |  <=  eps.

       Here A_n(O, z) is the orientation-graded "actual sample
       count" grading (0 or 1).  The w_j may depend on the entire
       orientation.

The feature of (ii) is that it allows the unary weights w_j to be
arbitrary orientation-dependent functions; the bound is
uniform over them.

Proof sketch.  The proof has two parts.

PART I: The reference approximation.

Reduce to the case r = 2 first.  On K_n x K_n, expand the
"twisted cut" of W_n - E[W_n]:
consider the conditioning sigma-algebra generated by finite
partitions of the two coordinates and the Gram data.  By a
bounded-number-of-refinements argument (twisted regularity,
Lemma 22.3), the function W_n decomposes as

    W_n  =  S_n^{tw}  +  R_n,

where S_n^{tw} is a bounded linear combination of "twisted
product" terms, and R_n is a "terminal term" with twisted cut
norm < delta (delta as small as we like).  Each twisted product
term factors as a bounded Fourier combination of unary tests
times a "Gram twist" character.

The reference bound (i) then follows from Walsh estimates for
the twisted-cut decompositions (same machinery as Lemma 20.5).
For multi-factor r > 2, iterate the two-factor argument on
splits of the full position set; each terminal factor is left
as one "unary" component, and the structured factors are
split recursively until all factors are unary.

PART II: The actual-query comparison.

The actual-query comparison follows from a four-copy argument:
(W_n - S_n) is bounded, so its fourth power is nonnegative and
bounded; the actual-query error squared is at most a quadruple
integral whose Walsh structure factorises.  The cross terms
gather into products that either match at the "reference" level
or have high "bit rank" (>= N) and so are bounded by
O(2^{-N/2}) by Walsh.

The role of (histogram-mixed-caps) is to bound the pair-density
so that the exceptional integral is small.  The bound is uniform
over the weights w_j.  []

22.4  The twisted cut and its regularity.

Lemma 22.3 (twisted regularity from bounded-net, lem:product-twisted-regularity).

Fix a bounded function W on (K_n)^r with ||W||_infty <= B.  For
every delta > 0 there is a bounded family of "twisted Gram"
characters such that W factors as a bounded sum of twisted
products plus a remainder with twisted cut norm < delta.

Proof sketch.  Quantize W; refine partitions by the quantized
levels; iterative conditional-expectation decomposition bounded
by 4B^2/delta^2 + 1 rounds.  Finite Fourier expansion on the
Gram bits.  []

22.5  The four-copy expansion.

For the actual-query comparison, one uses a four-copy (four
independent orientation records) expansion.  The key relation is:

Lemma 22.4 (four-copy identity).

Let W = W_n - S_n with |W|_infty <= 2B, |S_n|_infty <= CB.  Then

    E_{O, z}  A_n(O, z)  W(K(O, z))  prod_j w_j(O, z_j)^2
        =  ...  (expansion into products of twisted-cut factors);

where the expansion bounds are:

    sum of nontrivial four-copy contributions  <=  O(2^{-N/4}).

The role of the "four-copy" structure:  W is a bounded function
of an r-tuple of keys, so W^4 is a bounded, nonnegative function
of a 4r-tuple.  The 4-fold product
    W(K_1) W(K_2) W(K_3) W(K_4)
under independent orientations decomposes into cross-character
sums; the cross-character sums with mixed 4-tuples (i.e. not
"four unary factors") contribute at most 2^{-N/2} by Walsh
estimates.  The remaining "four unary factor" sums assemble into
the twisted product expansion from Lemma 22.3.  []

The actual proof combines Lemma 22.3 and Lemma 22.4 into
Theorem 22.2(ii); the argument iterates over the r positions
of W and is bounded by (r + O(1)) fragments of the two-factor
expansion.  []

23.  The common limit
----------------------------------------------------------------

23.1  We now formalize the "limit of successful queries" from
Theorem 22.2.  The content is a compactness statement: after
passing to a subsequence, the "successful queries" of our
original setup have a common limit that can be analyzed as a
continuous object.

23.2  Compact bit-sequence spaces.

Fix a tag l in I and a diagonal bit q in F_2.  Let  Omega_{l, q, n}
be the probability space of "global plus frames on the star of l,
conditioned on q in every component" with its rawlaw-uniform
measure.

Lemma 23.1 (compactness).

There is a compact metric space  Xi_{l, q}  with a reference
Borel measure  m_{l, q}  of total mass one, and a sequence
of measurable maps  pi_{l, q, n} : Omega_{l, q, n} -> Xi_{l, q}
such that:
  - the pushforwards (pi_{l, q, n})_* rawlaw -> m_{l, q} weakly,
  - every  m_{l, q}-measurable event is approximated by
    pi_{l, q, n}-pullbacks of events for large n.

Sketch.  Take the compact product space of all sequences of bits
(finite queries of indicator variables at all "cells" of a
finite partition), and take the unique Borel measure
consistent with the cylinder masses.  []

Similarly for tuples:

Lemma 23.2 (tuple compactness).  For each tuple shape (r-fold
product of keys), there is a compact metric space  Upsilon  with
a Borel measure  rho  and natural projection maps
xi_j : Upsilon -> Xi_{l_j, q_j}  satisfying compatibility.

23.3  Common limit model.

The "common limit model" assembles the compact spaces into a
single random object Z:

    Z  =  ( theta_A, theta_B,  flags,  limit-query measures ) .

Each theta is a "base orientation array" containing:

    - its bounded discrete metadata (tags, labels, flavor cells,
      prediction coefficients if present),
    - its single-atom status measures: for each (tag, type,
      status) triple, a density  h^theta_{t, upsilon} : Xi_{l, q}
      -> [0, 1].

Normalization:

    sum_upsilon  h^theta_{t, upsilon}(xi)  =  1

almost everywhere.  And the sum over the "recorded actual" status
types of the "generic" flavor has a positive lower bound
(explicitly  beta_base > 0), by the pin-injection lemma applied
to the lower-bound forms of Section 21.

23.4  Successful query factorization.

A common query success on leaf pair (L_A, L_B) is detected by:

    (orientation-only flag)  x  (status indicators at each
    matched position)  x  (specified binary and Gram indicators).

The "orientation-only flag" is a bounded predicate on
(theta_A, theta_B); the "status indicators" are the indicator
functions 1_{upsilon = v_j}  at each position; and the "specified
binary and Gram indicators" are explicit Gram value conditions
checked at the leaf pair.

Notation: the "successful query measure" at a fixed orientation
record Z is a measure  G_Z  on the tuple key space.  It has a
density (Lemma 23.3 below).

Lemma 23.3 (density).

For almost every Z, the full limiting successful-query measure
G_Z on one side (say the A-side) is absolutely continuous with
respect to the reference measure  rho  on the tuple key space,
with density

    G_Z(u)  =  kappa_Z  int  prod_l  h^theta_{t_l, v_l}(xi_l(u))
                               d alpha_Z(theta),

where  kappa_Z > 0  is a "binary mixing constant" and
alpha_Z is the "notation-only" subprobability measure on
"orientation arrays compatible with Z".

Proof.  The density is jointly measurable and non-negative.  For
any tuple cylinder indicator W, the empirical success is
approximated by the reference probability via the weak product
comparison, and the actual-query comparison transfers the
reference probability to the actual measure.  Both limits are
covered by Theorem 22.2.  []

23.5  The limit-overlap obstruction.

The key conclusion of the common limit analysis is:

Proposition 23.4 (limit overlap, prop:limit-overlap).

Assume that the "vanishing overlap" condition holds: for every
numerical option  omega  and every realization of the limit
model Z, the overlap between the two sides vanishes in the
appropriate sense.

Then for almost every sampled pair of orientation records (two
distinct leaves L_A, L_B) with  J(Z) = 1  (a permitted-pair
indicator), there is NO usable numerical option whose two
orientation flags pass and for which, at every matched position l,

    int_{Xi_{l, q_l}}
        h^theta_A_{t_A, v_A}(xi)   h^theta_B_{t_B, v_B}(xi)
        dm_{l, q_l}
        > 0.

Proof.  Fix an option omega and a compatible triple
(theta_A, theta_B, flag).  The "four cross holes" at every
matched position is a product structure.  By Lemma 23.3 and the
"limit-zero-product" lemma, the Fubini factorization is

    int G_{A, Z}  G_{B, Z}  d rho
    =  kappa_A  kappa_B  int int prod_l
            (  int  h^theta_A h^theta_B dm_{l, q_l}  )
            d alpha_{A, Z}  d alpha_{B, Z} .

All factors are non-negative.  Under vanishing overlap, this
integral is zero.  Averaging over Z and taking the finite union
over numerical options, the conclusion follows: at almost every Z
with J(Z) = 1, at least one of the inner integrals is zero for
every usable option.  This is the "no positive overlap" condition
that we need.  []

23.6  Reduction to status spans.

The conclusion of Proposition 23.4 is: for almost every
sampled orientation pair, there is no positive-overlap query
available.  This is a strong "no-coordinate-with-common-mass"
condition.  In Part 4C we use it to solve the status-span
problem, then assemble Distribution Tests 1 and 2.

24.  The status span
----------------------------------------------------------------

24.1  Setup: cross edges and generators.

Work in the common limit Z of Section 23 with a permitted pair
J(Z) = 1 of orientation records (theta_A, theta_B).  Both theta_A
and theta_B are prepared by Lemma 21.1 (with possibly different
alternatives), and both have bounded pin dimension K_1.

The "cross edges" of the pair are the four pairs

    (i, j) in {1, 2} x {1, 2},

where i indexes an endpoint of A, and j indexes an endpoint of B.
On each cross edge (i, j), the successful-query condition at tag l
involves:

    q      : diagonal bit of the atom, same on both sides;
    h      : role bit a(atom)  in {0, 1};
    x      : basis status vector (bounded dimension);
    p      : "channel-bit parity" at the edge;

and it must satisfy the "edge system":

   (E_{ij})  The pair "s_J" = s_j,  "r_i" is defined by   the
             scalar relation on (E_{ij}):
             s_j (p_{A, i} + h_{A, i}) + r_i (p_{B, j} + h_{B, j})
             = c_{ij} . x_{A, i} + c'_{ij} . x_{B, j}
             + beta_{ij}(h_{A, i} + h_{B, j})
             + gamma_{ij} q

where the coefficients s_j, r_i are in F_2, and c_{ij}, c'_{ij},
beta_{ij}, gamma_{ij} are coefficients.

The successful-query condition says: for every (i, j) and every
tag l, the edge system (E_{ij}) has a solution for the SPECIFIC
s_j, r_i that hold at that edge.

24.2  Available generators.

Define the AVAILABLE GENERATOR set (from Definition in sec. 12 of
the original):

    g  =  (q, h_{A, i}, h_{B, j}, x_{A, i}, x_{B, j}, p_{A, i}, p_{B, j})

is an available generator on cross edge (i, j) if some common tag,
surviving label, and compatible flavors give positive overlap in
the limit Xi_{l, q}:

    int_{Xi_{l, q}}
        h^theta_A_{t_A, v_A}(xi) h^theta_B_{t_B, v_B}(xi)
        dm_{l, q}  >  0

for these parameter values at every position (with v_A, v_B
recording the h, x, p entries).

Let V_{ij} be the F_2-span of these generators.  Its "base
projection" forgets the p entries, giving

    B_{ij}  =  F_2^3 + F_2^{dim C_{A, i}} + F_2^{dim C_{B, j}}.

Lemma 24.1 (generator generation, part of lem:status-duality).

For every successful query pair and every cross edge (i, j), the
generator set V_{ij} projects surjectively onto B_{ij}.

Sketch.  The base projection covers all possible (q, h_{A,i} +
h_{B,j}, x_{A,i}, x_{B,j}) combinations.  The p entries are
"effectively free" (bounded combinatorial dimension).  []

24.3  Dual relations.

Lemma 24.2 (dual relations, lem:status-duality in the original).

The scalar system (E_{ij}) is soluble on all edges (i, j) exactly
when no NONZERO dual vector  (s_1, s_2, r_1, r_2)  in F_2^4 makes
(E_{ij}) fail to be reproduced on every edge V_{ij}.

Explicitly: an obstruction to the scalar system is a nonzero
(s_1, s_2, r_1, r_2) such that, on every cross edge V_{ij},

     s_j(p_{A, i} + h_{A, i}) + r_i(p_{B, j} + h_{B, j})
      =  c_{ij} . x_{A, i} + c'_{ij} . x_{B, j}
         + beta_{ij}(h_{A, i} + h_{B, j})
         + gamma_{ij} q

for suitable coefficients (c, c', beta, gamma) depending on the
dual vector and the edge.

Proof.  Finite-dimensional duality: the linear constraint map on
direct-sum_{i, j} V_{ij} has dual equal to relations of this
form.  A nonzero obstruction means a nonzero dual vector; the
"projection surjective" part rules out degenerate cases where
all four equations have s_j = r_i = 0.  []

24.4  Structure of status arrays.

For the orientation pair Z with J(Z) = 1, define the status
classes (per side):

    alpha_i  in F_2      (the prediction constant),
    e_i                  (the prediction class),

for i in {1, 2}.  These come from Lemma 21.1's prediction
structure (if applicable) or are "empty" (unpredicted).

Status classifications:

   (EMPTY)   e_1 = e_2 = 0,    alpha_1 = alpha_2 = 1
             (the "trivial" prediction where nothing is
             predicted beyond "well-signed").

   (SINGLE)  exactly one of e_1, e_2 is nonzero.

   (DOUBLE-HOMOGENEOUS)  e_1 = e_2 != 0, and alpha_1 = alpha_2.

   (DOUBLE-HETEROGENEOUS)  e_1, e_2 != 0 and different.

Each case has an associated "compatibility" condition on
role bits (see below).

24.5  Preventing the empty-status obstruction.

Lemma 24.3 (empty status excluded, lem:empty-status).

Under the no-prediction alternative of the preceding preparation
and with empty status (EMPTY), the scalar system on every edge
has a solution.  Consequently no obstruction arises.

The full proof uses the fact that empty status implies p_i = T
(lambda_i, x) + alpha_i h_i exactly on every retained unit, and
that the projection onto B_{ij} is surjective.  []

24.6  Extracting a global prediction.

The key lemma for the "predicted" alternatives:

Lemma 24.4 (extraction of a global prediction, lem:status-global-prediction).

Suppose that (some status class is active, and) the cross-edge
arrays are OBSTRUCTABLE on a mass >= 0.1 (with witnesses of size
at most B_* per endpoint).  Then the obstruction yields a
"prediction" — a pair of global functions  f_A, f_B  on the
reference Xi_{l, q} such that, uniformly over surviving labels
and tags,

    p_{A, i}  =  T(lambda_{A, i}, atom)  +  alpha_{A, i} h_{A, i}
                  +  f_i(q, xi)    ( for the A-side),

    (same for the B-side).

Then substituting these into the cross-edge dual relations gives
the "prediction class" constraints

    s_j e_i = r_i e_j   (i, j in {1, 2}).

Sketch.  From the dual relation, extract the "p + T + alpha*
h" pattern.  The dual coefficients c_{ij}, c'_{ij}, beta_{ij}
are forced by comparing generic status arrays from the A-side
and B-side.

The equality s_j f_i + r_i f_j = gamma_{ij} q is what makes
the "offsets" determined by q (allowing us to quotient out).

The e_i, e_j relations are then the "class equations".

24.7  Preventing obstruction: contradiction with limit overlap.

Lemma 24.5 (obstruction implies positive overlap).

Suppose that, for a permitted pair Z with J(Z) = 1, the
arrivals at different status classes violate the constraint of
Lemma 24.4 — for example, a "prediction" is extracted from the
dual relations and requires a positive overlap that Proposition
23.4 forbids.  Then this contradicts Proposition 23.4.

Sketch.  The extracted prediction from Lemma 24.4 would force,
for every compatible orientation pair, a positive-overlap
integral.  But Proposition 23.4 says this integral is zero for
almost every permitted pair.  []

24.8  Non-obstruction.

Combining Lemmas 24.3, 24.4, 24.5:

Theorem 24.6 (no obstruction).

Under the hypotheses of distribution Tests 1 and 2, for almost
every permitted pair Z with J(Z) = 1 and every usable numerical
option, the scalar system on the cross edges is soluble (no
dual obstruction).

Sketch.  If the scalar system were obstructable on some
positive mass, Lemma 24.4 would produce a prediction satisfying
the class equations.  Case analysis:

  EMPTY   -> Lemma 24.3 excludes it.
  SINGLE  -> predicts the middle bit from offset.
  DOUBLE  -> predicts both bits from a single q hypothesis.

None of these produce positive overlap under Proposition 23.4.
So the scalar system must be soluble on positive-mass events.

[]

24.9  The successful-query solver.

The "successful-query solver" is the algorithm implied by Theorem
24.6: at a permitted pair Z with J(Z) = 1:

  (1)  Take the trivial (empty) option.
  (2)  Verify the scalar system is soluble.
  (3)  If yes: the query succeeds (hole condition satisfied).
  (4)  If not: an obstruction would exist by construction; by
       Theorem 24.6 this contradicts Proposition 23.4; so
       positive-mass non-solvability is impossible.

The solver's existence is what proves:

Theorem 24.7 (status-span success).

At almost every permitted pair Z with J(Z) = 1, there is a
"successful query" available:

    Pr( four cross holes | Z )  >=  p_0

for a positive-mass constant p_0 > 0 (explicitly
p_0 = 2^{-O(N)} from the peeling mass bound).

25.1  Setup.

We prove Distribution Test 2: a unit A = (A_1, A_2) against an
independent point z, both from (a restriction of) pi_n.  The goal
is to show that, on a positive fraction of the pairs, both (A_1, z)
and (A_2, z) are holes (i.e. z is non-adjacent to both endpoints).

The two "endpoint-side" hypotheses of Distribution Test 2 are:

    sigma_1 <= L * pi_n   (A_1 marginal bounded),
    sigma_2 <= L * pi_n   (A_2 marginal bounded),
    sigma   <= 2^{3000 g N} pi_n^2   (joint pair density),
    theta   <= L * pi_n   (point marginal bounded),

where sigma is the unit law and theta is the point law.

25.2  Independent points.

First, without using the specific unit law:

Lemma 25.1 (independent pairs are holes with high probability,
cor:independent-point-leaf).

Let B_1, B_2 be two independent samples from theta, both <= L * pi_n.
Then

    Pr( {B_1, B_2} is a hole )  <=  O_g( L^2 2^{2 dim B - N} )  =  o(1).

Proof.  The two primal spans in each component are independent,
except on a set of mass <= O_g(L^2 2^{2 dim B - N}) where they
happen to overlap.  On the complement, the "first hole equation"
forces both profiles to be zero, contradicting the "last hole
equation" (which requires them to be nonzero witnesses).  []

Consequence: after removing the exceptional set, the two points
have C_{B, 1} = C_{B, 2} = 0.  All full-frame image bounds
gain a factor eps_ch N; no "unchanged full-frame marginal" is
asserted.

25.3  No common prediction for the point side.

Consider the point side.  The point has NO unit structure (it is
a single frame).  Therefore it cannot make any "prediction"
about A_1 or A_2.  The following lemma formalizes this.

Lemma 25.2 (channel correlations on a common key,
lem:asym-channel-orthogonality).

Let v, w be two FRAMES (not units).  Suppose that for a
distinguished tag l, the concatenated channel columns
[X_{v, e}, X_{w, e}] and [Y_{v, e}, Y_{w, e}] have full rank 2h
in every component e of the star of l.

Then, uniformly in v, w, and q,

    (a)  E_{Omega_{l, q}}   chi_v  =  2^{-h(g-1)}  +  O_g(2^{-N+4h})
    (b)  E_{Omega_{l, q}}   chi_v chi_w  =  2^{-2h(g-1)}  +
                                            O_g(2^{-N+4h})

where chi_v, chi_w are the "channel-parity characters" of
Section 20.2.

For independent frames with law nu <= L * pi, the rank conditions
fail with probability o(1).

Proof.  Before imposing x . y = q in one component, the four
channel evaluation vectors

    (Y_v^T x,  Y_w^T x,  X_v^T y,  X_w^T y)

are uniform on F^{4h}.  Conditional on their values, x, y are
uniform on affine subspaces of codimension 2h; the pairing between
their translation spaces has rank at least N - 4h.  For a bilinear
form of rank R, its sign average on an affine product is either
zero or has absolute value 2^{-R}.  Thus each channel-evaluation
tuple has probability 1/2 + O(2^{-N+4h}).  Conditioning on the
diagonal changes the uniform law by O(2^{-N+4h}) in total
variation.  []

25.4  The case where the A-side has no prediction.

Assume A-side has empty-prediction (Lemma 21.1 no-prediction
alternative).  Then the pin-injection lemma (Lemma 21.2) applies
uniformly, and there is a positive probability that a "consistent
actual table" relating A_1 and A_2 exists at every tag.

Moreover, the point z has primal density bounded by L * pi_n.
So z's primal directions "reach" A_1's and A_2's primal spaces
with probability bounded below.

Lemma 25.3 (empty-prediction success).

Under the empty-prediction alternative on the A-side, the
probability of a two-hole relation A ~ z is at least

    2^{-100 g N}

for all sufficiently large n.

Proof sketch.  The chain:

  1.  The A-side has a pin-injection success with probability
      at least 1/128 (from Lemma 21.2).
  2.  Given A's setup, the point z has primal directions
      bounded by L * pi_n.  By the frame image bounds
      (Lemma 20.6), the probability that z's primal directions
      lie in the "accepting coset" is at least 2^{-100 g N - O(1)}
      (from the parameter ledger).

Combining (1) and (2) via Fubini gives the result.  []

empty-prediction cannot have a dual relation obstruction.  The

Given this, the two holes (A_1, z) and (A_2, z) require only

2^{-100 g N}.

Proof.  Substitute the empty-status formula for p into the

We collect all parameters in one place and fix their

A.1  Acyclic dependency order.

   (1)  g >= 3 odd                 number of tags.

   (22) b = b(g)                    selector length: B_* < 2^{b-2j_*}.

The horizontal ordering is strictly acyclic.  Every later

A.2  The critical inequalities.

Inequality  A.1 (graph vs counterexample).
   c_*(g)  and  a(g)  are chosen so that the number of matching
   edges absorbed by the colour-exceptional set is at most m/100.
   Explicitly:
       (4 / eta_col) * 2 a m  <  m/100.
   This holds by eta_col < 4 a / (200) = a/50.

Inequality  A.2 (peeling vs status).
   zeta * (N/2) >> 1.  Since N = M_0 n and n >= 2 r_0 is
   macroscopic, this holds for large n.

Inequality  A.3 (channel rank vs combinatorial reach).

Inequality  A.4 (mixer spread vs Walsh estimate).

   k_max = 2K_1.

A.4  Proof of existence.

All parameters exist with the listed properties by the
following trivial observation: the dependency graph is acyclic,
and at each step we only need to choose a parameter sufficiently
small (delta_*, c_*, a_g, eta_col) or sufficiently large (D, M,
K_1, r, L_0, p_0, delta_*, R_*, j_*, b, A, J, r_0, h, M_0).
These are all "free choices" - the governing inequalities are
strict and can be achieved one at a time.

We do not spell out every inequality or every slack; the
existence of the parameters is immediate.

A.5  End of construction.

Take g large enough that c_*(g) > 100 (for the exponent constant
of Proposition 23.4).  Then take all other parameters in the
listed order.  Take N = M_0 n with n growing.  Then:

   - Part 2 (Theorem 4.2) gives a well-signed matrix of rank
     exceeding ms/2 + 1 for every s large enough, on the graph
     H[K_s] where H satisfies the three conflict properties.
   - Part 3-4 (Theorem 4.1) gives H of order m on n growing,
     satisfying (G1)-(G3) with the correct parameters.
   - Therefore Theorem 4.2 applies.

The error margins in the proof are all "positive-slack": each
approximation lemma gives an inequality that is strict with
slack, and the slack is only reduced by finitely many "constant
factor" or "O(1/N)" or "O(2^{-zeta N})"-type errors.  For M_0
large enough (fixed, not n-dependent) with N = M_0 n tending
to infinity, every strict inequality holds with room to spare.

Hence the main theorem holds: for arbitrarily large m, there
is a finite graph G on m s vertices with alpha(G) <= 2,
mu(G) + 1 < ms/2 <= chi(G).  The counterexample is complete.

APPENDIX B.  MEASURE CONSTRUCTIONS
================================================================

We record the standard compactness facts used in Sections 23.

B.1  Weak subsequential compactness.

Lemma B.1.  Let (Omega_n, F_n, nu_n)_n be any sequence of
probability spaces, each equipped with a finite collection of
"observable" real-valued functions of bound one.  Suppose the
"observable expectations" all admit limits along some
subsequence.  Then there is a compact metric space (X, m) with
a Borel probability measure m, and a sequence of measurable maps
pi_n : Omega_n -> X, such that:

   (i)  the pushforwards (pi_n)_* nu_n converge weakly to m;
   (ii) every bounded observable f_n on Omega_n is
        approximated by a pullback pi_n^* f from a fixed family
        of continuous functions on X.

Sketch.  Construct X as the product space of all bit sequences
on a countable family of "test sets", topologised as a compact
product of two-point spaces.  Define m as the unique Borel
measure consistent with cylinder limits.  The maps pi_n are the
bit-sequence observers.  Weak convergence is immediate from the
cylinder limits.  []

B.2  Densities of dominated cylinder measures.

Lemma B.2 (densities, lem:cylinder-densities).

Let X be a compact bit-sequence space with Borel probability m,
let theta have a probability law on a parameter space Theta,
and suppose for each theta there is a measure nu_theta satisfying
0 <= nu_theta <= m.  Then there is a jointly measurable function
h(theta, x) in [0, 1] such that, for almost every theta,

    nu_theta(A)  =  int_A  h(theta, x)  dm(x)

for every Borel A.

Proof.  Take the partition P_k of X by the first k bits.  Define

    h_k(theta, x)  :=  nu_theta(C_k(x)) / m(C_k(x))   on each
                                                       cell of P_k,

with value 0 where m(C_k(x)) = 0.  Each h_k is jointly measurable,
in [0, 1].  The differences h_{k+1} - h_k have zero average over
each parent cell, hence are orthogonal in L^2(dtheta x dm).  Their
L^2 squared norms are bounded by 1, so (h_k) is Cauchy in L^2.
Taking a further subsequence, h_k converges a.e. to a joint
measurable h.  (Joint measurability follows by the standard
argument from Borel sections.)  []

B.3  Use in Section 23.

Lemma B.2 is used to construct the "h^theta_{t, upsilon}"
densities in Section 23.3: each parameter value theta specifies
a "conditional successful query measure" nu_theta on the
reference space, and the density h^theta is the Radon-Nikodym
derivative with respect to the reference measure m_{l, q}.
The compatibility identities (sum_upsilon h^theta_{t, upsilon} = 1)
follow from the normalization of the corresponding unary
frequencies and are stable under the compactness limit.

B.4  Interpolation and nonnegative functions.

Lemma B.3.  Let (X_j) be a countable family of compact
bit-sequence spaces, m_j a compatible net of measures on each.
Let f: X_1 x X_2 -> R be a bounded measurable function that
depends on each coordinate only measurably.  Then f is jointly
m_1 x m_2-measurable.

Sketch.  Standard: f is f_X1(x_1, x_2) with x_j in a compact
space; use monotone class / cylinder approximation.  []

B.5  Consequence.

The measures m_{l, q} of Section 23 are well-defined and satisfy
all the compatibility identities used to identify the limiting
"successful-query densities".  This closes the last gap in the
compactness part of Part 4.
