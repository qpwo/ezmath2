Fix a finite loopless undirected multigraph G = (V,E) with an even number
of vertices |V| = 2m and at least one perfect matching. Parallel edges are
distinct labels and distinct coordinates in R^E. A perfect matching is a
set of edges covering every vertex exactly once. Write M(G) for the
matching family, N(G) = |M(G)| for its size, and form the matching
polytope

    P(G) = conv{ 1_M : M in M(G) }  in R^E,

with 1_M the incidence vector of M. The points of P(G) are exactly the
feasible vectors of edge probabilities x_e.

For a probability law p on M(G) put Ent(p) = -sum_M p_M log p_M, with
0 log 0 = 0, and take natural logarithms throughout. The largest entropy
at a prescribed mean is

    H(x) = max{ Ent(p) : p a law on M(G), sum_M p_M 1_M = x }.

The feasible set of laws is a compact polytope, so the maximum is
attained. Two one-coordinate sums accompany H:

    F(x) = -sum_e x_e log x_e,   B(x) = -sum_e (1 - x_e) log(1 - x_e).

Fix x in P(G). Prescribing the probability x_e of each edge does not fix
the law, and H(x) measures how many matching choices coexist with those
probabilities. The central claim compares H with the separable sums F and
B at every feasible mean.

Theorem 1. Let G be a loopless multigraph on 2m >= 2 vertices with at
least one perfect matching. Each x in P(G) satisfies

    F(x) - (2 - 2/m) B(x)  <=  H(x)  <=  F(x).

The two bounds have different characters. The upper bound H <= F is the
vertex-star instance of Shearer's entropy inequality: every edge lies in
exactly two vertex stars, a matching chooses exactly one edge at each
vertex, and conditioning only lowers entropy. The lower comparison
F - (2 - 2/m) B <= H is the substance; its coefficient results from a
sharp face-dimension estimate followed by a covariance computation, and
no interiority of x within P(G) is assumed.

The terminal cases are exact. When m = 1 the vertex set has two elements,
the matching family is the simplex on the distinguished parallel edges,
the coefficient 2 - 2/m equals 1, and both bounds collapse to H = F. The
empty vertex set has the empty matching, and F = B = H = 0 without the
coefficient formula. The upper inequality is due to Chung, Graham, Frankl
and Shearer, whose work on intersection and shadow problems contains the
star decomposition that the entropy argument uses.

pdf: ./chung-graham-frankl-shearer-1986-intersection-theorems.pdf

The polytope P(G) is governed by Edmonds' matching-polytope theorem: a
point of R^E lies in P(G) exactly when it is nonnegative, has unit sum on
the edge set of each vertex, and has sum at least one on the edge set
crossing each odd vertex set. These odd-cut inequalities separate general
graphs from bipartite ones. On the bipartite side the coefficient-one
comparison H >= F - B holds by entirely different means: Schrijver's
permanent inequality for regular bipartite graphs, in the Bethe-entropy
form used by Gurvits, gives it through entropy duality. The bipartite
setting is essential there. An eight-vertex nonbipartite graph has a
feasible mean at which H < F - B.

pdf: ./edmonds-1965-maximum-matching-polyhedron.pdf
pdf: ./schrijver-1998-counting-one-factors-regular-bipartite.pdf
pdf: ./gurvits-2011-schrijver-permanental-inequality-bethe.pdf

Theorem 1 answers a question of Anari, Oveis Gharan and Vinzant on a
convex-optimization route to approximate counting. In the present notation
their objective at a mean x is the binary-coordinate entropy F(x) + B(x),
and the question was whether its maximum over P(G) exceeds log N(G) by only a
linear function of the number of vertices. Maximization over x gives

    log N(G) <= max_{x in P(G)} ( F(x) + B(x) ) <= log N(G) + 3m - 2,

so the prescribed-mean inequality produces the linear-error estimate as
an optimized consequence rather than a definition. The same pointwise
bound controls arbitrary finite edge weights through the Gibbs variational
formula, and the weighted form together with the counting corollaries
follow from it.

The upper bound also has a matching-star interpretation independent of
weighted counting. It is convenient to record a short chain-rule proof
that makes the role of labelled parallel edges explicit.

Lemma 1 (upper bound). For every x in P(G), H(x) <= F(x).

Proof. Let X = (X_e) be the incidence vector of a matching law of mean x,
and order E. For a vertex v, the chain rule over the star delta(v) gives

    Ent(X_{delta(v)}) = sum_{e in delta(v)} Ent(X_e | X_f, f < e)
                      >= sum_{e in delta(v)} Ent(X_e | X_f, f < e, f not in delta(v))
                       = sum_{e in delta(v)} Ent(X_e | X_f : f < e),

because conditioning on additional finite variables lowers conditional
entropy. Every edge, parallel labels included, belongs to exactly two
vertex stars, so summing over v and applying the chain rule gives
sum_v Ent(X_{delta(v)}) >= 2 Ent(X). At a vertex the star vector makes
exactly one choice with probabilities (x_e), hence

    sum_v Ent(X_{delta(v)}) = sum_v [ -sum_{e in delta(v)} x_e log x_e ]
                            = 2 F(x).

Thus Ent(X) <= F(x). Taking the maximum over laws of mean x proves the
claim, including fixed coordinates and disconnected graphs.

The lower bound needs the geometry of the face of P(G) that carries x.
For a subset S of V let delta(S) be the set of edges with exactly one end
in S, write delta(v) for delta({v}), and set chi_S = 1_{delta(S)}. A cut
delta(S) is called tight at x when x(delta(S)) = 1, that is, when the
corresponding odd-cut inequality holds with equality.

For an odd set S with nonempty complement, contract the complement of S
to a new vertex, keeping S and discarding edges internal to the
complement, and call the result G_1. Contract S instead to obtain G_2.
Every edge of C = delta(S) keeps its label in both graphs, parallel edges
stay distinct, and a cut is nontrivial when both sides have at least
three vertices, in which case the contracted graphs have smaller even
order.

Lemma 2 (gluing across an odd cut). Suppose y_i in P(G_i) for i = 1,2 and
the two vectors agree on C. Then there is y in P(G) whose internal
coordinates are those of y_1 and y_2 and whose crossing coordinates are
the common values.

Proof. Choose a matching law of mean y_i in each contracted graph. A
matching uses exactly one edge at the contracted vertex, so the common
crossing coordinates q_e = (y_1)_e = (y_2)_e sum to one. Draw a label e
with probabilities q_e, then draw the two matchings independently from
their laws conditioned on using e; a label with q_e = 0 is never chosen.
Erase the contracted vertices and splice the two copies of the chosen
crossing edge into its original edge. The internal matchings together
with this edge cover every original vertex once. The crossing marginals
are q_e, and the law of total probability preserves each internal
marginal, so the resulting matching law has mean y.

Edmonds' theorem is the organising description. The multigraph form,
with labels carried through contractions, is used directly by the
dimension count.

Theorem 2 (perfect-matching polytope). For every such graph G,

    P(G) = { x in R^E : x_e >= 0 (e in E),
                        x(delta(v)) = 1 (v in V),
                        x(delta(S)) >= 1 (S subset V, |S| odd) }.

pdf: ./edmonds-1965-maximum-matching-polyhedron.pdf

Proof. Let Q be the set on the right. Every perfect matching has unit
degrees and crosses every odd cut, so P(G) is contained in Q. The degree
equation at either end of an edge forces 0 <= x_e <= 1 on Q, so Q is
bounded; when Q is empty the inclusion is trivial.

A nonempty bounded polytope is the convex hull of its extreme points:
unless a point is extreme there is a nonzero direction annihilating every
active row, the feasible interval in that direction has two endpoints,
the point is their convex combination, and each endpoint acquires a new
independent active row, so iteration inside faces terminates. It remains
to show extreme points of Q are matching vectors, by induction on the even
order.

The order-zero case is immediate. At order two, Q is the simplex
{ x >= 0 : sum_{e} x_e = 1 } on the distinguished parallel edges, exactly
their matching polytope, and is empty without an edge.

Take |V| >= 4 and an extreme point x of Q. If some odd set S with
3 <= |S| <= |V| - 3 has x(delta(S)) = 1, form the contracted graphs G_1,
G_2 and the restrictions x_i. Both have smaller even order. Degree
equations at retained vertices are unchanged and the degree sum at the new
vertex is x(C) = 1. To test an odd-cut inequality in a contracted graph,
complement its side if necessary so that the new vertex is excluded; the
complement is still odd, since the order is even, and its cut has the same
labels and sum as a cut of original vertices. Hence x_i lies in P(G_i) by
induction, and Lemma 2 assembles x in P(G).

Otherwise every nontrivial odd cut is slack at x. A nonzero vector
supported on the positive coordinates of x and preserving all degree
equations then admits small feasible perturbations of both signs, since
positive coordinates stay positive and the finitely many nontrivial odd
cuts keep positive slack. So the columns of the unsigned vertex-edge
incidence matrix on the positive edges are linearly independent. Each
connected component of the positive-edge graph has no isolated vertex.
A vertex of positive degree one forces its edge to value one and appears
in an isolated weight-one edge component. Every remaining component has
minimum degree at least two and at most as many edges as vertices by
independent columns, so it is a cycle, possibly a two-edge parallel
cycle. An even cycle gives a signed dependence among incidence columns,
and an odd cycle component has cut sum zero on its odd vertex set, against
feasibility. Only isolated weight-one edges remain, and x is a matching
vector. The induction is complete.

The minimal face and its direction space govern the dimension count. For
x in P(G) define the two-sided tangent cone

    T(x) = { h in R^E : x + t h in P(G) for all small |t| ],

and let F_x be the face of P(G) obtained by keeping equality in every
inequality of Theorem 2 that is tight at x. Let A_x be the set of
matching vectors a(M) = 1_M that lie in F_x.

Lemma 3 (minimal face and its directions). For every x in P(G), the set
T(x) is the linear space cut out by

    h_e = 0  if x_e = 0,
    h(delta(v)) = 0  (v in V),
    h(delta(S)) = 0  if |S| is odd and x(delta(S)) = 1.

Moreover F_x is the minimal face containing x, and

    aff F_x = x + T(x),   F_x = conv A_x,   T(x) = span{ a - x : a in A_x }.

The point x is relative interior to F_x, and every law of mean x is
supported on A_x.

Proof. Feasibility of both signs forces every active row to annihilate the
direction, and the listed equations preserve all active rows while the
finitely many inactive rows keep positive slack for small perturbations,
so these describe T(x). For each inactive row pick a radius below half its
slack divided by the row norm and take the least; the ball of that radius
inside x + T(x) stays in F_x, which proves the affine hull and relative
interiority. For y in F_x, a short segment extended from y through x stays
in that neighborhood, so x is relative interior to a segment ending at y
and every face containing x contains y, giving minimality. Expressing a
point of F_x as a convex combination of matching vectors, each defining
inequality has nonnegative slack and zero average slack, so every atom of
positive weight lies in F_x; this gives the convex-hull and spanning
statements.

Write d(x) = dim F_x = dim T(x). When every coordinate of x is positive
there are no active nonnegativity constraints and the degree rows are the
singleton cuts, so Lemma 3 gives the exact rank identity

    |E| - d(x) = dim span{ chi_S : |S| odd, x(delta(S)) = 1 }.

The right side is the rank of the tight odd-cut rows, and a sharp bound
follows.

Proposition 1 (codimension on positive coordinates). Let |V| = 2m >= 2
and suppose x in P(G) has x_e > 0 on every edge. Then |E| - d(x) <= 3m - 2.

Proof. Induct on the even order n = 2m. At order two the polytope is the
simplex on distinguished parallel edges and a positive point has dimension
|E| - 1, giving codimension one. For n >= 4, if no nontrivial odd cut is
tight then by Lemma 3 only the n degree rows restrict T(x) and
|E| - d(x) <= n <= 3n/2 - 2. Otherwise choose a tight nontrivial cut
C = delta(S) and let x_i be the restrictions to the contracted graphs G_i
of Theorem 2; each is feasible with positive retained coordinates. Put
n_i = |V(G_i)|, s_i = |E(G_i)|, d_i = dim T(x_i). Each crossing label
appears in both graphs and each internal label in one, so

    n_1 + n_2 = n + 2,   s_1 + s_2 = |E| + |C|,   4 <= n_i < n.

Let W be the space of pairs (h_1,h_2) in T(x_1) + T(x_2) with equal
crossing coordinates. Each h_i preserves the degree of the contracted
vertex, so sum_{e in C} (h_i)_e = 0; the map to h_1|_C - h_2|_C therefore
lands in { z : sum_{e in C} z_e = 0 }, a space of dimension |C| - 1, and
its kernel is W, giving dim W >= d_1 + d_2 - |C| + 1. Mapping
(h_1,h_2) to the vector with the internal coordinates and the common
crossing coordinates is injective, and Lemma 2 makes each such vector a
valid parent direction, since both signs are feasible and crossing
coordinates agree for all t. Hence d(x) >= dim W, and with the order and
size relations and the induction hypothesis,

    |E| - d(x) <= (s_1 - d_1) + (s_2 - d_2) - 1
               <= (3 n_1 / 2 - 2) + (3 n_2 / 2 - 2) - 1
                = 3 n / 2 - 2.

The single saved compatibility condition is what closes the recurrence.

Deleting the zero-coordinate edges of an arbitrary mean keeps the vertex
set and identifies the supported minimal face with the minimal face in
the positive-edge graph, because every law of that mean omits those edges
and restriction, zero extension are inverse on the face. Hence the
supported form holds,

    |supp x| - d(x) <= 3m - 2,

for every x in P(G) on 2m >= 2 vertices. A final reduction removes the
coordinates equal to one.

Lemma 4 (fractional coordinates). Let x in P(G) and let
E_f = { e : 0 < x_e < 1 } be its fractional edges, V_f the set of vertices
meeting E_f, and write |V_f| = 2 m_f. With G_f = (V_f, E_f) and bar x the
restriction of x to E_f, the coordinate extension fixing the remaining
coordinates identifies P(G_f) with the face of P(G) on which those
coordinates equal their values on x; it carries the minimal face at bar x
to F_x, and for every z in P(G_f) the laws of mean z on G_f correspond
bijectively to the laws of the extended mean on G. Consequently
sum_{e in E_f} x_e = m_f, and for m_f >= 1,

    d(x) >= |E_f| - 3 m_f + 2.

If m_f = 0 then x is a matching vector and d(x) = 0.

Proof. An edge of coordinate one exhausts the degree sum at both ends, so
no fractional edge meets its endpoints; at a vertex outside V_f all
incident coordinates are zero or one and sum to one, so exactly one is
one. The fixed edges therefore form a perfect matching of the complement
of V_f, and |V_f| is even. Every law of mean x uses each value-one edge
and omits each value-zero edge with probability one, so deleting the fixed
edges gives a matching law of mean bar x on G_f and bar x lies in P(G_f);
adjoining the fixed edges reverses this. The coordinates being zero or one
define faces whose intersection Q_x is a face containing x, and the same
matching extension identifies Q_x with the image of P(G_f), with the
asserted bijection of laws. An affine isomorphism preserves faces and
relative interiors, and the minimal face at x is sent to the minimal face
at bar x, so the dimensions agree; the direction statement also follows
directly by vanishing on fixed coordinates. When m_f >= 1 all coordinates
of bar x are positive and Proposition 1 gives d(x) >= |E_f| - 3 m_f + 2.
When m_f = 0 all coordinates are integral and the degree equations identify
a single matching vector. Finally, at each vertex of V_f the fractional
incident coordinates sum to one, and summing these degree equations counts
each fractional edge twice, giving sum_{e in E_f} x_e = m_f.

The lower bound turns the codimension estimate into an entropy inequality.
The bridge is the maximum-entropy law at a prescribed mean, which is an
exponential family on the minimal face, and a second-derivative test along
its smooth reparameterizations. A comparison of entropies underlies every
step.

Lemma 5 (entropy comparison). Let p and q be probability laws on a finite
set with q_a > 0 wherever p_a > 0. Then

    Ent(p) <= -sum_{a : p_a > 0} p_a log q_a,

with equality exactly when p = q.

Proof. The bound log t <= t - 1 gives
sum_{p_a>0} p_a log(q_a / p_a) <= sum_{p_a>0} q_a - 1 <= 0, which is the
statement, and the equality condition is the equality case of log t <= t-1.

Taking q uniform in Lemma 5 gives Ent(p) <= log N for a law on N atoms.

Lemma 6 (continuity at the boundary). For a nonempty matching polytope
P(G), the function H is attained, nonnegative, concave, and continuous on
the whole polytope.

Proof. The laws of a prescribed mean form a nonempty closed subset of the
finite probability simplex, so compactness and continuity of entropy give
attainment. Mixing two maximizing laws of the same mean keeps the mean and
concavity of entropy gives concavity of H; entropy is nonnegative.

For upper semicontinuity at x, take y_j -> x with maximizing laws, pass to
a subsequence realizing the upper limit of the entropies, then to a
convergent subsequence of laws; the limit has mean x and continuity of
entropy on the simplex gives limsup H(y_j) <= H(x). For lower
semicontinuity, take y near x in P(G), put t = sqrt(||y - x||) and
z = x + (y - x)/t. For y close enough, 0 < t < 1 and z lies in P(G):
equalities hold, a row tight at x keeps its slack divided by t at z, and
the finitely many inactive rows stay satisfied as z approaches x. Since
y = (1 - t) x + t z, concavity and nonnegativity give
H(y) >= (1 - t) H(x), and y -> x gives the reverse semicontinuity.

Let A be the set of matching incidence vectors and A_x those lying in the
minimal face F_x. A finite maximum-entropy
principle holds on that face; it is the discrete form of the
maximum-entropy duality of Jaynes and, in the algorithmic encoding,
of Singh and Vishnoi.
The covariance identities are those of exponential families, as collected
by Wainwright and Jordan.

Lemma 7 (exponential laws on the minimal face). Every law of mean x is
supported on A_x. Its entropy maximizer p is positive on every atom of A_x
and has the form p_a = exp(theta . a) / sum_{b in A_x} exp(theta . b) for
some theta in R^E. For every eta in R^E, replacing theta by eta maximizes
entropy at its own mean, and that mean has minimal face F_x.

Proof. Each active inequality of F_x has nonnegative slack at every
matching vector, and its expected slack at x is zero, so every atom of
positive probability lies in F_x; Lemma 3 also gives F_x = conv A_x with x
relative interior. Let b be the barycenter of A_x. For small positive
epsilon the point (x - epsilon b)/(1 - epsilon) is relative interior to
F_x, and representing it by a law on A_x and mixing in weight epsilon of
the uniform law produces a law q of mean x positive on every atom of A_x.
If a maximizer p vanished on a nonempty set Z of atoms, then
Ent((1-u) p + u q) - Ent(p) = u log(1/u) sum_{a in Z} q_a + O(u) > 0 for
small u, because the terms with p_a > 0 are differentiable; so p is
positive. The matrix with columns (1, a) indexed by a in A_x has, in its
kernel, all small perturbations of p preserving mass and mean, so the
entropy gradient (-1 - log p_a) lies in the row space; the constant row is
present, so log p_a = c + theta . a and normalization gives the displayed
form. For a law of that form with parameter eta, every atom of A_x has
positive probability, and an inequality is tight at its mean exactly when
it is tight at every atom, hence exactly when it is tight at x; so the
minimal face is F_x and every competing law of the mean is supported on
A_x. Lemma 5 then gives Ent(q') <= log sum_{a in A_x} exp(eta . a) - eta . y
with equality for the exponential law, proving maximality.

The analytic step fixes a real c and writes J_c = F - c B. A lemma
records the consequence of a maximum of J_c - H on the strictly
fractional part; the coefficient c is not yet specialized.

Lemma 8 (second variation at a fractional maximum). Let G have 2m >= 2
vertices and suppose x in P(G) has 0 < x_e < 1 on every edge. If J_c - H has
a local maximum at x, then with d = dim F_x and s = |E|,

    0 >= d - s + (c + 1) m.

Proof. Let p and theta come from Lemma 7, and write T = T(x). For v in R^E
and real t set Phi(t) = log sum_{a in A_x} exp((theta + t v) . a),
p_a(t) = exp((theta + t v) . a - Phi(t)), y(t) = sum_a p_a(t) a. Lemma 7
gives F_{y(t)} = F_x and H(y(t)) = Phi(t) - (theta + t v) . y(t). All sums
are finite, so the curves are smooth, and every coordinate of y(t) stays
strictly between zero and one because both bit values occur among the
positive-probability atoms. Define the covariance

    K = sum_{a in A_x} p_a (a - x)(a - x)^transpose.

Differentiation gives p_a'(0) = p_a v . (a - x) and y'(0) = K v. Since
w^T K w = sum_a p_a (w . (a - x))^2 and the vectors a - x span T, while p
is positive, the range, kernel and rank are

    ker K = T^perp,   im K = T,   rank K = d.

Also y''(0) lies in T because the curve stays in x + T. Let g = grad J_c(x)
and let D be the diagonal Hessian with
g_e = -log x_e - c log(1 - x_e) - (c + 1) and D_ee = -1/x_e + c/(1 - x_e).
Since Phi'(t) = v . y(t), the entropy derivative is
dH/dt = -(theta + t v) . y'(t). For r(t) = J_c(y(t)) - H(y(t)) the first
two derivatives at zero are

    r'(0) = (g + theta) . K v,
    r''(0) = (K v)^T D (K v) + v^T K v + (g + theta) . y''(0).

Stationarity gives r'(0) = 0 for every v. Since im K = T and y''(0) in T,
the last term of r'' vanishes, and the second-derivative test is

    0 >= (K v)^T D (K v) + v^T K v,   all v in R^E.

This cancellation is why differentiating inside the minimal face suffices;
smoothness of H across faces is never invoked. Take orthonormal
eigenvectors u_1,...,u_d of K with positive eigenvalues lambda_i.
Substituting v = u_i, dividing by lambda_i, and summing gives

    0 >= d + sum_i lambda_i u_i^T D u_i = d + tr(K D).

Only the spectral decomposition of K is used; K and D need not commute,
and the case d = 0 is the empty sum. Each coordinate is Boolean, so
K_ee = x_e(1 - x_e), and with sum_e x_e = m,

    tr(K D) = sum_e [ -(1 - x_e) + c x_e ] = -s + (c + 1) m.

This proves the obstruction.

Proof of the lower bound in Theorem 1. Write the original vertex count as
2M >= 2 and fix c = 2 - 2/M + eps with eps > 0. By Lemma 6 the function
J_c - H attains a maximum on P(G). Suppose the maximum is positive, at x,
and delete the zero edges and the endpoints of the value-one edges. Lemma 4
identifies all laws of mean x with the laws of the reduced mean, preserving
F, B, H; an empty reduction would give F = B = H = 0, against positivity.
The reduced graph has 2m vertices for some 1 <= m <= M, and all retained
coordinates are strictly fractional. Every feasible reduced mean extends
by the fixed matching edges to a feasible original mean with the same F, B,
H, so the reduced mean is again a global maximum of J_c - H. The rank bound
of Lemma 4 gives d >= s - 3m + 2, while Lemma 8 gives

    0 >= d - s + (c + 1) m >= 2 + (c - 2) m = 2(1 - m/M) + eps m > 0,

since m <= M. This contradiction proves H >= F - c B for every eps > 0.
For each fixed mean B is finite, so eps -> 0 gives H >= F - (2 - 2/M) B. The
strict coefficient followed by this limit is essential: the geometric
comparison can be an equality when m = M and eps = 0.

A componentwise refinement follows from the exact reduction. Remove the
zero edges and the endpoints of the value-one edges of x, let the nonempty
connected components of the remaining graph have 2 m_i vertices, and let
B_i be the sum defining B on component i. Then

    F(x) - sum_i (2 - 2/m_i) B_i(x) <= H(x) <= F(x),

and F = B = H = 0 when no component remains. Indeed, the exact reduction
preserves the functions, every residual component has a perfect matching
and hence even positive order, a law of a whole matching induces laws on
the components whose entropies sum to at least the joint entropy, and the
independent product of component maximizing laws realizes the prescribed
mean with the sum of the entropies. So H, like F and B, is additive at
these fixed component means, and Theorem 1 applies to each component.

From now on G is a finite loopless multigraph on 2m > 0 vertices with at
least one perfect matching, N = N(G), P = P(G), and the logarithms are
natural. The elementary inequality 0 <= -(1 - u) log(1 - u) <= u on the
unit interval, proved by differentiating u + (1 - u) log(1 - u), gives
0 <= B(x) <= m, since sum_e x_e = m for every x in P.

Corollary 1 (entropy-dependent defect). For every x in P,

    0 <= F(x) - H(x) <= min{ F(x), 2m - 2 }.

Proof. The first inequality is H <= F. Nonnegativity of entropy gives the
first term of the minimum, while Theorem 1 and B <= m give
F - H <= (2 - 2/m) B <= 2m - 2. The case m = 1 has zero defect.

The binary-coordinate entropy is
H_bin(x) = sum_e [ -x_e log x_e - (1 - x_e) log(1 - x_e) ] = F(x) + B(x);
the name refers to the two values of an edge indicator.

Corollary 2 (separable estimates of the matching count).

    log N <= max_{x in P} F(x) <= log N + 2m - 2,
    log N <= max_{x in P} H_bin(x) <= log N + 3m - 2.

Proof. Lemma 5 applied to the uniform law gives entropy at most log N for
any law on N outcomes, with equality for the uniform law. At the mean xbar
of the uniform matching law, H(xbar) = log N, and Theorem 1 gives
log N <= F(xbar) <= H_bin(xbar), proving the two lower estimates.
Corollary 1 gives F(x) <= H(x) + 2m - 2 <= log N + 2m - 2 at every x.
Also H_bin(x) - H(x) <= (3 - 2/m) B(x) <= 3m - 2. Taking maxima proves the
upper estimates, which exist because P is compact and the functions are
continuous.

The same inequality evaluated at feasible uniform means gives lower counts
from structural hypotheses. When G contains k >= 2 pairwise edge-disjoint
perfect matchings, their uniform mixture has mean 1/k on their union of
km labelled edges and zero elsewhere.

Theorem 3 (many edge-disjoint perfect matchings). Let G contain k >= 1
pairwise edge-disjoint perfect matchings. If k = 1 then N >= 1, and if
k >= 2 then

    N >= k^m (1 - 1/k)^{2(m-1)(k-1)} >= e^{-2(m-1)} k^m >= (e^{-2} k)^m.

Proof. Let M_1,...,M_k be the selected matchings and take their uniform
mixture, of mean x = (1/k) sum_i 1_{M_i} in P. The hypotheses need not
exhaust the edges of G, only the selected union. Then F(x) = m log k, and
for k >= 2 direct evaluation gives B(x) = -m (k-1) log(1 - 1/k). Since
H(x) <= log N, Theorem 1 gives

    log N >= m log k + 2(m-1)(k-1) log(1 - 1/k),

and exponentiation gives the first inequality. The function
log(1 - u) + u/(1 - u) starts at zero and has derivative u/(1 - u)^2 >= 0,
so (k - 1) log(1 - 1/k) >= -1, giving the second inequality; the third uses
m - 1 <= m. At k = 1 the selected matching already gives N >= 1.

Only feasibility of the uniform mean enters the proof, so it applies to a
class that need not partition its edges.

Corollary 3 (regular graphs with large odd cuts). Let G be a finite
loopless k-regular multigraph on 2m > 0 vertices, k >= 1, and suppose
|delta(S)| >= k for every odd vertex set S. Then the conclusions of
Theorem 3 hold. In particular these hold for every (k - 1)-edge-connected
k-regular graph of positive even order.

Proof. The vector x_e = 1/k has unit degree sums, and the cut hypothesis
gives x(delta(S)) >= 1 for every odd S, so Theorem 2 places x in P(G); in
particular G has a perfect matching. Since |E| = km, the evaluations of F
and B apply unchanged when k >= 2, and k = 1 makes G itself a matching.
For the last assertion, an odd S is nonempty and proper, edge connectivity
gives |delta(S)| >= k - 1, and summing degrees in S gives
k|S| = 2|E(S)| + |delta(S)|, so |delta(S)| is congruent to k modulo two; it
cannot equal k - 1 and is at least k. Parallel edges count with multiplicity
in this identity.

The odd-cut hypothesis is a condition on the uniform vector, not on each
edge lying in some perfect matching. At small degree the base of
(e^{-2} k)^m is below one, so these estimates do not reproduce the
classical exponential lower bound for cubic graphs. On the bipartite side
Schrijver's bound has the stronger asymptotic base k/e per matched pair.

Weighted counting replaces natural-log entropy by binary-log weights, so
that the analytic estimate can drive an exact-arithmetic algorithm. For a
mean x in P put h_2(x) = F(x)/ln2 = sum_e -x_e log2 x_e, and for a real
vector beta in R^E put

    Z_beta = sum_{M in M(G)} 2^{beta . 1_M},   q* = max_{x in P} ( h_2(x) + beta . x ).

The maximum exists because P is compact.

Corollary 4 (weighted counting estimate). For every finite real beta,

    q* - (2m - 2)/ln2 <= log2 Z_beta <= q*.

Proof. The law p_beta(M) = 2^{beta . 1_M}/Z_beta is positive. For any
matching law p of mean x the nonnegativity of sum p log(p/p_beta), a
consequence of log t <= t - 1, gives

    ( -sum_M p log p )/ln2 + beta . x <= log2 Z_beta,

with equality for p_beta. Taking a maximizing law at each mean and then the
maximum over means gives the variational formula
log2 Z_beta = max_{x in P} ( H(x)/ln2 + beta . x ). Corollary 1 gives
F(x) - (2m - 2) <= H(x) <= F(x); dividing by ln2, adding beta . x, and
maximizing yields the bracket.

The analytic comparison does not itself produce a numerical optimizer.
The exact-arithmetic construction uses a coarser bracket with fixed
constants that leave room for rounding and optimization error. With n = 2m
and ln2 = integral_1^2 dt/t >= 1/2, one has (n - 2)/ln2 <= 2n - 4 <= 4n,
and enlarging the bracket gives

    q* - 4n <= log2 Z_beta <= q* + n

for every finite loopless labelled multigraph on an even n >= 2 vertices
with a perfect matching and every finite beta in R^E. For the empty graph
the matching family is the empty matching, Z_beta = 1 and q* = 0; that input
is handled directly.

From now on n >= 4 is even and the input is a vertex set V of size n
together with nonnegative integer multiplicities k_e in binary for the
unordered pairs e of distinct vertices, absent pairs having multiplicity
zero. The count N is the number of perfect matchings with parallel
choices distinguished. Work on the complete simple graph K_n with pair
set of size p = n(n - 1)/2, whose polytope P = P(K_n) is nonempty even when
the input has no matching. Small positive weights on absent pairs encode
the support in the objective, and the uniform vector u_{ij} = 1/(n - 1) has
unit degree sums and strict nontrivial odd-cut inequalities, a slack used
to repair violations.

Put b_max = max( {0} union { floor(log2 k_e) : k_e > 0 } ) and

    L = 100 (n + b_max + 1)^3,
    beta_e = floor(log2 k_e) if k_e > 0, and beta_e = -L if k_e = 0.

The exponent floor(log2 k_e) equals the binary bit length of k_e minus one,
so these coefficients are computed by integer arithmetic, with magnitudes
polynomial in n + b_max. Use Z_beta and q* for K_n with these weights. A
term of Z_beta is valid when its matching uses only pairs of positive
input multiplicity; write Z_good and Z_bad for the sums of valid and
remaining terms.

Lemma 9 (weighted completion). The contribution of matchings using an
absent pair satisfies 0 <= Z_bad <= 2^{-20n}. Moreover N = 0 implies
log2 Z_beta <= -20n, and N > 0 implies

    max{ 1, 2^{-n/2} N } <= Z_beta <= 2N.

Proof. For each pair with k_e > 0 put r_e = 2^{floor(log2 k_e)}, so
k_e/2 <= r_e <= k_e. For a valid matching of K_n the product of its k_e is
the number of corresponding matchings in the input, so replacing the n/2
factors by r_e and summing gives 2^{-n/2} N <= Z_good <= N. If N > 0 at
least one valid matching exists with positive integer rounded weight,
hence Z_good >= 1. A remaining matching uses a pair of weight 2^{-L} and
each other pair weight at most 2^{b_max}; there are at most 2^p matchings,
so Z_bad <= 2^{p + b_max n/2 - L} <= 2^{-20n}, because with t = n + b_max + 1
one has p + b_max n/2 + 20n <= t^2 + 20t <= 100 t^3 = L. When N = 0 every
term is bad, and Z_beta > 0 because K_n has a perfect matching and all
weights are positive, giving the first implication. When N > 0 the rounded
count gives the lower bounds and Z_beta <= N + 2^{-20n} <= 2N, since N is a
positive integer.

Entropy is replaced by an integer-slope dyadic interpolant. Let K be the
least nonnegative integer with 2^K >= p, let phi(t) = -t log2 t on [0,1]
with phi(0) = 0, and let psi be the continuous linear interpolant of phi at
0, 2^{-K}, 2^{-(K-1)}, ..., 2^{-1}, 1. Its chords are

    psi(t) = K t                         for 0 <= t <= 2^{-K},
    psi(t) = (k - 1) t + 2^{-k}          for 2^{-(k+1)} <= t <= 2^{-k}, 0 <= k < K,

and the pieces agree at common endpoints.

Lemma 10 (dyadic entropy approximation). The function psi is concave with
integer slopes of absolute value at most K, and for every x in P,

    0 <= h_2(x) - sum_e psi(x_e) <= n/2 + 1 <= n.

Proof. At a positive knot, phi(2^{-k}) = k 2^{-k}, so the chord on
[2^{-(k+1)}, 2^{-k}] has slope k - 1 and intercept 2^{-k}, while the chord
from zero has slope K; this gives the displayed pieces, and reading
intervals left to right the slopes are nonincreasing, so psi is concave.
Since p >= 6 the integer K is at least one and all slopes lie between -1
and K. Concavity of phi puts every chord below the graph. On
2^{-(k+1)} <= t <= 2^{-k} one has psi(t) - k t = 2^{-k} - t >= 0 and
phi(t) <= (k + 1) t, so 0 <= phi - psi <= t there. On the interval next to
zero write t = 2^{-K} r with 0 <= r <= 1; then phi(t) - psi(t) =
2^{-K} (-r log2 r) <= 2^{-K}, the maximum of -r log2 r on the unit interval
being 1/(e ln2) < 1. For x in P the degree sums give sum_e x_e = n/2, so
bounding the error by x_e above 2^{-K} and by 2^{-K} below it gives a total
of at most sum_{x_e >= 2^{-K}} x_e + #{e : x_e < 2^{-K}} 2^{-K} <=
n/2 + p 2^{-K} <= n/2 + 1 <= n.

Define the concave function f on the box [0,1]^p by

    f(x) = sum_e psi(x_e) + beta . x,   f* = max_{x in P} f(x).

Lemma 10 gives f(x) <= h_2(x) + beta . x <= f(x) + n on P, so taking
maxima yields f* <= q* <= f* + n. On each affine piece f has integer
coordinate slopes of absolute value at most K + L, and every breakpoint and
intercept has denominator dividing 2^K < 2p, so f is evaluated exactly by
rational arithmetic.

Constrained maximization is replaced by unconstrained maximization of a
penalized concave function on the box. For x in the box define

    w(x) = max{ 0, max_i |x(delta(i)) - 1|, max_{S odd} (1 - x(delta(S))) }.

By Theorem 2, w(x) = 0 exactly when x lies in P.

Lemma 11 (feasibility repair). With A_0 = 10 n^2, every x in [0,1]^p has
a point y in P with ||y - x||_inf <= (2 + A_0) w(x).

Proof. Write w = w(x), d_i = 1 - x(delta(i)), d_tot = sum_i d_i, and
correct degrees by x'_{ij} = x_{ij} + (d_i + d_j)/(n - 2) -
d_tot/((n - 2)(n - 1)). Since sum_{j != i} (d_i + d_j) = (n - 2) d_i +
d_tot, the correction sums to d_i at vertex i, so x'(delta(i)) = 1. As
|d_i| <= w and |d_tot| <= n w, the size of the correction is at most
(2/(n - 2) + n/((n - 2)(n - 1))) w <= 2w, hence x'_e >= -2w and every odd
set S satisfies x'(delta(S)) >= 1 - (1 + 2p) w. The vector u_{ij} = 1/(n-1)
has u(delta(S)) = |S|(n - |S|)/(n - 1); singleton and co-singleton cuts
equal one, and every nontrivial odd cut has 3 <= |S| <= n - 3, so for
n >= 6 it exceeds 3/2, and for n = 4 there is no nontrivial odd cut. Hence
u lies in P. Put t = min{1, A_0 w} and y = (1 - t) x' + t u. If A_0 w >= 1
then y = u lies in P. Otherwise t = A_0 w < 1, and A_0/(n - 1) >= 2 and
A_0/2 >= 1 + 2p give y_e >= -2(1 - t) w + A_0 w/(n - 1) >= 0 and, on each
nontrivial odd cut, y(delta(S)) >= 1 - (1 - t)(1 + 2p) w + A_0 w/2 >= 1;
the degree sums remain one, so the trivial odd cuts also hold at one, and
Theorem 2 gives y in P. In either branch y - x = (1 - t)(x' - x) + t(u - x)
with u, x in the box, so ||y - x||_inf <= 2(1 - t) w + t ||u - x||_inf <=
2w + t <= (2 + A_0) w, and the case w = 0 is immediate.

This repair bound converts constraint violation into distance from
feasibility, so a fixed penalty large enough recovers the constrained
optimum. Put M_0 = p (K + L)(2 + A_0), Phi(x) = f(x) - M_0 w(x), and
D_0 = p (K + L + M_0)^2. A vector g is a supergradient of Phi at x on the
box when Phi(z) <= Phi(x) + g . (z - x) for every z in [0,1]^p.

Lemma 12 (exact penalty and integral supergradients). The function Phi is
concave on [0,1]^p, its maximum there equals f*, and at every point of the
box it has an integral supergradient g with ||g||^2 <= D_0.

Proof. The slopes of psi are integers of absolute value at most K and
|beta_e| <= L, so f is Lipschitz in the sup norm: |f(x) - f(y)| <=
p (K + L) ||x - y||_inf. For the point y in P supplied by Lemma 11,
Phi(x) <= f(y) + p (K + L) ||x - y||_inf - M_0 w(x) <= f(y) <= f*, while
Phi = f on P, so the maxima agree. The function w is a maximum of affine
functions, hence convex, and f is concave, so Phi is concave. Choose a
supporting piece slope sigma_e of psi at x_e, allowing either adjacent slope
at a knot, and set b_e = sigma_e + beta_e; then f(z) <= f(x) + b . (z - x)
on the box. Writing each absolute value as the maximum of its two affine
terms and the zero term as the constant zero, any active affine term
a . z + c of w has a_e in {-1, 0, 1} and w(z) >= a . z + c = w(x) +
a . (z - x). Subtracting M_0 times this from the f-inequality shows
g = b - M_0 a is a supergradient of Phi on the whole box, the independent
choices of pieces and active rows being valid at endpoints and ties.
Finally g is integral with |g_e| <= K + L + M_0, so ||g||^2 <=
p (K + L + M_0)^2 = D_0.

The classical projected subgradient method of Polyak approximates the
optimum; the bounded integral supergradients let the step size be fixed and
keep every iterate on one rational grid.

Lemma 13 (finite projected ascent). Let N_it = p D_0, x^(0) = 0, and for
j = 0,...,N_it - 1 choose a supergradient g^(j) as in Lemma 12 and set
x^(j+1) = clip_{[0,1]^p}( x^(j) + g^(j)/D_0 ). Then

    R = floor( max_{0 <= j < N_it} Phi(x^(j)) )

satisfies R <= f* <= R + 2.

Proof. Choose z in P with f(z) = f*; then Phi(z) = f*. Clipping cannot
increase distance to z in the box. Expanding the squared distance and using
the supergradient inequality give

    ||x^(j+1) - z||^2 <= ||x^(j) - z||^2
        - (2/D_0)( f* - Phi(x^(j)) ) + 1/D_0.

Summing over the N_it indices yields

    2 sum_j ( f* - Phi(x^(j)) ) <= D_0 ( ||x^(0) - z||^2 - ||x^(N_it) - z||^2 ) + N_it
                                 <= p D_0 + N_it = 2 N_it,

since ||x^(0) - z||^2 <= p. Hence the largest sampled value V satisfies
f* - 1 <= V <= f*, and R = floor(V) gives R <= V <= f* and
f* <= V + 1 < R + 2.

Every iterate has coordinates that are integer multiples of 1/D_0: the
update adds an integral vector divided by D_0 and clipping inserts only 0
or 1. Evaluating w and choosing an active row compare the zero term and the
2n signed degree terms with the largest odd-cut violation, which requires a
minimum odd cut from the nonnegative integer capacities D_0 x_e^(j) and its
row in the original coordinates. The odd-cut recursion supplies both, and
the values of Phi and the floor defining R are then computed exactly by
rational arithmetic.

The optimizer needs both the value w(x) and an affine row attaining its
maximum. The degree terms are immediate. The missing ingredient is an
exact minimum odd cut together with its vertex set; minimum odd cuts as
matching-constraint separators go back to Padberg and Rao, whose b-matching
reduction the recursion specializes.

Consider an auxiliary graph on W with nonnegative integer capacities
c_{ij} = c_{ji} for distinct i, j in W, absent edges having capacity zero,
parallel capacities summed and loops discarded. Write c(S) for the sum of
c_{ij} over edges with one end in S, C for the total capacity, and v = |W|.
The classical augmenting-path method of Ford and Fulkerson supplies the
two-terminal minimum cut.

pdf: https://doi.org/10.4153/CJM-1957-024-0

Lemma 14 (integral two-terminal minimum cut). For distinct a, b in W a
minimum cut separating a from b is found deterministically with at most C
unit augmentations and O(v^2 (C + 1)) arithmetic operations on integers of
O(log2(v + C + 2)) bits.

Proof. Keep integers b_{ij} = -b_{ji} with b_{ij} <= c_{ij} in both
directions and sum_j b_{ij} = 0 for i outside {a,b}; the two directional
bounds give -c_{ij} <= b_{ij} <= c_{ij}. Start from zero flow. If a simple
directed path from a to b uses only steps with positive residual capacity
c_{ij} - b_{ij}, increase the flow on each forward step by one and
decrease its reverse by one; integrality makes this feasible, conservation
is preserved, and the net source outflow q = sum_j b_{aj} increases by one.
As q <= sum_j c_{aj} <= C, there are at most C augmentations. When no such
path exists, let S be the vertices reachable from a by positive-residual
steps; then b is outside S, every step from S to its complement is
saturated, and conservation gives q = sum_{i in S, j not in S} b_{ij} =
sum_{i in S, j not in S} c_{ij} = c(S). For any other a-b cut the same
identity with b_{ij} <= c_{ij} gives capacity at least q, so S is minimum.
A graph search with fixed vertex order finds a simple residual path or the
final reachable set in O(v^2) operations, there are at most C + 1 searches,
and all flows and residual capacities have magnitude at most 2C; the
argument includes C = 0.

Lemma 15 (minimum odd-terminal cut). Let U subset W have positive even
cardinality. A set S minimizing c(S) subject to |S intersect U| odd is
found deterministically, returning the set itself, using at most |U| - 1
recursive instances and O(|U|^3 v^2 (C + 1)) arithmetic operations on
integers of O(log2(v + C + 2)) bits.

Proof. Call a cut terminal-separating when both sides meet U. Compute a
minimum cut for every pair of distinct terminals with Lemma 14 and take
the least-capacity result, with sides A and its complement. Every
terminal-separating cut separates some pair, and every recorded pair cut is
terminal-separating, so this is a minimum terminal-separating cut. If
|A intersect U| is odd, return A; every admissible odd-terminal cut is
terminal-separating, so this answer is optimal. Otherwise both A intersect
U and its complement intersect U have positive even cardinality, and two
children are formed: keep A, contract the complement to a new nonterminal
and use terminal set A intersect U; or keep the complement, contract A and
use the complementary terminal set. In the first child the capacity from i
in A to the new vertex is sum_{j not in A} c_{ij}. Recurse on both and
return the better lifted cut; each call strictly decreases the positive
even terminal count, and when |U| = 2 the first cut is already odd.

A child cut lifts by replacing a contracted vertex, if included, with the
whole block it represents. Crossing capacities are unchanged and including
the block adds an even number of parent terminals, so the lift has the same
capacity and is terminal-odd. This holds through nested contractions:
current vertices partition into blocks, every current terminal is an
original singleton, every nonterminal block holds an even number of
original terminals, and capacities between current vertices sum original
capacities between blocks, so every returned subset lifts to an original
subset of the same capacity and parity.

To preserve an optimum, let S be an optimal odd-terminal side in the
current instance. Exactly one of S intersect A and S intersect the
complement carries an odd number of terminals; rename so that it is the
first, replacing S by its complement if needed, which keeps the odd
intersection because |A intersect U| is even. Now S union A contains
terminals of A and omits a terminal of the complement, so c(S union A) >=
c(A). For nonnegative undirected capacities the submodular inequality
c(S intersect A) + c(S union A) <= c(S) + c(A) holds, since the difference
is twice the capacity between S minus A and A minus S. Hence
c(S intersect A) <= c(S), and S intersect A is a feasible odd-terminal
side of the first child avoiding its contracted vertex; so at least one
child has optimum at most the parent's, while lifting shows every child
optimum is at least the parent's, and induction on |U| gives the parent
optimum.

For the size, each nonleaf splits its terminal set into two disjoint
nonempty even sets, so there are at most |U|/2 leaves and at most |U| - 1
instances in the binary recursion tree, and each contracted side holds at
least two terminals, so a child has fewer vertices. Within an instance
every surviving capacity sums a disjoint set of original capacities, with
edges internal to blocks discarded, so its total is at most C, and
multiplying the per-instance cost by the number of instances accounts for
capacities overlapping across children. There are at most O(|U|^2) pair
computations per instance, each O(v^2 (C + 1)), and contractions and
lifted-set bookkeeping fit within the same bound. Comparisons and ties
may use fixed orderings; zero capacities need no perturbation.

Recovering the active row in original coordinates uses the grid
invariance. At a trial point D_0 x_e is a nonnegative integer for every
original pair, since the initial point is zero and an integral
supergradient step of size 1/D_0 followed by clipping to [0,1] preserves
the grid. Lemma 15 applied with U = V and capacities c_e = D_0 x_e
returns, with each contracted vertex carrying its block of original
vertices, an explicit original set S of odd cardinality minimizing
x(delta(S)). The affine function of w is then l_S(y) = 1 -
sum_{e in delta(S)} y_e, whose coefficient is -1 on every original pair
crossing S, including pairs with x_e = 0, and zero elsewhere; spanning the
original pairs recovers the row even when zero-capacity edges were omitted
during searches, and contraction loops never cross a lifted cut. Comparing
l_S(x) with zero and the two signed degree violations at each vertex gives
w(x) and an affine row attaining it. The initial total capacity is at most
p D_0, a merged edge can exceed D_0 but the per-instance total stays at most
p D_0, and a large reverse residual does not change the source-outflow
bound of Lemma 14, so one violation computation takes O(n^5 (p D_0 + 1))
arithmetic operations.

The constructions assemble into one deterministic algorithm. The input is
a vertex set V = {1,...,n} and nonnegative integer pair multiplicities
k_{ij} in binary, an omitted pair having multiplicity zero; listing
parallel edges individually is also allowed, since multiplicities are then
counted first. The number N counts perfect matchings with parallel choices
distinguished. Fix the vertex and pair orderings and use the deterministic
cut procedure.

Step 1, elementary cases. If n = 0 return 1. If n is odd return 0. If n = 2
return k_{12}. Sort the endpoint labels occurring in positive records and
count the distinct labels; if fewer than n occur, an isolated vertex forces
count zero and the routine returns 0, using only the listed records even
when n is given in binary, before allocating any array indexed by all
vertices or pairs.

Step 2, setup. Now n >= 4 is even. Use all p = n(n-1)/2 pair coordinates.
Compute b_max, L, beta, let K be the least integer with 2^K >= p, and
define psi and f. Set A_0 = 10 n^2, define w, compute M_0, Phi, D_0, and
set N_it = p D_0 with integer vector a^(0) = 0, representing
x^(j) = a^(j)/D_0.

Step 3, evaluate and update the N_it trial points. For j = 0,...,N_it - 1:
apply Lemma 15 to the integral capacities a^(j)_e with every vertex a
terminal, obtaining a minimum-capacity odd cut S_j; compare
0, x(delta(1)) - 1, 1 - x(delta(1)), ..., x(delta(n)) - 1,
1 - x(delta(n)), 1 - x(delta(S_j)), whose maximum is w(x), and select the
first maximizing expression, giving a coefficient vector r^(j) in {-1,0,1}^p;
evaluate Phi(x) exactly and keep the largest trial value. Choose in each
coordinate the right-hand slope sigma_e^(j) of psi at x_e^(j), using the
left-hand slope at 1, and set g_e^(j) = sigma_e^(j) + beta_e - M_0 r_e^(j),
an integral supergradient by Lemma 12. Update the numerators by
a_e^(j+1) = min{ D_0, max{ 0, a_e^(j) + g_e^(j) } }.

Step 4, return the estimate. Let R = floor( max_{0 <= j < N_it} Phi(x^(j)) ).
If R < -10n return 0; otherwise return A = 2^rho with rho = max{0, R - 5n}.
The slope convention and the ordering settle ties, and the numerator update
is exactly the clipped step of Lemma 13.

Theorem 4 (deterministic approximate counting). There is one uniform
deterministic algorithm which, on a graph on n vertices with nonnegative
binary integer pair multiplicities, returns an integer A >= 0 with
N/512^n <= A <= N. Its running time and output length are polynomial in
the input bit length, and A = 0 exactly when N = 0. The guarantee includes
a compact input given by binary n and a list of positive pair records.

Proof of the approximation guarantee. The elementary cases are exact, so
assume n >= 4 even and the routine reaches the optimization. Lemma 13,
Lemma 10, and Corollary 4 give R <= f* <= R + 2, f* <= q* <= f* + n, and
q* - 4n <= log2 Z_beta <= q* + n. Combining them yields

    R - 4n <= log2 Z_beta <= R + 2n + 2 <= R + 3n.

If N = 0, Lemma 9 gives log2 Z_beta <= -20n, hence R <= -16n < -10n. If
N > 0, the same lemma gives Z_beta >= 1, hence R >= -3n > -10n; the zero
test is exact. Now let N > 0. The bounds Z_beta <= 2N and
Z_beta >= 2^{-n/2} N of Lemma 9 give

    R - 5n <= R - 4n - 1 <= log2 N <= R + 7n/2 <= R + 4n.

Also log2 N >= 0, so rho = max{0, R - 5n} <= log2 N, and rho >= R - 5n
gives log2 N - rho <= 9n. Exponentiating yields A <= N <= 2^{9n} A =
512^n A.

The analysis of bit size pins the polynomial bound.

Proposition 2 (bit complexity). The algorithm is uniform and
deterministic, and its running time and output length are polynomial in the
input bit length.

Proof. The elementary cases use only integer operations on the input. In
the remaining case put tau = n + b_max + 1 >= 5. The parameters have
polynomial numerical magnitude, not only polynomial bit length: p <= tau^2,
K <= n <= tau, 2^K < 2p, L = 100 tau^3, and A_0 <= 10 tau^2, so

    M_0 = p (K + L)(2 + A_0) <= 1212 tau^7,
    D_0 = p (K + L + M_0)^2 <= 1313^2 tau^16,
    N_it = p D_0 <= 1313^2 tau^18,

using K + L <= 101 tau^3 and 2 + A_0 <= 12 tau^2 for the first inequality
and K + L + M_0 <= 1313 tau^7 for the second. The exponent of each positive
multiplicity is its binary length minus one, floor(log2 k_e) =
bitlen(k_e) - 1, and no logarithm is evaluated numerically.

The update keeps a_e^(j) in {0,...,D_0} because every supergradient
coordinate is integral, so every iterate has denominator dividing D_0. On a
noninitial dyadic interval psi is (k - 1) t + 2^{-k} and next to zero it is
K t, so intercept denominators divide 2^K, while every degree or cut sum,
hence w(x^(j)), has denominator dividing D_0. A single common denominator
for all trial objectives is Q = D_0 2^K, independent of the number of
iterations and of changes of dyadic piece, so piece comparisons, objective
comparisons, and the final floor are exact integer operations. Since
0 <= w(x) <= n on the box and |f(x)| <= p(1 + L), |Phi(x)| <= p(1 + L) +
n M_0, the numerators with denominator Q, the supergradients, scaled
capacities and counters all have polynomial magnitude in tau, hence bit
length O(log tau).

At a trial point the cut oracle receives capacities a_e^(j) of total at
most p D_0. After contractions each surviving capacity sums original
capacities between two disjoint blocks with internal edges discarded, so
every original edge contributes to at most one surviving pair and the total
bound persists. Lemma 14 uses at most p D_0 unit augmentations per
terminal-pair computation, Lemma 15 uses O(n) recursive calls each with
O(n^2) terminal-pair computations, and dense residual searches take O(n^2)
elementary operations, so the optimization uses at most
O(N_it n^5 (p D_0 + 1)) = O(tau^41) elementary graph and arithmetic
operations on integers of O(log tau) bits, a polynomial bit bound.

The explicit output has polynomial length. Lemma 13 gives R <= f*, and
since psi(t) <= -t log2 t <= 1 on [0,1], beta_e <= b_max, and
sum_e x_e = n/2 on P(K_n), one has f* <= p + b_max n/2 >= 0, so the clamped
exponent satisfies rho = max{0, R - 5n} <= max{0, R} <= max{0, f*} <=
p + b_max n/2. Writing 2^rho as a binary integer takes O(n^2 + n b_max + 1)
bits and operations, and the zero and exact elementary outputs have
polynomial length. For an explicit vertex list, n and b_max are bounded by
the input bit length, and the coverage test of Step 1 is polynomial; if it
does not return zero, every vertex appears in a record, so n is at most
twice the number of positive pair records, and the complete-pair allocation
and optimization are polynomial in this encoding as well.

Sharpness of the codimension bound and the obstruction to coefficient one
are both exhibited by triangle expansions, the building blocks of the Klee
graphs studied by Cygan, Pilipczuk and Skrekovski. Extremal rank examples
also occur among the cubic staircases of Abdi, Cornuejols, Dadush and
Dalirrooyfard, whose three matching vectors meet every minimum odd cut once
and whose cut rows have rank |E| - 2; balanced matching laws on cubic graphs
and triangle contractions appear in the corrected full version of Esperet,
Kardos, King, Kral and Norine.

Let v be a vertex of degree three of a loopless multigraph G with a perfect
matching, incident to labelled edges e_i = v u_i, i = 1,2,3, the vertices u_i
not necessarily distinct. Replace v by a triangle on new vertices
t_1, t_2, t_3, reattach e_i to t_i u_i, let f_i denote the triangle edge
opposite t_i, and call the result G'. Reattached edges keep their labels and
the f_i receive new labels. Every perfect matching of G contains exactly one
of e_1, e_2, e_3, say e_i, and has a unique extension crossing the cut of
T = {t_1,t_2,t_3} once, obtained by adding f_i; conversely, contracting T in
a matching of G' crossing delta(T) once recovers exactly one matching of G.

Proposition 3 (face of a triangle expansion). The set Q_T = { y in P(G') :
y(delta(T)) = 1 } is a face of P(G') affinely isomorphic to P(G). Under the
isomorphism an old edge keeps its coordinate and y_{f_i} = y_{e_i}. If x in
P(G) has coordinate 1/3 on every edge, its image x' has coordinate 1/3 on
every edge of G', and the isomorphism carries the minimal face at x to the
minimal face at x'.

Proof. Every matching of G' crosses the odd cut delta(T) once or three
times, so y(delta(T)) >= 1 is valid on P(G') and its equality set is a face;
a convex combination lies in the face exactly when every matching of
positive weight crosses the cut once. For those matchings extension and
contraction are inverse bijections and the indicator of f_i equals that of
e_i, so these induce the stated affine isomorphism, with inverse given by
restriction to the old labels. The coordinate statement follows; Q_T is a
face containing x', and the minimal face of P(G') at x' is the minimal face
of Q_T at x', which an affine isomorphism preserves.

Begin with two vertices joined by three labelled parallel edges, whose three
one-edge matchings partition the edges. Expand a vertex repeatedly. Each
expansion adds two vertices and three edges and keeps degree three, so a
graph G_m after m - 1 expansions has |V(G_m)| = 2m and |E(G_m)| = 3m. The
three initial matchings extend uniquely at each step and still partition the
edge set, the new edge f_i joining the matching that holds e_i, so
x^(m) = (1/3)( a(M_1) + a(M_2) + a(M_3) ) has every coordinate 1/3 and lies
in the full perfect-matching polytope. The first expansion gives K_4 and
later expansions preserve simplicity, so G_m is simple for m >= 2; these are
the Klee graphs, and only the start m = 1 uses parallel edges.

Proposition 4 (sharp codimension and prescribed-marginal entropy). For
every integer m >= 1 the graph G_m and the point x^(m) satisfy

    F_{x^(m)} = conv{ a(M_1), a(M_2), a(M_3) },   d(x^(m)) = 2,

and the unique law on perfect matchings of mean x^(m) is the uniform law on
M_1, M_2, M_3. Consequently

    |E(G_m)| - d(x^(m)) = 3m - 2,   H(x^(m)) = ln3,
    F(x^(m)) = m ln3,   B(x^(m)) = 2m ln(3/2).

Proof. For m = 1 the three matching vectors are the coordinate vectors of
R^3 and P(G_1) is their simplex, whose uniform point is relative interior.
Repeated use of Proposition 3 shows the minimal face at x^(m) is the image
of this simplex with vertices a(M_1), a(M_2), a(M_3), of dimension two. A
direct restriction on laws confirms it: at the last inserted triangle a law
with marginals 1/3 has expected cut-crossing count one, and since every
matching crosses the cut once or three times it crosses once almost surely,
contraction gives a law with the same uniform marginals on the preceding
graph, and iteration leaves only the three initial matchings. Those matchings
partition the edges, so the marginal of an edge in M_i equals the probability
of M_i, which must be 1/3; the law is unique and its entropy is ln3. There
are 3m edges, all of marginal 1/3, and substitution in F and B gives the
remaining formulas.

All coordinates are strictly between zero and one, so the equality
|E| - d = 3m - 2 attains Proposition 1 at every positive even order;
equivalently the tight odd-cut rows have rank 3m - 2. The dimension two is
the dimension of the minimal face, and the whole polytope may have further
vertices.

Corollary 5 (restriction on a universal coefficient). If a constant c
satisfies H(x) >= F(x) - c B(x) for every finite loopless multigraph G and
every x in P(G), then c >= ln3 / (2 ln(3/2)). The same necessary bound holds
when only simple graphs are admitted.

Proof. Applying the inequality to G_m, x^(m) gives
c >= (m - 1) ln3 / (2m ln(3/2)); letting m grow and recalling that G_m is
simple for m >= 2 proves both statements.

The necessary coefficient lies strictly between 1 and the universal
coefficient 2 of Theorem 1, so sharpness of the geometric estimate does not
settle the optimal entropy coefficient. A fixed eight-vertex graph makes the
failure of coefficient one explicit.

Take vertex set {0,1,...,7} and edge set

    E = { 01, 03, 05, 14, 16, 23, 24, 27, 34, 56, 57, 67 },

with ij the undirected edge of endpoints i, j. Contracting the triangles
T = {2,3,4} and U = {5,6,7} gives K_4, so this graph is obtained by expanding
two vertices of K_4 and is an instance of G_4. Its five perfect matchings are

    M_1 = {01,27,34,56},   M_2 = {03,16,24,57},
    M_3 = {05,14,23,67},   N_1 = {03,14,27,56},
    N_2 = {05,16,27,34}.

A matching uses one of 01, 03, 05. With 01 the two odd triangles are joined
only by 27, forcing M_1. With 03, vertex 1 is matched by 14 or 16, after
which the rest is forced, giving N_1 or M_2. With 05, the same two choices at
vertex 1 force M_3 or N_2. The cuts delta(T) = {03,14,27} and
delta(U) = {05,16,27} each have total marginal one at x_e = 1/3. The matching
N_1 crosses delta(T) three times and N_2 crosses delta(U) three times, so
both have probability zero in every law with those marginals. The remaining
three matchings partition E, so their probabilities are all 1/3 and the
entropy is ln3 even though the graph has five matchings.

At this feasible point of the full polytope,

    H(x) = ln3,   F(x) - B(x) = 4 ln(4/3) > ln3,

because (4/3)^4 = 256/81 > 3. The difference F(x) - B(x) - H(x) is
ln(256/243) > 0, an eight-vertex counterexample to the coefficient-one lower
bound.

Two further routes to the codimension bound are recorded for their
distinct structure and for the weaker forms feeding the covariance
comparisons. Both work on the supported edges, where restriction and
zero extension are inverse affine maps on the minimal face.

A family of vertex sets is laminar when any two are disjoint or one contains
the other, and two sets cross when the two meet and neither contains the other.
Svensson and Tarnawski use laminar families of tight odd cuts in the
matching problem; Abdi et al. use the same uncrossing to bound tight-cut
rank.

Lemma 16 (laminar spanning family). Suppose x in P(G) has x_e > 0 on every
edge. There is a laminar family L of tight odd sets whose cut vectors are
linearly independent and span every tight cut vector chi_S, S an odd set
with x(delta(S)) = 1.

Proof. Let A, B be tight crossing sets and split V into the four regions
Z = A intersect B, D = A minus B, D' = B minus A, O = the rest. When |Z| is
odd both Z and A union B are odd, and the coordinatewise cut identity
chi_A + chi_B = chi_Z + chi_{A union B} + 2 1_{E(D,D')} holds. Dotting with
x, the left side is two, the two new odd terms are at least one each, and
the last term is nonnegative, so both new odd sets are tight and
x(E(D,D')) = 0; positivity of x makes E(D,D') empty and its indicator zero.
When |Z| is even the sets D and D' are odd and
chi_A + chi_B = chi_D + chi_{D'} + 2 1_{E(Z,O)}, and the same argument makes
D, D' tight and E(Z,O) empty. The replacements are nonempty proper, both
identities hold edge by edge, and the two replacements U, W lie in the tight
family with chi_A + chi_B = chi_U + chi_W.

Take an inclusionwise maximal laminar subfamily L of tight sets with
independent cut vectors and span R. Suppose a tight vector lies outside R and
choose among its sets one, A, crossing the fewest members of L. It crosses
some B in L, since otherwise A would extend L preserving laminarity and
independence. Apply that uncrossing to A, B; at least one replacement vector is
outside R, because otherwise chi_B in R and the identity would put chi_A in
R. Each replacement is laminar with B and crosses only members of L that
already crossed A: a set C laminar with both A and B lies in one of the
regions according to the nesting, and each region set is laminar with all of
L that A did not cross. So the replacement outside R crosses fewer members
of L, contradicting the choice of A, and L spans every tight cut vector.

This gives the sharp bound again. Adjoin missing singletons and the root V
to the laminar family. The inclusion tree has 2m singleton leaves, every
internal node is a disjoint union of its children, every proper node is odd,
so a nonroot internal node has an odd number of at least three children and
the root has an even number c >= 2 of children. With q nonroot internal
nodes the leaf count 2m - 1 = sum over internal nodes of (children - 1) is at
least (c - 1) + 2q, so the number of proper nodes 2m + q is at most
3m - c/2. When c >= 4 their cut vectors have rank at most 3m - 2, and when
c = 2 the two root children are complementary with equal cut vectors, so the
rank is at most 3m - 2 again.

The quotient-space view recasts the same count. Restricting to the supported
edge set A identifies T(x) with a subspace U_x of R^A, and Proposition 1
gives |A| - d(x) <= 3m - 2 for the supported mean.

Proposition 5 (supported face codimension). For a loopless labelled
multigraph on n = 2m >= 2 vertices and x in P(G), with A = {e : x_e > 0} and
s_A = |A|, one has s_A - d(x) <= 3m - 2. In particular s_A - d(x) <= 2(n - 2)
for n >= 4, s_A - d(x) = 1 for n = 2, hence s_A - d(x) <= 2n = 4m; the empty
graph has one point and zero codimension.

Proof. Induct on n. At order two the supported polytope is a simplex and a
positive point has codimension one. For n >= 4, if no nontrivial odd cut is
tight only the degree equations constrain U_x and the codimension is at most
n <= 3n/2 - 2. Otherwise choose a tight nontrivial cut delta(S), contract
each side to obtain x_i in P(G_i), supported sets A_i and spaces U_i, with
4 <= n_i < n and n_1 + n_2 = n + 2; the intersection C = A intersect
delta(S) is nonempty. Let Q(u) = ( r_1(u) + U_1, r_2(u) + U_2 ) map R^A to
the direct sum of the quotient spaces. A vector in the kernel restricts to
child directions, and Lemma 2 glues small perturbations of both signs into
parent directions, so the kernel lies in U_x. The cut-sum functionals
ell_i(z + U_i) = sum_{e in C} z_e are well defined because every child
direction preserves the contracted degree, each is nonzero, and
ell_1(r_1(u) + U_1) = sum_{e in C} u_e = ell_2(r_2(u) + U_2). Hence the image
of Q lies in the kernel of the nonzero functional a_1 - a_2, of codimension
one in the full quotient. Rank-nullity with the induction hypothesis gives

    s_A - d(x) <= rank Q <= (3 n_1/2 - 2) + (3 n_2/2 - 2) - 1 = 3n/2 - 2.

For n >= 4 this is at most 2(n - 2); the order-two simplex and the empty
graph give the remaining claims.

The exact fractional cases follow on removal of the fixed coordinates. With
E_f the fractional edges and V_f the vertices meeting them, s_f = |V_f| is
even and

    d(x) >= |E_f| - 2(s_f - 2)  when s_f >= 4,
    d(x) >= |E_f| - 1           when s_f = 2,
    d(x) >= 0                   when s_f = 0,
    sum_{e in E_f} x_e = s_f/2.

The proof repeats Lemma 4: value-one edges fix their endpoints, a matching
law of mean x restricts to a matching law of the reduced graph H with mean
bar x, the affine extension of P(H) injects the direction space at bar x into
T(x), Proposition 5 gives |E_f| - 2(s_f - 2) when s_f >= 4, a simplex on
k >= 2 parallel edges gives |E_f| - 1 when s_f = 2, and s_f = 0 gives a single
matching vector. Summing the degree equations over V_f counts each fractional
edge twice, giving the second identity.

The coarser dimension estimates already imply separable entropy
bounds, and the calculation displays how the exact residual cases separate
the coefficients three and four. Keep the continuity and face-law results of
Lemmas 6 and 7 and the entropy comparison of Lemma 5. The calculation keeps
fixed coordinates in the ambient space and differentiates only on the
fractional coordinates.

Theorem 5 (separable entropy bounds by covariance). Let G be a finite
loopless labelled multigraph of even order n = 2m with a nonempty matching
family, and for real c define J_c(x) = F(x) - c B(x). For each c in {3,4} and
every x in P(G),

    J_c(x) <= H(x) <= F(x) + B(x) = H_bin(x).

Proof. For the upper bound, regard a matching law of mean x as a law on
{0,1}^E supported on matching vectors and compare it with the independent
Bernoulli product of respective means x_e. A coordinate of mean zero or one
is fixed at that value under both laws, so the product is positive wherever
the matching law is positive, and Lemma 5 gives the upper bound.

For the lower bound fix c = 3 or c = 4. Lemma 6 and continuity of J_c make
H - J_c attain a minimum on the compact P. At an integral mean the only law
is the point mass at a matching vector, where H = J_c = 0, so it remains to
rule out a fractional minimizer x. Take its positive maximizing law p and a
parameter theta from Lemma 7, and for v in R^E, t in R set
p_a(t) = exp((theta + t v) . a) / sum_b exp((theta + t v) . b) and
x(t) = sum_a p_a(t) a. Lemma 7 keeps x(t) in the relative interior of F_x and
gives H(x(t)) = Phi(t) - (theta + t v) . x(t) with
Phi(t) = log sum_{a in A_x} exp((theta + t v) . a), so the curves may be
differentiated without smoothness of H across faces.

Let C = sum_a p_a (a - x)(a - x)^T be the covariance at t = 0. Then
p_a'(0) = p_a v . (a - x), x'(0) = C v, and for any w,
w^T C w = sum_a p_a (w . (a - x))^2. All p_a are positive and the vectors
a - x span T(x), so

    ker C = T(x)^perp,   im C = T(x),   rank C = d(x).

At a fractional mean some C_ee = x_e(1 - x_e) > 0, so d(x) >= 1, and
x''(0) lies in T(x). On the fractional coordinates write
g_e = -log x_e - c log(1 - x_e) - (c + 1) and D_ee = -1/x_e + c/(1 - x_e),
let D be diagonal, and set g_e = D_ee = 0 elsewhere. A coordinate fixed at
zero or one is constant on the face atoms, so its contribution to J_c(x(t))
vanishes identically; a fractional coordinate takes both bit values among
the atoms and positivity keeps it strictly fractional for every finite t, so
the chain rule on fractional coordinates gives all derivatives of J_c(x(t)).

From Phi'(t) = v . x(t) and the entropy formula,
dH/dt = -(theta + t v) . x'(t). Both signs of t are allowed, so the minimum
property gives (theta + g) . C v = 0 for every v, hence theta + g is
orthogonal to T(x) and (theta + g) . x''(0) = 0. The second derivative at
the minimum is then

    0 <= d^2/dt^2 ( H(x(t)) - J_c(x(t)) ) = -v^T C v - (C v)^T D (C v).

Take orthonormal eigenvectors u_1,...,u_d for the positive eigenvalues
lambda_i of C. Substituting v = u_i and dividing by lambda_i gives
lambda_i u_i^T (-D) u_i >= 1, and summing with C = sum_i lambda_i u_i u_i^T
yields

    d(x) <= sum_i lambda_i u_i^T (-D) u_i = tr( C(-D) ).

Only the spectral decomposition of C is used; no inverse of C and no
simultaneous diagonalization of C and D is needed.

Each coordinate is Boolean, so C_ee = x_e(1 - x_e). With s_f the number of
vertices meeting the fractional edges E_f,

    tr(C(-D)) = sum_{e in E_f} x_e(1 - x_e)( 1/x_e - c/(1 - x_e) )
              = |E_f| - (c + 1) sum_{e in E_f} x_e = |E_f| - ((c+1)/2) s_f.

For c = 4 the weaker consequence d(x) >= |E_f| - 2s_f of the residual
dimension bound suffices: tr(C(-D)) = |E_f| - (5/2) s_f < |E_f| - 2s_f <=
d(x), since a fractional point has s_f > 0. For c = 3 the trace is
|E_f| - 2s_f and the exact residual cases are used. If s_f >= 4 then
d(x) >= |E_f| - 2(s_f - 2) = |E_f| - 2s_f + 4 > tr(C(-D)). If s_f = 2 then
d(x) >= |E_f| - 1 > |E_f| - 4 = tr(C(-D)). These exhaust the positive even
values of s_f, and each coefficient contradicts d(x) <= tr(C(-D)). So no
fractional minimizer exists, the minimum is at an integral mean, and it
equals zero, proving the lower bound for each coefficient.

Corollary 6 (separable and nonlinear consequences). For every x in P(G)
with n = 2m > 0,

    F(x) - 4B(x) <= F(x) - 3B(x) <= H(x) <= F(x) + B(x),
    F(x) - H(x) <= min{ F(x), 3m } <= 8m(1 - e^{-F(x)/m}),
    log N(G) <= max_{x in P} ( F(x) + B(x) ) <= log N(G) + 2n <= log N(G) + (5/2) n.

Proof. Theorem 5 gives F - 3B <= H <= F + B by the covariance route, and
its c = 4 case gives F - 4B <= H, so the first line follows from B >= 0.
Nonnegativity of entropy and B <= m give F - H <= min{F, 3m}. Put t = F/m
and f(t) = 8(1 - e^{-t}). On [0, ln2], f(0) = 0 and f'(t) = 8 e^{-t} >= 4 >=
1, so f >= t; on t >= ln2, f(t) >= 4 >= 3. Hence min{t,3} <= f(t), proving
the nonlinear inequality, independently of the normalized-inverse-covariance
argument. For the optimized bound, H <= log N and
(F + B) - (F - 3B) = 4B <= 4m = 2n give the upper error 2n, while F - 4B
instead gives (F + B) - (F - 4B) = 5B <= 5m = (5/2) n; the uniform law gives
the lower bound exactly as in Corollary 2, and the sharper error 3m - 2
there improves both.

Corollary 7 (coefficient-three and nonlinear counts). For k >= 1 put b_1 = 1
and b_k = k (1 - 1/k)^{3(k-1)} for k >= 2. A loopless labelled multigraph on
2m > 0 vertices containing k >= 1 pairwise edge-disjoint perfect matchings
satisfies

    N(G) >= b_k^m >= (e^{-3} k)^m,
    N(G) >= [ k exp(-8(1 - 1/k)) ]^m >= (e^{-8} k)^m.

The same conclusions hold when G is k-regular and every odd cut has at
least k edges.

Proof. At the selected mixture mean of Theorem 3, F = m log k and x vanishes
outside the labelled union. For k >= 2, F - 3B = m log k + 3m(k-1) log(1 - 1/k);
using H <= log N and Corollary 6 then exponentiating gives the first bound,
and (k - 1) log(1 - 1/k) >= -1 gives its coarse form, while k = 1 has
b_1^m = 1. The nonlinear inequality gives log N >= m log k - 8m(1 - 1/k),
including k = 1, and exponentiating with 1 - 1/k <= 1 gives the second line.
For k-regular graphs with the odd-cut hypothesis, Corollary 3 makes the
uniform vector feasible and the same evaluations apply.

Corollary 8 (exact partition of the ambient edges). If the entire edge set of
a loopless labelled graph on 2m > 0 vertices is partitioned by k >= 1
perfect matchings, then

    N(G) >= [ k exp(-8(1 - 1/k)) ]^m >= (e^{-8} k)^m.

When k = 1 the count is exactly one. If k = 0 and the order is positive the
graph is edgeless with count zero, and only the coarse bound is asserted; the
empty vertex set has one empty matching.

Proof. The partition satisfies the hypothesis of Corollary 7, and its
uniform law has marginal 1/k on every ambient edge, so the nonlinear proof
applies verbatim; k = 1 makes the graph a single perfect matching, k = 0 has
no edges, and the empty case follows from the definition of a matching
without expressions containing 1/m.

The remaining nonlinear bound is proved directly by normalizing the positive
marginals, so that the marginal-entropy Hessian becomes minus the identity
while the covariance trace takes an exact combinatorial value.

Theorem 6 (nonlinear entropy bound). For a finite loopless multigraph G on
2m > 0 vertices with at least one perfect matching and every y in P(G),

    F(y) - H(y) <= 8m ( 1 - e^{-F(y)/m} ).

Proof. Define f(t) = 8(1 - e^{-t}) and
Psi(y) = F(y) - H(y) - m f(F(y)/m). Suppose Psi is positive somewhere; by
Lemma 6 it has a positive maximum at x in P. Let F_x be the minimal face, put
A = {e : x_e > 0}, s = |A|, d = dim F_x, t = F(x)/m. Each matching has m
edges, so sum_e x_e = m and 0 <= x_e <= 1, and concavity of -u log u gives
0 <= t <= log(s/m). On [0, ln8], f(0) = 0 and f'(t) >= 1, so f >= t; since
H >= 0, positivity of Psi forces t > ln8 and s > 8m. Proposition 5 then gives

    d >= s - 4m > s/2 > 0.

Thus integral and low-entropy cases are excluded before any inverse is
introduced.

Let M_x be the face atoms. Every law whose mean lies in F_x is supported on
M_x, because each active inequality has nonnegative slack and zero expected
slack, so F_x = conv{ a(M) : M in M_x }. Discard coordinates outside A and
set D = diag(x_e : e in A) and the normalized tangent space
T = D^{-1/2} T(x). All diagonal entries are positive, and Lemma 3 makes x
relative interior to F_x, so z = D^{-1/2}(y - x) identifies a relative
neighborhood of x with a neighborhood of zero in the d-dimensional T. Put
b_M = D^{-1/2}(a(M) - x); their convex hull contains a neighborhood of zero
in T. All gradients, Hessians, inverses and traces are taken on T;
coordinates equal to one have zero centered entries and zero tangent
directions and cause no singularity.

Express the face law of Lemma 7 in the normalized coordinates. With p the
positive maximizer and parameter theta on A, and a(M) = x + D^{1/2} b_M,

    theta . a(M) = theta . x + (D^{1/2} theta) . b_M,

and every b_M lies in T, so only lambda = proj_T(D^{1/2} theta) matters. Set
Phi(eta) = log sum_{M in M_x} exp(eta . b_M) on T; then
p_M = exp(lambda . b_M - Phi(lambda)) and grad Phi(lambda) = 0. For any eta in
T put p_{eta,M} = exp(eta . b_M - Phi(eta)), z(eta) = sum_M p_{eta,M} b_M and
y(eta) = x + D^{1/2} z(eta). Lemma 7 shows this law maximizes entropy at
y(eta) on the same minimal face, and differentiating the finite sum gives

    z(eta) = grad Phi(eta),   H(y(eta)) = Phi(eta) - eta . z(eta),
    C(eta) = grad^2 Phi(eta) = Cov_{p_eta}(b_M).

Each C(eta) is positive definite on T: zero variance in u in T would make
u . b_M constant on the atoms, and because p_eta is positive the affine span
of the b_M, which is T, would meet u^perp nontrivially unless u = 0. Write
C = C(lambda).

Set Fhat(z) = F(x + D^{1/2} z) and L(z) = Fhat(z) - m f(Fhat(z)/m), smooth
near zero on T. On the retained coordinates the Hessian of F at x is
-D^{-1}, so the change of coordinates gives grad^2 Fhat(0) = -I_T. The smooth
function J(eta) = L(z(eta)) - Phi(eta) + eta . z(eta) = Psi(y(eta)) has a
local maximum at lambda, with gradient
grad J(eta) = C(eta)( grad L(z(eta)) + eta ). Since C is invertible and
z(lambda) = 0, stationarity gives grad L(0) + lambda = 0, and differentiating
again, the derivative of C(eta) hitting the zero vector, gives
grad^2 J(lambda) = C grad^2 L(0) C + C <= 0. Congruence by C^{-1} yields

    grad^2 L(0) + C^{-1} <= 0

on T. Under p = p_lambda the normalized vectors b_M have mean zero, and for
each edge the indicator of a random matching has variance x_e(1 - x_e), so

    tr_T C = E_p ||b_M||^2 = sum_{e in A} x_e(1 - x_e)/x_e = s - m.

The trace on T equals the ambient trace because the b_M lie in T. For u > 0,
u^{-1} >= 2 - u, so applied to the d positive eigenvalues of C,

    tr_T(-I_T + C^{-1}) >= d - tr_T C = d - s + m >= -3m,

the last by Proposition 5. For the nonlinear correction, with
g = grad Fhat(0) = -1 on A, the chain rule gives

    grad^2 [ m f(Fhat(z)/m) ] at 0 = -f'(t) I_T + (f''(t)/m) g g^T,

and since f'' < 0 the rank-one term contributes at least zero to the trace.
Thus grad^2 L = f'(t) I_T - I_T - (f''(t)/m) g g^T, and

    tr_T( grad^2 L(0) + C^{-1} )
        >= -3m + f'(t) d >= -3m + 8m d / s > m > 0,

using t <= log(s/m), so f'(t) = 8 e^{-t} >= 8m/s, and d > s/2. This
contradicts grad^2 L(0) + C^{-1} <= 0, so Psi <= 0 throughout P.

The nonlinear statement assumes m > 0 because it divides by m. On the empty
vertex set the unique empty matching has F = H = 0, and a nonempty graph with
no perfect matching has no means to which the statement applies.

A final convention allows a loop to cover its single incident vertex. Let
l_i be the number of distinguished loop choices at vertex i and keep the pair
multiplicities k_{ij}, all given in binary. A matching covers each vertex once
by a loop or an ordinary pair. Let N_j be the number of such matchings using
exactly j loops and N_loop = sum_j N_j.

Proposition 6 (singleton loops). There is one deterministic algorithm which,
given a graph on n vertices with nonnegative binary integer pair and
singleton-loop multiplicities, returns a nonnegative rational number A_loop
with N_loop / 2^{18n} <= A_loop <= N_loop, returning zero exactly when
N_loop = 0, in polynomial time and output length including the compact binary
encoding.

Proof. Count the distinct vertices occurring in a positive pair or having a
positive loop count; if any of the n vertices is missing it cannot be covered
and the routine returns zero, using only the listed records. Otherwise, with
r positive pair records and s positive loop records, n <= 2r + s, so the
constructions have polynomial size. For each j in {0,...,n} build a
loopless graph G_j by adjoining j labelled new vertices with no edges among
them, joining original vertex i to each new vertex by l_i parallel edges
labelled by the loop choices, and keeping the original pairs. Every matching
of G_j pairs the new vertices to j distinct original vertices; replacing those
pairs by the loop choices and keeping the rest gives a matching counted by N_j,
and each such matching has exactly j! lifts, one per bijection, labels
preserving the choices, so N(G_j) = j! N_j.

Run the ordinary algorithm on each G_j to get a nonnegative integer A_j and
return A_loop = sum_j A_j / j!. Parity is tested on each transformed order
n + j, equal in parity to n - j, and there is no rejection for odd n because a
single looped vertex is already a positive example. Theorem 4 and the identity
give N_j / 512^{n+j} <= A_j / j! <= N_j; since n + j <= 2n, summing proves the
factor 512^{2n} = 2^{18n}. Nonnegativity makes A_j = 0 exactly when N_j = 0, so
zero recognition is exact. The construction keeps compressed records, each
transformed graph has at most 2n vertices and uses only input multiplicities,
and Proposition 2 bounds each call and gives O(n^2 + n b_max + 1) bits for
A_j; there are n + 1 calls. The rational sum has common denominator n!,

    A_loop = ( sum_j A_j n!/j! ) / n!,

with an O(n log2(n+1) + 1)-bit denominator and an
O(n^2 + n b_max + n log2(n+1) + 1)-bit numerator, so factorials, exact
divisions, products and the sum take polynomial bit time. The case n = 0 uses
the single term j = 0 with 0! = 1 and A_0 = 1, counting the empty matching
exactly.
