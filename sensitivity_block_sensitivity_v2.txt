A Boolean function on n bits is a map f: {0,1}^n -> {0,1}. For x in {0,1}^n and B a set of coordinates, x^B denotes x with the bits in B flipped; x^a abbreviates x^{{a}}. The sensitivity of f at x is

    s(f,x) = #{a in [n] : f(x^a) != f(x)},

and s(f) = max_x s(f,x). The block sensitivity of f at x is the largest m for which pairwise disjoint nonempty coordinate sets B_1, ..., B_m exist with f(x^{B_j}) != f(x) for every j; bs(f) = max_x bs(f,x). A single coordinate is a block, so s(f) <= bs(f).

Block sensitivity arose in Nisan's 1989 study of CREW PRAM decision trees, which already records a quadratic separation due to Rubinstein. Nisan and Szegedy (1994) connected both measures to the real degree deg(f), the least degree of a real multilinear polynomial agreeing with f on {0,1}^n, and proposed bs(f) <= s(f)^2. Rubinstein (1995) reached bs(f) = s(f)^2 + o(s(f)^2). Virza (2011) sharpened the quadratic coefficient to 1/2. Ambainis and Sun (2011) raised it to 2/3.

    ./ambainis-sun-1108.3494.pdf

Huang (2019) settled the polynomial form: every induced subgraph of the n-cube on more than 2^(n-1) vertices has maximum degree at least sqrt(n), which gives deg(f) >= sqrt(s(f)) for every total Boolean f. In the paper's own words:

    "This result is best possible, and improves a logarithmic lower bound shown by Chung, Furedi, Graham and Seymour in 1988."

    ./hao-huang-1907.00847.pdf

Tal (2013) tied block sensitivity, certificate complexity and degree tightly enough that Huang's bound yields bs(f) <= s(f)^4.

    ./tal-2013.pdf

Wellens (2022) improved the constant to bs(f) <= sqrt(2/3) s(f)^4 + 1.

    ./wellens-2005.00566.pdf

Aaronson, Ben-David, Kothari, Rao and Tal (2021) gave approximate-degree and quantum duals of Huang's combinatorial lemma, showing that the sensitivity-degree link is structural rather than accidental.

    ./aaronson-et-al-2010.12629.pdf

Meiburg (2026) obtained a superquadratic separation of block sensitivity from spectral sensitivity using a tournament of rows with one selected blocking coordinate on every outgoing edge.

    ./meiburg-2608.00851.pdf

Main theorem. For every real C > 0 there exist a positive integer n and a total nonconstant f: {0,1}^n -> {0,1} with bs(f) > C s(f)^2. Sharper, for each integer d >= 1 there is such an f with

    bs(f) / s(f)^2 >= 2^d / (4 (d+2)^2).

Functions are built by recursion on the depth d. Depth zero uses indicators of unions of Hamming balls of a common integer radius around well-separated centres; higher predicate indices use smaller radii, so the family is nested. At depth l >= 1, the input splits into kr disjoint children in k rows of r columns. A tournament directs one edge between each pair of rows; its label selects one column in the destination. A clause at row i asserts that all r children of row i accept the strongest child predicate and that, for every outgoing neighbour j of i, the labelled child of j fails a weaker child predicate. The parent predicate is the OR, over rows i, of the clause at i. Varying the gate predicate's index q in {1, ..., H_l} produces a nested family at level l.

Three lemmas drive the recurrences. A random edge labelling prevents any set of t = 16 rows from having matching labels on all internal edges. The tournament structure admits at most three gate-candidate rows at once. Repairing a gate on an accepting parent forces two nested child predicates to reverse simultaneously on the same child, which is why the recurrences carry a joint profile J_{l,b} alongside S_{l,b}.

The proof combines the recurrences with a comparison sequence that bounds S_{l,b} by 2L M^(l+b) once M is large relative to d, and with explicit disjoint blocks that make block sensitivity at the all-zero input of the final OR wrapper equal to M^2 k^d. The ratio of these two quantities yields the stated separation.

Parameters. Fix integers d >= 1 and M >= 3 and set

    L = d + 2,       k = 2 M^2 + 1,       r = ceil(sqrt M),       t = 16.

The tournament on [k] directs exactly one edge between each pair of distinct vertices. Take a cyclic tournament: label vertices by residues modulo k and direct each vertex to the next M^2 vertices; every vertex has outdegree M^2.

Edge labels. Choose a(i,j) in [r] for every edge i -> j, independently and uniformly at random.

Lemma (labelling). With positive probability, no set W subset [k] of size t admits a choice m_j in [r] for each j in W with a(i,j) = m_j on every edge i -> j internal to W.

Proof. Fix a set W of size t and a tuple (m_j) in [r]^W. The probability that the binomial(t,2) = 120 internal equalities all hold is r^(-120). The number of pairs (W, m) is at most k^t r^t, so the union bound gives probability at most

    k^t r^t r^(-120) = k^16 r^(-104) <= (3 M^2)^16 (sqrt M)^(-104) = 3^16 M^(-20),

using k <= 3 M^2, r >= sqrt M and M >= 3. The exponent of M is -20, so the right-hand side is less than one. The complementary event is therefore nonempty: some labelling satisfies the stated property.

Notation. For 0 <= l <= d set H_l = d + 1 - l and N_l = L M (kr)^l. The construction produces nested predicates P_{l,q}: {0,1}^{N_l} -> {0,1} for 1 <= q <= H_l, with

    P_{l,1}(x) >= P_{l,2}(x) >= ... >= P_{l,H_l}(x)       for every x in {0,1}^{N_l}.

Nesting refers to the index q, not to the input bits.

Base predicates. Partition [LM] into M blocks E_1, ..., E_M, each of size L. Let z_j in {0,1}^{LM} be the indicator of E_j, so z_j has L ones at the positions of E_j and zeros elsewhere. Set

    D(x) = min_{j in [M]} dist(x, z_j),        P_{0,q}(x) = 1_{D(x) <= H_0 - q} .

The radii H_0 - q run over d, d-1, ..., 0 as q runs over 1, ..., d+1 = H_0. Distinct centres sit at distance 2L = 2d + 4 apart, well separated. The predicates are nested because lowering q raises the radius.

Recursion. Fix l in [1, d] and put H = H_l, Q = H + 1 = H_{l-1}. Split the input into kr disjoint children x_{j,c} in {0,1}^{N_{l-1}}, indexed by row j in [k] and column c in [r]. For q in [H], the clause of row i asserts

    P_{l-1,Q}(x_{i,c}) = 1                 for every c in [r],
    P_{l-1,Q-q}(x_{j,a(i,j)}) = 0          for every edge i -> j from i.

The first line contains the target conditions, the second the gate conditions. Define P_{l,q}(x) = 1 if at least one row's clause holds, and P_{l,q}(x) = 0 otherwise. Every index is in range: 1 <= Q - q <= H < Q. Within a single clause, targets occupy row i and each gate occupies a distinct other row; row j hosts at most one gate of the clause because i has only one edge to j. The r + M^2 conditions of one clause therefore involve r + M^2 distinct children, and a single coordinate flip can touch at most one of these children. The same bit can appear inside several clauses, which is handled by a union bound in the recurrences.

Nesting. Increasing q lowers the gate index Q - q and so requires a stronger child predicate to be zero; the target conditions do not move. Each clause at index q+1 lies inside the clause at index q, and the P_{l,q} at level l form a nested family.

Total bits. The recursion N_l = kr N_{l-1} with N_0 = L M gives N_l = L M (kr)^l. Each level multiplies the bit count by kr.

Profiles. For b in {0,1} set

    S_{l,b} = max { |{ a in [N_l] : P_{l,q}(x^a) = 1-b }| : 1 <= q <= H_l, x in {0,1}^{N_l}, P_{l,q}(x) = b },

and

    J_{l,b} = max { |{ a in [N_l] : P_{l,q}(x^a) = P_{l,q'}(x^a) = 1-b }| : 1 <= q < q' <= H_l, x in {0,1}^{N_l}, P_{l,q}(x) = P_{l,q'}(x) = b }.

The maximum over an empty index set is zero; in particular J_{d,0} = J_{d,1} = 0 because H_d = 1. The two predicates in J_{l,b} are evaluated at the same input and flipped by the same coordinate.

Lemma (base). S_{0,0} <= L, S_{0,1} <= LM, and J_{0,0} = J_{0,1} = 0.

Proof. Fix q, radius R = H_0 - q in {0, 1, ..., d}, and x with P_{0,q}(x) = 0. A single flip x -> x^a makes the predicate one only if D(x^a) <= R; the Lipschitz bound |D(x) - D(x^a)| <= 1 then gives D(x) <= R + 1. The hypothesis P_{0,q}(x) = 0 says D(x) > R, so D(x) = R + 1 and some centre z_j sits at distance exactly R + 1 from x. Two centres z_j, z_{j'} within distance d + 1 of x would satisfy dist(z_j, z_{j'}) <= 2d + 2 < 2L, contradicting the exact separation 2L = dist(z_j, z_{j'}). At most one centre lies within distance d + 1 of x, so every successful flip moves x towards that same centre. The count of successful coordinates is therefore at most R + 1 <= d + 1 <= L, giving S_{0,0} <= L. The bound S_{0,1} <= LM is simply the total number of input bits.

For J_{0,b}: the triangle inequality on any adjacent pair x, y gives |D(x) - D(y)| <= 1. Two distinct integer radii R, R' both changing from 1 to 0 (or both from 0 to 1) along a single flip would force D to change by at least 2 across the two radii. That is impossible, so J_{0,0} = J_{0,1} = 0.

Lemma (blocks at zero). For every 0 <= l <= d and every q in [H_l], P_{l,q}(0) = 0. The set [N_l] partitions into M k^l pairwise disjoint nonempty blocks of size L r^l, each of which, when flipped at the all-zero input, sends every P_{l,q} to one.

Proof. Level 0: D(0) = L > d, so P_{0,q}(0) = 0. The blocks E_1, ..., E_M each have size L and satisfy 0^{E_j} = z_j, whence D(z_j) = 0 <= H_0 - q for every q, and every P_{0,q} evaluates to one at z_j.

Inductive step. Suppose level l-1 has blocks B_1, ..., B_{M k^{l-1}} with the stated property. Enumerate the blocks and, for each row i and family index h, take the union of the copies of B_h across the r children of row i. Flipping this union makes every child of row i accept the strongest predicate, so all targets of clause i hold. Gate children of clause i sit in other rows and remain at zero, so gates hold for every q and P_{l,q} becomes one after the flip. Within a row the unions are disjoint because the underlying blocks are disjoint in every child; between different rows the unions are disjoint. The count is k * M k^{l-1} = M k^l and each block has size r * L r^{l-1} = L r^l.

Proposition (recurrences). Fix 1 <= l <= d. Write S'_b = S_{l-1,b} and J'_b = J_{l-1,b}. Then

    S_{l,1} <= M^2 S'_0 + r S'_1,           J_{l,1} <= M^2 J'_0 + r S'_1,           (one to zero)
    S_{l,0} <= t S'_0 + S'_1 + 3 J'_1,      J_{l,0} <= t S'_0 + 3 J'_1.            (zero to one)

Proof. Fix l, put H = H_l and Q = H + 1, and return to the definition of P_{l,q}. At index q, every target tests P_{l-1,Q} = 1 and every gate tests P_{l-1,Q-q} = 0 on a specified child. Targets of clause i lie in row i; its gates lie in distinct other rows. Every condition of a fixed clause uses a different child.

All flips considered are flips of single parent coordinates. Such a flip lies in one child and hence changes at most one condition of any fixed clause. A child can appear in several clauses, and the contributions are combined over candidate clauses.

Transitions from one. Fix q and x with P_{l,q}(x) = 1, and choose a clause satisfied at x. Any flip taking P_{l,q} to zero breaks that clause. Either a target flips from one to zero (r targets, each at most S'_1 flips of one child) or a gate flips from zero to one (M^2 gates, each at most S'_0 flips of one child). Summing, S_{l,1} <= M^2 S'_0 + r S'_1.

For the joint estimate, fix q < q' and x with P_{l,q}(x) = P_{l,q'}(x) = 1. Choose a clause satisfied at x for index q'; nesting gives P_{l,q}(x) >= P_{l,q'}(x) = 1, so the clause is satisfied for q as well. A flip taking both parents to zero must break this fixed clause for q' and therefore for q. A broken target contributes at most r S'_1. A broken gate: put g = Q-q and g' = Q-q', so 1 <= g' < g < Q. The clause is satisfied for q', so P_{l-1,g'}(x) = 0; nesting gives P_{l-1,g}(x) = 0. Failure of the gate for q' after the flip means P_{l-1,g'}(x^a) = 1; nesting gives P_{l-1,g}(x^a) = 1. Both child predicates flip 0 -> 1 at the same child, so the gate costs at most J'_0. Over M^2 gates: M^2 J'_0. Together, J_{l,1} <= M^2 J'_0 + r S'_1.

Initial candidate clauses at a zero. Fix q and x with P_{l,q}(x) = 0. Let T be the set of clauses that at x fail exactly one target and no gate. Let G be the set of clauses that at x fail exactly one gate and no target. The sets depend on x and q alone, not on any later flip. If a flip sends P_{l,q} to one, some previously false clause becomes true; the flip lives in one child, so it changes at most one clause condition, and that clause must be in T or G with its unique failed condition repaired.

Size of T. For j in T, let m_j in [r] denote the position of the unique failed target in row j. If i, j in T are joined by an edge i -> j, then clause i has a passing gate at child (j, a(i,j)), i.e. P_{l-1,Q-q}(x_{j,a(i,j)}) = 0. Nesting gives P_{l-1,Q}(x_{j,a(i,j)}) = 0. By definition of T, P_{l-1,Q} is zero only at m_j inside row j, so a(i,j) = m_j. A subset W of T of size t would provide choices m_j for j in W with a(i,j) = m_j on every internal edge, contradicting the labelling lemma. Hence |T| < t.

Repair cost, target side. Repairing a clause in T requires only its unique failed target to become one, at most S'_0 flips per clause. The total target contribution to S_{l,0} is at most t S'_0.

Size of G. Every target of a vertex of G is one at x. If i, j in G and i -> j, then clause i has a passing gate at child (j, a(i,j)), giving P_{l-1,Q-q}(x_{j,a(i,j)}) = 0. Row j has all targets equal to one, so P_{l-1,Q}(x_{j,a(i,j)}) = 1; nesting forces P_{l-1,Q-q}(x_{j,a(i,j)}) = 1, contradicting a passing gate. Hence every edge i -> j internal to G is the unique failed gate of clause i. Each vertex of G has at most one internal outedge, so the induced tournament on m = |G| vertices has outdegree at most one everywhere. Counting its edges, m(m-1)/2 <= m, hence m <= 3. At most one vertex of G has outdegree zero inside G, because the edge between two outdegree-zero vertices would point one way.

Repair cost, gate side of S_{l,0}. If i in G is joined to j in G, the unique failed gate of i sits at child (j, a(i,j)); initially P_{l-1,Q-q}(x_{j,a(i,j)}) = P_{l-1,Q}(x_{j,a(i,j)}) = 1. Repair requires P_{l-1,Q-q} = 0, which nesting turns into P_{l-1,Q} = 0. Both flip 1 -> 0 jointly on the same child, so at most J'_1 flips repair this clause. The possible vertex of G with no internal outedge has its failed gate in a row outside G; its repair changes P_{l-1,Q-q} from one to zero and costs at most S'_1 flips. Since |G| <= 3, the gate contribution is at most S'_1 + 3 J'_1. Adding the target side gives S_{l,0} <= t S'_0 + S'_1 + 3 J'_1.

Joint transitions from zero. Fix q < q' and x with P_{l,q}(x) = P_{l,q'}(x) = 0, and form the same lists T, G for the weaker index q. A flip making both parents one must satisfy some previously false clause at x for q; by nesting, the clause satisfied for q' is satisfied for q, so a specific clause can be chosen from the initial lists that is satisfied for both after the flip.

Target witness in T: the bound t S'_0 applies as in the S_{l,0} case.

Gate witness in G: put g = Q-q and g' = Q-q', so 1 <= g' < g < Q. Its unique failed gate at index q has P_{l-1,g}(x) = 1 initially; nesting gives P_{l-1,g'}(x) = 1 initially. Satisfying the clause for q' after the flip requires P_{l-1,g'}(x^a) = 0, and nesting then forces P_{l-1,g}(x^a) = 0. Both child predicates flip 1 -> 0 at the same child, so each clause of G contributes at most J'_1. This covers the outdegree-zero vertex of G as well: the two parent indices q, q' supply the pair of thresholds on the same child even when the unique failed gate sits outside G. With |G| <= 3, the gate contribution is at most 3 J'_1, and J_{l,0} <= t S'_0 + 3 J'_1.

Taking the maxima over q, q' and x gives the proposition. If H = 1 there are no pairs q < q', and the empty-maximum convention supplies both joint inequalities.

Lemma (profile growth). Suppose d >= 1 and M >= 9^(d+1). For every 0 <= l <= d and b in {0,1},

    S_{l,b} <= 2 L M^(l+b).

Proof. Define

    u_l = max_{b in {0,1}} S_{l,b} / M^(l+b),         v_l = max_{b in {0,1}} J_{l,b} / M^(l+b),
    epsilon = max(r, t) / M.

The base bounds give u_0 <= L and v_0 = 0. Fix 1 <= l <= d and divide each recurrence by the appropriate power of M. Using S_{l-1,b} / M^(l-1+b) <= u_{l-1} and J_{l-1,b} / M^(l-1+b) <= v_{l-1} at every b,

    S_{l,1} / M^(l+1) <= (1 + r/M) u_{l-1},
    S_{l,0} / M^l     <= (1 + t/M) u_{l-1} + 3 v_{l-1},
    J_{l,1} / M^(l+1) <= (r/M) u_{l-1} + v_{l-1},
    J_{l,0} / M^l     <= (t/M) u_{l-1} + 3 v_{l-1}.

Every coefficient of u_{l-1} on the right is at most 1 + epsilon, and every coefficient of v_{l-1} is at most 3, so

    u_l <= (1 + epsilon) u_{l-1} + 3 v_{l-1},
    v_l <= epsilon u_{l-1} + 3 v_{l-1}.          (normalized)

The forcing term of v_l is at most epsilon u_{l-1}, while the inherited contribution is multiplied by 3. Since M >= 9^(d+1) >= 81, both r = ceil(sqrt M) <= 2 sqrt M and t = 16 <= 2 sqrt M hold, giving

    epsilon <= 2 / sqrt M <= 2 / 3^(d+1).          (epsilon bound)

Introduce comparison sequences U_0 = L, V_0 = 0 and

    U_l = (1 + epsilon) U_{l-1} + 3 V_{l-1},
    V_l = epsilon U_{l-1} + 3 V_{l-1}.

Nonnegativity of the coefficients propagates u_l <= U_l and v_l <= V_l by induction. Prove simultaneously that, for 0 <= l <= d,

    U_l <= 2 L,          V_l <= epsilon L (3^l - 1).          (comparison)

Both hold at l = 0. Suppose both bounds hold at every index strictly smaller than l. Then

    V_l <= 2 epsilon L + 3 epsilon L (3^(l-1) - 1) = epsilon L (3^l - 1).

Next, summing the increments of U_j for 0 <= j < l,

    U_l = L + sum_{j=0}^{l-1} (epsilon U_j + 3 V_j)
        <= L + 2 epsilon L l + 3 epsilon L sum_{j=0}^{l-1} (3^j - 1)
        = L + epsilon L [(3/2)(3^l - 1) - l].

Applying the epsilon bound,

    epsilon [(3/2)(3^l - 1) - l] <= (3^(l+1) - 3 - 2 l) / 3^(d+1).

The numerator is strictly less than 3^(d+1) when 0 <= l <= d, so the right-hand side is strictly less than one. Therefore U_l < L (1 + 1) = 2 L. This closes the simultaneous claim, and u_l <= U_l gives S_{l,b} <= 2 L M^(l+b).

Proof of the main theorem. Fix d >= 1 and choose M >= 9^(d+1); take any labelling satisfying the labelling lemma. Let f be the OR of M disjoint copies of P_{d,1}. Each copy has dimension L M (kr)^d, so f acts on

    n = L M^2 (kr)^d

bits. By the blocks lemma, each copy is zero at its zero input and has M k^d disjoint sensitive blocks at that input; hence f(0) = 0 and f is nonconstant.

Sensitivity of f. At a zero input of f every copy reads zero and has at most S_{d,0} sensitive bits; the OR is at most M S_{d,0}. At a one input, either at least two copies accept (no single bit can change an accepting copy, so no bit is sensitive for f), or exactly one copy accepts (all sensitive bits lie inside that copy, at most S_{d,1} sensitive bits). Hence

    s(f) <= max(M S_{d,0}, S_{d,1}) <= 2 L M^(d+1).         (sensitivity bound)

Block sensitivity at zero. Each copy delivers M k^d disjoint blocks by the blocks lemma; the union of these blocks over the M disjoint copies is a family of M^2 k^d disjoint sensitive blocks for f at zero, so

    bs(f) >= bs(f, 0) >= M^2 k^d.         (block bound)

Since f is nonconstant, s(f) > 0. Dividing the block bound by the square of the sensitivity bound,

    bs(f) / s(f)^2 >= (M^2 k^d) / (4 L^2 M^(2d+2)) = (k / M^2)^d / (4 L^2).

Since k = 2 M^2 + 1 >= 2 M^2, the factor (k / M^2)^d is at least 2^d, and 4 L^2 = 4 (d + 2)^2. Therefore

    bs(f) / s(f)^2 >= 2^d / (4 (d+2)^2).

For a proposed constant C > 0, first choose d so that 2^d / (4 (d+2)^2) exceeds C. Then choose M >= 9^(d+1), take any labelling satisfying the lemma, and form f. The resulting finite-dimensional total nonconstant function satisfies bs(f) > C s(f)^2. No universal quadratic upper bound of the shape bs(f) <= C s(f)^2 can hold.

The amplification methods for turning a single superquadratic seed into a fixed power law are related to Ambainis and Sun's OR-balancing argument and to Tal's composition analysis. A composition seed of the kind used next also appears in Ambainis and Prusis, who noted that a seed with bs > s^2 produces a superquadratic power separation by iteration.

    ./ambainis-prusis-2014-eccc-tr14-027.pdf

Lemma (composition). Let f: {0,1}^a -> {0,1} and g: {0,1}^b -> {0,1} be total Boolean functions. The disjoint composition f circ g on ab bits is

    (f circ g)(x_1, ..., x_a) = f(g(x_1), ..., g(x_a)),          x_i in {0,1}^b.

Then s(f circ g) <= s(f) s(g). If g(0) = 0, then (f circ g)(0) = f(0) and bs(f circ g, 0) >= bs(f, 0) bs(g, 0). Any disjoint families of p and q blocks sensitive at zero for f and g respectively yield a disjoint family of p q blocks sensitive at zero for f circ g.

Proof. For an input x = (x_1, ..., x_a), put y = (g(x_1), ..., g(x_a)). A bit of child x_i is sensitive for f circ g at x iff it is sensitive for g at x_i and coordinate i is sensitive for f at y. Hence

    s(f circ g, x) = sum_{i : f(y^{i}) != f(y)} s(g, x_i) <= s(f, y) s(g) <= s(f) s(g).

For the block bound, suppose g(0) = 0. Let C_1, ..., C_p subset [a] be disjoint nonempty blocks sensitive for f at zero, and D_1, ..., D_q subset [b] be disjoint nonempty blocks sensitive for g at zero. Identify coordinates of f circ g with [a] x [b] and set E_{i,j} = C_i x D_j. These sets are nonempty, and disjoint: different i use disjoint children, and for fixed i the D_j are disjoint inside every child. Flipping E_{i,j} at zero sends g(x_{i'}) = 0 to one exactly for i' in C_i, so the outer argument becomes 0^{C_i}, which changes f. Hence every E_{i,j} is sensitive at zero for f circ g. Choosing maximum families gives the inequality bs(f circ g, 0) >= bs(f, 0) bs(g, 0).

Corollary (fixed exponent by composition). There exist a real alpha > 2 and nonconstant total Boolean functions F_m, m >= 1, with

    bs(F_m, 0) >= s(F_m)^alpha     for every m,      bs(F_m, 0) -> infinity as m -> infinity.

Proof. Fix d = 9, choose M >= 9^10, and take any labelling satisfying the labelling lemma. Let f be the function of the main theorem proof with these parameters. Put

    A = 22 M^10,          B = M^2 k^9.

Since L = 11, the sensitivity bound and block bound for f give s(f) <= A, bs(f, 0) >= B, and f(0) = 0. The ratio satisfies

    B / A^2 = (k/M^2)^9 / 484 >= 2^9 / 484 = 128 / 121 > 1.

Hence A > 1, B > A^2, and the real number

    alpha = log B / log A

satisfies A^alpha = B and alpha = log B / log A > log(A^2) / log A = 2. Set F_1 = f and, for m >= 1, set F_{m+1} = f circ F_m using disjoint copies of F_m. Inductively F_m(0) = 0 and F_m is a total Boolean function on n^m bits, with n = L M^2 (kr)^9. The composition lemma gives

    s(F_m) <= A^m,          bs(F_m, 0) >= B^m.

The block bound tends to infinity, which also proves nonconstancy. Since A^alpha = B,

    s(F_m)^alpha <= A^(m alpha) = B^m <= bs(F_m, 0).

The same estimates give

    bs(F_m) / s(F_m)^2 >= (B / A^2)^m >= (128 / 121)^m.

The polynomial exponent can therefore be fixed at any value greater than two. No universal quadratic upper bound of the form bs(f) <= C s(f)^2 holds for a constant C independent of f.
